# 2026 글로벌 AI 투자 트렌드 — 숏폼 데이터 영상

코드(순수 Python)로 생성하는 세로형 9:16 숏폼 데이터 애니메이션 영상입니다.
빌드 도구·타임라인 편집기 없이 `make_video.py` **한 파일**로 MP4를 만듭니다.

- **산출물**: [`out/ai_trends_2026.mp4`](out/ai_trends_2026.mp4)
- **규격**: 1080×1920 (9:16) · 30fps · H.264(yuv420p) · 약 31.7초 · ~1.6MB
- **주제**: 요즘 트렌드에 맞춘 "2026 글로벌 AI 투자 트렌드" (인프라 투자 → 수익화)

> ⚠️ 화면에 나오는 수치(1.5조 달러, CAPEX 추이 등)는 **트렌드를 설명하기 위한 예시 데이터**이며
> 특정 기관의 공식 전망치가 아닙니다.

## 디자인

미래에셋 디자인 시스템을 적용했습니다.

- 컬러: Orange `#F58220` · Blue `#043B72`, 흰 캔버스
- 시그니처: 1px 오렌지 섹션 룰, 하단 진행 바
- 규칙: 그라데이션·이모지 없음, 샤프한 모서리, 로고/워드마크 흉내 없음

## 실행

```bash
pip install pillow imageio imageio-ffmpeg numpy
cd video
python3 make_video.py      # -> out/ai_trends_2026.mp4
```

`imageio-ffmpeg` 가 ffmpeg 바이너리를 자동으로 제공하므로 별도 설치가 필요 없습니다.

## 폰트

`fonts/NotoSansKR-*.ttf` — Noto Sans KR(SIL Open Font License).
저장소 용량을 위해 **영상에 실제로 쓰이는 글리프만 서브셋**한 파일(각 ~43KB)입니다.

문구를 바꿔 새 글리프가 필요해지면, 전체 웨이트를 받아 다시 서브셋하세요.

```bash
# 전체 웨이트 내려받기 (TTF 포함)
npm pack @expo-google-fonts/noto-sans-kr
tar -xzf expo-google-fonts-noto-sans-kr-*.tgz
# 원하는 웨이트를 fonts/ 로 복사 후 사용, 필요 시 pyftsubset 로 서브셋
```

## 콘텐츠 수정

`make_video.py` 상단의 씬 함수(`scene_*`)에서 문구·수치를 바꾸면 됩니다.
`SCENES` 리스트로 씬 순서·길이를, `FPS`/`W`/`H` 로 규격을 조정합니다.
