# 부동산 세금 계산기 — 2026년 세제개편안 반영

재정경제부 「2026년 세제개편안」(2026. 8. 3. 발표) 상세본을 기준으로 **취득세 · 재산세 ·
종합부동산세 · 양도소득세**를 한 화면에서 계산하는 상담 실무용 도구입니다.
거주/비거주, 단독명의/공동명의, 1주택/2주택/3주택 이상 등 조건을 바꾸면 네 세목이 즉시 다시 계산됩니다.

빌드 도구 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

```
tax-calculator/
├── index.html      # 화면 (레이아웃 + CSS + 입력 폼)
├── tax-engine.js   # 세금 계산 엔진 (순수 함수, DOM 의존 없음)
├── app.js          # 상태 관리 · 렌더링 · 한/영 전환
└── verify.js       # 세미나 자료 사례 대조 검증 (node verify.js)
```

## 세목별 적용 기준

### 종합부동산세 — 개편 대상 (2027년 시행)

계산 5단계를 모두 반영합니다.

1. **과세대상 문턱** (2027년 신설) — 1세대 1주택자 공시가격 14억원 초과 / 그 외 9억원 초과
2. **기본공제** — 2026년 12억/9억 → 2027년 거주 1주택 14억, 비거주 1주택 9억,
   그 외 개인 `4억원 + 5억원 × (거주주택 공시가격 ÷ 보유주택 공시가격 합계)`
3. **공정시장가액비율** — 60% → 2027년 70% → 2028년 이후 3주택 이상·조정지역 보유자(1세대 1주택자 제외) 80%
4. **세율** — 2027년 과표 6~12억 구간 1.0% → 1.3%, 2028년부터 주택 수 구분 없는 단일 세율표(0.5~5.0%)
5. **재산세 중복분 공제 → 세액공제 → 세부담상한** — 보유공제에서 거주공제로 전환,
   금액한도 2027년 800만원 / 2028년 이후 600만원, 세부담상한 150% → 200%

공동명의는 **개별과세(인별 지분 판정)** 와 **공동명의 1주택자 특례(주택 전체 판정 + 세액공제 적용)** 를
모두 계산해 유불리를 나란히 보여줍니다.

### 양도소득세 — 개편 대상 (2028~2029년 시행)

- **장기보유특별공제 → 장기거주 소득공제** : 1세대 1주택 우대공제(보유 3년 + 거주 2년 요건)는
  ~2027년 보유 4% + 거주 4% → 2028년 거주 6% + 보유 2% → 2029년 거주 연 8%(보유공제 폐지)
- **공제 금액한도 신설** : 2028년 인별·물건별 각 20억원 → 2029년 이후 각 10억원.
  물건별 한도는 지분율대로 안분
- **기본공제** : 연 250만원 → 10년 이상 거주 + 양도가액 30억원 이하 1세대 1주택은 2,500만원(2027년~)
- **다주택 중과 한시 완화** : 2026~2027년 2주택 +5%p / 3주택 +10%p, 2028년 +10%p / +15%p, 2029년 복귀
- **고령 1주택자 지방 이주 감면** : 2027년 50%(한도 5억) / 2028년 30%(한도 3억)
- 단기양도세율(1년 미만 70%, 1~2년 60%)과 비교해 큰 세액을 적용, 지방소득세 10% 가산

### 취득세 · 재산세 — 개편 대상 아님 (현행 지방세법)

이번 개편은 국세(종부세·양도세)만 손질하고 지방세는 그대로 두었습니다. 두 세목은 현행 기준으로 산출합니다.

- **취득세** : 1주택 6억 이하 1%, 6~9억 누진(1~3%), 9억 초과 3% / 조정 2주택·비조정 3주택 8% /
  조정 3주택 이상·비조정 4주택 이상·법인 12%. 지방교육세 및 전용 85㎡ 초과 시 농어촌특별세 가산
- **재산세** : 공정시장가액비율 1세대 1주택 43~45%, 그 외 60%. 공시가격 9억원 이하 1세대 1주택은
  세율 0.05%p 인하 특례. 도시지역분(과세표준 × 0.14%)과 지방교육세(본세 × 20%) 포함.
  공동명의도 주택 전체로 산출한 뒤 지분 안분하므로 누진 완화 효과가 없습니다

## 검증

```bash
node verify.js
```

세미나 자료(50p)의 계산 사례 **31개 항목을 대조**해 통과합니다 — 재산세(p.46), 종부세(p.39~42, 47),
양도세(p.30, 43, 44, 49).

### 자료 산술 오류로 대조에서 제외한 3개 항목

아래 항목은 자료가 **함께 제시한 과세표준·세율로 재계산하면 자료의 결과값과 맞지 않습니다.**
본 계산기는 자료의 결과값을 재현하지 않고, 자료가 명시한 세율·공제 규정을 그대로 적용합니다.

| 자료 위치 | 자료 값 | 규정대로 계산한 값 |
|---|---|---|
| p.42 A안 2027년 종부세 | 366만원 | **416만원** (과표 6.43125억 × 0.5/0.7/1.3%) |
| p.42 C안 2027 · 2028년 | 491만 / 748만원 | **672만 / 828만원** |
| p.49 2028 · 2029년 양도세 | 8,542만 / 1억 150만원 | **9,150만 / 1억 677만원** (과표 1.619억·1.802억, 38% 구간, 누진공제 1,994만원) |

p.42 A안의 경우 세율 구조가 동일한 **2028년 행은 자료 값(536만원)과 정확히 일치**하므로,
2027년 행의 계산 착오로 판단했습니다.

## 계산 방법에 관한 유의사항

- 종부세는 산출세액에서 **재산세 중복분을 먼저 공제한 뒤 세액공제를 적용**하는 법정 순서로 계산합니다.
  세미나 자료의 일부 예시는 이 단계를 생략하고 있어 수만 원 단위 차이가 날 수 있으며,
  「계산 옵션」에서 끌 수 있습니다.
- 공동명의 지분율은 **보유 중인 모든 주택에 동일하게 적용**되는 것으로 가정합니다.
  주택별로 명의 구조가 다르면 개별 검토가 필요합니다.
- **세부담상한**(150% → 200%)은 직전연도 보유세 합계를 입력한 경우에만 판정합니다.
- 상생임대주택, 등록임대주택, 재개발·재건축 공사기간, 부득이한 사유에 따른 **거주기간 인정 특례는
  반영되어 있지 않습니다.** 해당되는 경우 거주기간 입력값에 직접 가산하십시오.
- 공시가격은 사용자 입력값으로 고정하며, 연도별 비교는 **공시가격 불변 가정**입니다.
