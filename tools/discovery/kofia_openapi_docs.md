 API 활용약관

 금융투자협회 오픈API 서비스의 활용약관 입니다.

 제 01 조 [목적]

 본 활용 약관(이하 ‘약관’이라 합니다.)은 금융투자협회가 제공하는 오픈API 서비스의 이용에 관한 제반 사항과 기타 필요한 사항을 규정함을 목적으로 합니다.

 제 02 조 [용어의 정의]

 ① 본 약관에서 사용하는 용어의 정의는 다음 각 호와 같습니다.

 가. 오픈API라 함은 Application Programming Interface 의 약자로, 정보 제공자가 정보 이용자에게 제공하기 위하여 정의한 규약을 말합니다.

 나. 오픈API 서비스라 함은 금융투자협회가 제공·운영하는 정보를 이용자들이 자유롭게 이용할 수 있도록 제공하는 등록 값의 집합을 말합니다.

 다. 오픈API 이용자(이하 'API 이용자')라 함은 본 약관에서 규정한 절차를 통해 금융투자협회가 제공하는 오픈API 서비스에 대한 이용 허락을 득한 자로서 금융투자협회가 제공하는 오픈API 서비스를 활용하는 자를 말합니다. 

 라. 인증키라 함은 오픈API 서비스 이용 허가를 받은 사람임을 식별할 수 있도록 금융투자협회가 정보 이용자에게 개별적으로 할당하는 고유한 값을 말합니다.

 ② 이 약관에서 정하지 아니한 것은 관계 법령 및 이용 안내에서 정하는 바에 따르며, 그 외에는 일반 관례에 따릅니다.

 제 03 조 [적용범위]

 ① 본 약관은 금융투자협회 통합 회원에 가입한 후, 본 약관에 동의한 자(이하 “회원”이라 합니다) 또는 금융투자협회 통합 회원에 가입하지는 않았으나 오픈API 서비스 이용을 위하여 본 약관에 동의한 자(이하 “비회원”이라 합니다)에 대하여 적용합니다.

 ② 본 약관은 회원 또는 비회원에 대한 오픈API 서비스 제공 행위 및 회원 또는 비회원의 오픈API 서비스 이용 행위에 대하여 우선적으로 적용됩니다.

 ③ 본 약관에서 규정하지 않은 인증키 발급 등 회원 관리에 관한 제반 사항은 금융투자협회 회원 관리 정책을 준용합니다.

 ④ 본 약관은 금융투자협회 정보자산 제공 및 관리 지침에 반하지 아니하는 범위 내에서 효력을 갖습니다.

 제 04 조 [약관의 효력 및 변경]

 ① 본 약관은 오픈API 서비스의 이용을 위하여 회원 또는 비회원이 동의를 함으로써 효력이 발생합니다.

 ② 금융투자협회는 합리적인 사유가 발생할 경우 본 약관을 변경할 수 있으며, 이 경우 일정한 기간을 정하여 적용일자 및 변경사유를 명시한 사항을 회원 또는 비회원에게 공지 또는 통지합니다.

 ③ 제2항에 따른 약관의 변경은 회원 또는 비회원이 동의함으로써 그 효력이 발생됩니다. 다만, 제2항에 따른 통지를 하면서 회원 또는 비회원에게 일정한 기간 내에 의사 표시를 하지 않으면 의사 표시가 표명된 것으로 본다는 뜻을 명확히 전달하였음에도 회원 또는 비회원이 명시적으로 거부의 의사표시를 하지 아니한 경우에는 회원 또는 비회원이 개정약관에 동의한 것으로 봅니다. 

 ④ 회원 또는 비회원은 오픈API 서비스를 이용할 시 주기적으로 공지사항을 확인하여야 할 의무가 있습니다. 

 ⑤ 약관의 변경 사실 및 내역을 확인하지 못하여 발생한 모든 손해에 대한 책임은 회원 또는 비회원에게 귀속됩니다. 

 제 05 조 [오픈API 서비스 제공]

 ① API 이용자는 오픈API 서비스를 이용함에 있어 인증키 신청을 통하여 신청 후 금융투자협회의 승인을 거쳐 인증키를 발급받아야 하며, 발급받은 인증키를 이용하여 오픈API 서비스를 이용할 수 있습니다.

 ② 인증키 발급 신청시 API 이용자가 필수 입력해야 하는 항목들은 성실히 입력되어야 합니다.

 제 06 조 [오픈API 서비스 제한]

 ① 금융투자협회는 오픈API 서비스 이용 가능 기간 또는 일일 트래픽을 지정 및 변경할 수 있으며 이를 홈페이지를 통하여 사전에 고지하여야 합니다.

 ② API 이용자는 이용 가능 기간 내에서만 오픈API 서비스를 이용할 수 있으며, 만약 일일트래픽을 초과하여 이용하고자 할 경우에는 금융투자협회에서 규정하는 서류 제출 등의 절차를 거쳐야 합니다.

 ③ 금융투자협회는 API 이용자가 오픈API 서비스에 대한 불법적인 해킹 시도, 비정상적인 방식을 통한 오남용 시도, 네트워크 사용 초과 등의 시도를 하는 경우 제1항의 규정에도 불구하고 즉시 인증키의 사용을 정지시킬 수 있습니다. 

 제 07 조 [인증키 관리]

 ① API 이용자는 발급 받은 인증키를 타인에게 제공, 공개하거나 공유할 수 없으며, 발급 받은 정보 이용자 본인에 한하여 이를 사용할 수 있습니다. 

 ② API 이용자는 1개의 인증키만을 발급받아 사용할 수 있으며, 어떠한 경우에도 2개 이상의 인증키를 발급받거나 그러한 시도를 하여서는 안 됩니다.

 제 08 조 [서비스 이용 시 주의사항]

 ① API 이용자는 오픈API 서비스를 이용한 결과를 구성함에 있어 다음 각 호에 해당하는 내용과 결합하여 구성할 수 없습니다. 

 - 가. 공공질서 및 미풍양속에 반하는 경우

 - 나. 범죄적 행위에 관련되는 경우

 - 다. 국익 또는 사회적 공익을 저해하는 경우

 - 라. 타인의 명예를 손상시키거나 불이익을 주는 경우

 - 마. 오픈API 서비스에 위해를 가하는 등 서비스의 건전한 이용을 저해한 경우

 ② API 이용자는 오픈API 서비스를 비상업적인 목적으로만 이용할 수 있으며, 오픈API 서비스를 이용한 결과에 대한 비용을 API 이용자가 제공하는 서비스의 이용자에게 청구해서는 안 됩니다.

 ③ API 이용자는 오픈API 서비스를 이용한 결과의 앞, 뒤, 중간 등에 다른 내용을 삽입하거나 왜곡할 수 없고, 타인으로 하여금 결과의 내용 및 의도 등을 오인하게 해서는 안 됩니다. 또한 URL 등 오픈API 서비스로 제공되는 모든 내용을 API 이용자가 임의로 변조해서는 안 됩니다. 

 ④ 금융투자협회에서 제공하는 오픈API 서비스의 결과를 API 이용자가 왜곡한 경우 금융투자협회는 API 이용자에게 형사적 책임을 물을 수 있습니다.

 제 09 조 [오픈AI 정보 활용자의 의무]

 ① API 이용자는 오픈API 서비스를 이용함에 있어서 본 약관에서 규정하는 사항과 기타 금융투자협회에서 정한 제반 규정, 공지 사항 및 관계 법령을 준수하여야 합니다.

 ② API 이용자는 금융투자협회의 업무에 방해가 되는 행위 또는 금융투자협회의 명예를 손상시키는 행위를 해서는 안 됩니다.

 ③ 오픈API 서비스를 이용함에 있어서 오픈API 정보 활용자의 행위에 대한 모든 책임은 당사자가 부담하며, API 이용자는 금융투자협회를 대리하는 것으로 오해가 될 수 있는 행위를 해서는 안 됩니다. 

 제 10 조 [서비스 저작권]

 ① API 이용자는 오픈API 서비스 이용 시 금융투자협회의 지적재산권을 침해해서는 안 됩니다.

 ② 금융투자협회가 제공하는 오픈API에 대한 저작권은 금융투자협회에 있고, 금융투자협회의 이용 허락으로 인해 API 이용자는 당해 오픈API 서비스에 대한 저작권을 취득하는 것은 아닙니다. 다만, API 이용자가 제작한 프로그램에 대한 저작권은 API 이용자에게 귀속됩니다. 

 ③ API 이용자는 오픈API 서비스를 이용하여 검색결과를 노출할 경우, 해당 페이지에 "금융투자협회 오픈API"를 사용한 결과임을 명시해야 합니다. 다만, 금융투자협회가 별도의 표시 방식을 정한 경우에는 그에 따라야 합니다.

 제 11 조 [책임의 제한]

 ① 금융투자협회는 오픈API 서비스에 관하여 약관, 금융투자협회가 정한 제반 규정, 이용 안내 및 관계 법령을 준수하지 않은 이용으로 인한 결과에 대하여 책임을 지지 않습니다.

 ② 금융투자협회는 오픈API 서비스의 사용 불능으로 인하여 API 이용자에게 발생한 손해에 대하여 책임을 지지 않습니다.

 ③ API 이용자가 오픈API 서비스 정보를 편집하여 새로운 부가 가치를 창출한 경우 금융투자협회는 동 부가가치에 대한 책임을 지지 않습니다.

 ④ 금융투자협회는 API 이용자가 오픈API 서비스를 이용하여 기대하는 수익을 얻지 못하거나 상실한 것에 대하여 책임을 지지 않습니다.

 ⑤ 금융투자협회는 API 이용자와 제3자 상호 간에 오픈API 서비스를 매개로 발생한 분쟁에 대해 개입할 의무가 없으며, 이로 인한 손해를 배상할 책임도 없습니다.

 제 12 조 [이용자격 박탈 및 손해배상]

 ① 금융투자협회는 API 이용자가 본 약관을 준수하지 않는 경우 서비스 사용 중지 및 이용자격을 박탈할 수 있습니다. 

 ② 오픈API 서비스 이용상 오픈API 정보 활용자의 귀책사유로 인하여 금융투자협회의 손해가 발생한 경우 금융투자협회는 본 약관에 따른 계약의 해지와는 별도로 손해배상을 청구할 수 있습니다. 

 ③ 오픈API 서비스의 이용으로 금융투자협회와 API 이용자간에 발생한 분쟁에 관하여 소송이 제기되는 경우 그 관할법원은 금융투자협회의 본사소재지(서울시 영등포구 의사당대로 143)를 관할하는 법원으로 합니다.

 <부칙> 제 01 조 (시행일) 본 약관은 2014년 5월 19일부터 적용됩니다.
