앱스토어 없이 바탕화면에 아이콘으로 설치됩니다. 설치 후에는 주소창 없이 앱처럼 열리고, 새 기능은 저절로 반영됩니다.
  1. 크롬 또는 삼성 인터넷으로 이 주소를 엽니다.
  2. 메뉴를 엽니다. 크롬은 오른쪽 위 ⋮, 삼성 인터넷은 오른쪽 아래 ≡ 입니다.
  3. 크롬은 「앱 설치」 또는 「홈 화면에 추가」, 삼성 인터넷은 「현재 페이지 추가」 → 「홈 화면」을 누른 뒤 설치(또는 추가)를 누릅니다.
