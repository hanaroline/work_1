휴대폰에 앱 설치

앱스토어 없이 바탕화면에 아이콘으로 설치됩니다. 설치 후에는 주소창 없이 앱처럼 열리고, 새 기능은 저절로 반영됩니다.
  1. 크롬 또는 삼성 인터넷으로 이 주소를 엽니다.
  2. 메뉴를 엽니다. 크롬은 오른쪽 위 ⋮, 삼성 인터넷은 오른쪽 아래 ≡ 입니다.
  3. 크롬은 「앱 설치」 또는 「홈 화면에 추가」, 삼성 인터넷은 「현재 페이지 추가」 → 「홈 화면」을 누른 뒤 설치(또는 추가)를 누릅니다.
  4. 바탕화면에 생긴 {{INSTALL_NAME}} 아이콘으로 엽니다.
  1. 반드시 사파리(Safari)로 이 주소를 엽니다. (카카오톡·네이버 앱 안에서는 안 됩니다)
  2. 아래 가운데 공유 □↑ 버튼을 누릅니다.
  3. 목록을 내려 「홈 화면에 추가」를 누르고, 오른쪽 위 추가를 누릅니다.
  4. 바탕화면에 생긴 아이콘으로 엽니다. 처음 한 번은 다시 로그인해야 할 수 있습니다.
