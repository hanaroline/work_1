# 센터 인사이트 (insight-hub)

직원이 **링크만 올리면 AI가 읽고 정리해**, 센터 직원 전체가 함께 보는 투자 인사이트 공간입니다.
초대받은 직원만 **이름 + 비밀번호**로 들어오고, 자료는 **센터 PC(서버) 안**에만 저장됩니다.
GitHub Pages나 외부 웹사이트에 올리지 않습니다.

| 올린 것 | 정리하는 AI | 비고 |
|---|---|---|
| 기사 링크 · 리포트 PDF · 스크린샷 · 붙여넣은 본문 | **Claude API** | 유료·로그인 기사는 본문을 붙여넣거나 캡처로 올림 |
| 유튜브 링크 (watch · youtu.be · shorts · live) | **Gemini API** | **공개 영상만** 됨. 요점마다 영상 시각(mm:ss)이 붙음 |

화면: 피드 · 분류/태그/기간/인기순 필터 · 검색 · **좋아요 · 댓글** · 관리(초대·정지·비번 재설정).
휴대폰에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다(PWA — HTTPS 필요, 아래 참고).

## 실행

파이썬 3.10 이상, 표준 라이브러리만 씁니다(설치할 것 없음).

```bash
cd tools/insight-hub
export ANTHROPIC_API_KEY=...      # 글 정리
export GEMINI_API_KEY=...         # 영상 정리
python3 server.py invite 홍길동 --admin   # 첫 관리자 초대 코드(8자리)가 화면에 찍힘
python3 server.py serve --port 8080
```

브라우저에서 `http://서버주소:8080/#join` → 이름 + 초대 코드 + 새 비밀번호로 처음 입장.
이후 다른 직원은 화면 오른쪽 위 **관리 → 직원 초대**에서 코드를 만들어 메신저로 전달합니다
(코드는 **3일 안에 한 번만** 쓸 수 있고, DB에는 해시만 남습니다).
비밀번호를 잊은 직원은 관리자가 **비번 재설정**으로 새 코드를 만들어 줍니다.

## 윈도우 PC에서 더블클릭으로 (설치 없이)

`python3 scripts/build_insight_hub_windows.py --out dist/` 가 **`CenterInsight-windows.zip`**(약 13MB)을 만듭니다.
윈도우용 파이썬(NuGet `python` 패키지, x64)이 함께 들어 있어 센터 PC에 아무것도 깔 필요가 없습니다.

1. zip 을 풀고 **`Start.bat`** 더블클릭 → 처음 한 번 Claude·Gemini 키(이 PC 사용자 환경변수 `setx` 에 저장)와 관리자 이름을 묻고, 초대 코드를 보여 준 뒤 브라우저를 엽니다.
2. 직원 초대는 **`Invite.bat`** 또는 화면의 관리 → 직원 초대. 직원은 창에 찍힌 "같은 망 직원" 주소 + `#join` 으로 가입합니다.
3. 자료는 `%USERPROFILE%\.insight-hub` 에 남으므로, 새 판은 폴더만 바꿔 풀면 이어집니다.

실행기는 `launcher.py`(빈 포트 찾기·첫 관리자 코드·접속 주소 안내). zip 에 키는 들어가지 않습니다.

## 입장 방식 — 처음은 엄격하게, 그다음은 바로

| | 처음 (가입) | 그다음 (같은 기기) |
|---|---|---|
| 필요한 것 | 관리자가 만든 **이름 + 8자리 초대 코드** + 새 비밀번호 | 없음 — 앱 아이콘을 누르면 바로 피드 |
| 규칙 | 코드는 **3일 안에 한 번만**, 그 이름으로 **5번 틀리면 코드 무효**(새 코드 필요), 같은 IP에서 5번 틀리면 15분 잠금. 비밀번호는 **8자 이상·영문+숫자·이름 포함 금지·흔한 비밀번호 거절** | 기기에 남은 로그인이 **쓸 때마다 180일로 다시 늘어남**(하루 한 번만 기록). 180일 동안 한 번도 열지 않은 기기만 다시 비밀번호를 물음 |

- 다시 비밀번호를 묻는 경우: 그 기기에서 **로그아웃**했을 때, **비밀번호를 바꿨을 때**(다른 기기 전부),
  관리자가 **정지·비번 재설정**했을 때(즉시), 180일 넘게 열지 않았을 때, 브라우저 데이터를 지웠을 때.
- 휴대폰을 잃어버렸으면: 다른 기기에서 **계정 → 다른 기기 모두 로그아웃**, 또는 관리자에게 정지 요청.
- **아이폰**: 홈 화면에 추가한 앱은 사파리와 저장 공간이 따로라, **앱 안에서 한 번** 로그인해야 합니다
  (그 뒤로는 앱을 누르면 바로 열림). 로그인은 서버가 주는 `HttpOnly` 쿠키라 사파리의
  '스크립트 저장값 7일 삭제' 규칙에 걸리지 않습니다.
- 기간은 `INSIGHT_SESSION_DAYS`(기본 180), 초대 코드 유효 시간은 `INSIGHT_INVITE_HOURS`(기본 72)로 바꿉니다.

**API 키는 환경변수로만** 넣습니다. 저장소 파일에 적지 마십시오.

## 설정 (환경변수)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `INSIGHT_DATA_DIR` | `~/.insight-hub` | DB(`insight.db`)와 첨부(`uploads/`)가 놓이는 곳. **저장소 밖**. 백업은 이 폴더 통째로 |
| `INSIGHT_CENTER_NAME` | `센터 인사이트` | 화면 제목·앱 이름 |
| `INSIGHT_CLAUDE_MODEL` | `claude-opus-5-5` | 글 정리 모델 |
| `INSIGHT_CLAUDE_EFFORT` | `medium` | `low`로 낮추면 빠르고 싸짐 |
| `INSIGHT_GEMINI_MODEL` | `gemini-3.8-flash` | 영상 정리 모델. **쓰는 계정에서 사용 가능한 이름인지 먼저 확인하십시오** |
| `ANTHROPIC_BASE_URL` / `INSIGHT_GEMINI_BASE_URL` | 공식 주소 | 회사 프록시를 거칠 때만 |
| `INSIGHT_SESSION_DAYS` | `180` | 쓰지 않고 이 기간이 지나면 다시 로그인. 쓸 때마다 다시 늘어남 |
| `INSIGHT_INVITE_HOURS` | `72` | 초대·비번 재설정 코드 유효 시간 |
| `INSIGHT_COOKIE_SECURE=1` | | HTTPS 리버스 프록시 뒤에서 돌릴 때 |
| `INSIGHT_TRUST_PROXY=1` | | 프록시가 넘기는 `X-Forwarded-For`를 로그인 잠금에 씀 |

## 앱처럼 쓰기 (PWA)

홈 화면 설치는 브라우저 규칙상 **HTTPS**에서만 됩니다(같은 PC의 `localhost`는 예외).

- 사내 인증서가 있으면: `python3 server.py serve --port 8443 --cert cert.pem --key key.pem`
- 또는 사내 리버스 프록시(nginx 등) 뒤에 두고 `INSIGHT_COOKIE_SECURE=1`

서비스 워커는 화면 껍데기만 저장하고 **자료(`/api/…`)는 기기에 저장하지 않습니다.**

## 정리 규칙 (AI에 주는 지시의 요지)

- 자료에 있는 내용만. 바깥 지식·최신 시세·추정치를 덧붙이지 않음.
- 숫자·날짜는 자료에 적힌 그대로, 기준 시점이 없으면 "기준 시점 표기 없음"으로 보임.
- 없는 항목은 비워 둠(틀린 값보다 빈칸). 근거 약한 주장은 따로 "확인되지 않은 주장"에.
- 매수·매도 권유 문장을 쓰지 않음. 시사점은 "필자는 ~로 본다" 꼴.
- 본문을 못 읽은 경우(로그인 벽, 스크립트로 그리는 사이트, 본문 300자 미만)는 **지어내지 않고 멈춤** →
  화면에 "본문을 붙여넣어 다시 정리" 칸이 뜸.
- 본문이 15만 자를 넘으면 앞부분만 보내고 그 사실을 화면에 적음.

## 보안

- 비밀번호 PBKDF2-SHA256(31만 회), 세션은 무작위 토큰의 해시만 DB 저장, 쿠키 `HttpOnly; SameSite=Strict`(HTTPS면 `Secure`), 쓰는 동안 180일씩 연장.
- 같은 이름+IP로 5번 틀리면 15분 잠금. 초대 코드는 그 이름으로 5번 틀리면 무효. 정지된 직원은 즉시 로그아웃.
- 상태를 바꾸는 요청은 전용 헤더 + 출처(Origin) 확인.
- 링크 읽기는 **공인 주소만** — 사내망·`localhost`·클라우드 메타데이터 주소는 거절(리다이렉트도 매번 검사). `*.translate.goog`도 거절.
- 첨부는 PDF·PNG·JPG·WEBP·GIF, 20MB까지. 로그인한 직원만 받을 수 있음.
- 같은 링크가 30일 안에 이미 올라와 있으면 그 글로 안내.

## ⚠ 올리면 안 되는 것

올린 자료는 **Anthropic(Claude)·Google(Gemini) 서버로 보내져** 정리됩니다.
**고객 이름·계좌·연락처·상담 내용 등 고객 정보가 담긴 자료는 절대 올리지 마십시오.**
사내 비공개 자료를 올려도 되는지는 준법감시 기준을 먼저 확인하십시오.
AI 정리는 참고용이며, 고객에게 전달하기 전에 원문과 숫자를 직접 확인해야 합니다.
