# 퇴직급여 수령 의사결정 시뮬레이터

퇴직 시 퇴직급여를 **어느 연금계좌로 받아야 유리한지** 판정하고, 연차별 인출 한도와
세액을 시뮬레이션해 고객에게 A4 1장으로 출력해 주는 상담 도구.

산출물: 저장소 루트의 `retirement-simulator.html` — **외부 네트워크 없이 열리는 단일 파일**
(React·Tailwind·앱 코드가 모두 인라인되어 있어 지점 PC에서 그대로 열림).

## 빌드

이 저장소는 `package.json` 이 `.gitignore` 대상이라 빌드 의존성을 직접 설치해야 한다.

```bash
npm install --no-save react@18.3.1 react-dom@18.3.1 @babel/standalone@7.25.6 tailwindcss@3.4.16
node scripts/build-retirement-simulator.js
```

| 파일 | 역할 |
|---|---|
| `app.jsx` | 판정 로직 · 시뮬레이션 · React 컴포넌트 (수정은 여기서) |
| `styles.css` | 미래에셋 디자인 토큰 + A4 인쇄 스타일 |
| `tailwind.config.js` | 브랜드 컬러/라운드/폰트 토큰 |
| `shell.html` | 인라인 대상 자리표시자를 가진 HTML 껍데기 |
| `../../scripts/build-retirement-simulator.js` | Tailwind 추출 → JSX 트랜스파일 → 단일 HTML 조립 |

`retirement-simulator.html` 을 직접 고치지 말 것 — 빌드 산출물이라 덮어써진다.

## 판정 로직의 근거

### 1. 계좌 선택이 갈리는 지점 — 2013.3.1

연금수령한도는 `과세기간 개시일 현재 평가액 ÷ (11 − 연금수령연차) × 120%` 이고,
**2013.3.1 이전에 가입한 연금계좌는 연금수령연차를 6년차부터 기산**한다.

| 계좌 | 한도 기산 | 한도 해제까지 | 최소 권장 수령 기간 |
|---|---|---|---|
| 2013.3.1 이전 가입 (잔고 보유) | 6년차 | 5년 | **5년** |
| 2013.3.1 이후 가입 · 신규 개설 | 1년차 | 10년 | **10년** |

구계좌 특례는 **잔고가 남아 있어야** 인정된다. 잔고 0원 계좌는 신규와 동일하게 본다.

### 2. 재원별 이전 가능 여부

퇴직급여 재원은 `법정퇴직금` / `명예(법정외)퇴직금` / `DB` / `DC` 로 나뉘고,
재원마다 들어갈 수 있는 계좌가 다르다. 앱은 재원별로 최적 계좌를 따로 배정하므로
**분할 입금**이 자동으로 잡힌다.

- **만 55세 미만**: 법정퇴직금·DB·DC 는 IRP 의무이전 대상(근퇴법 §17·§20)이라 연금저축 입금 불가.
  명예퇴직금은 근퇴법상 퇴직급여가 아니므로 55세 미만이어도 연금저축 입금(과세이연) 가능.
- **DB·DC → 구 연금계좌**: 2013.3.1 이후 가입한 DB·DC 지급액은 2013.3.1 이전 가입 연금계좌로
  이체 불가 (소득세법 시행령 §40의4). 신규 개설로 유도한다.
- **법정퇴직금·명예퇴직금**: 연금계좌 간 '이체'가 아닌 퇴직소득 '입금'이라 위 제한을 받지 않는다.
  2013.3.1 이전 가입 계좌에 넣어 6년차 특례를 받을 수 있다.

### 3. 세액

- 인출 순서: 과세제외금액 → **이연퇴직소득** → 세액공제 납입분·운용수익 (소득세법 시행령 §40의3).
- 퇴직소득세 감면: 실제 연금수령 **1~10년차 30%**, **11년차부터 40%**.
  여기서 '실제 연금수령연차'는 한도 계산용 연차(구계좌는 6년차 기산)와 **별개로**
  실제 수령 누적 횟수로 센다. 그래서 과거 수령 횟수를 따로 입력받는다.
- 세액공제 납입분·운용수익 인출분: 연령별 연금소득세 (70세 미만 5.5%, 70대 4.4%, 80세 이상 3.3%).
- 분할 입금 시 이연퇴직소득세는 계좌 배정액 비율로 안분한다.

## 검증

Playwright 로 다음을 확인했다.

- 구 연금저축(2013 이전·잔고 보유) 보유 시 6년차 기산 추천, 5년 수령으로 잔액 0 소진
- 2016년 가입 DC → 구 연금저축 이전 불가 판정 후 신규 IRP 추천
- 만 50세: 법정퇴직금 → 신규 IRP, 명예퇴직금 → 구 연금저축 분할 배정
- 수령 기간 30년(표 최대 길이)에서도 인쇄가 A4 단면 1장 (콘텐츠 1,007px / 1,062px)

## 한계

- 이연퇴직소득세는 원천징수영수증 기준으로 **입력**받는다. 근속연수·환산급여 공제를 통한
  퇴직소득세 자체 계산은 하지 않는다.
- 사적연금 연 1,500만원 초과 시의 종합과세·16.5% 분리과세 선택은 화면에 안내만 하고
  세액 계산에는 반영하지 않는다 (분리과세 기준으로 계산).
- 300만원 이하 소액 퇴직급여의 IRP 의무이전 예외는 반영하지 않았다.
