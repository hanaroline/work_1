## 2. 보유 계좌를 다른 계좌로 옮길 수 있는가 (계약이전)

전액 이체 · 이체받는 계좌는 연금개시 전이라고 가정했습니다.
일부만 이체하거나 연금개시된 계좌로 보내면 어느 조합이든 **X** 입니다(Q23 ③④).

**연금수령요건 미충족**

| 보내는 계좌 \ 받는 계좌 | 연금저축(구) | 연금저축(신) | IRP(구) | IRP(신) |
|---|---|---|---|---|
| 연금저축(구) | O | O | X | X |
| 연금저축(신) | X | O | X | X |
| IRP(구) | X | X | O | O |
| IRP(신) | X | X | X | O |

### 옮기면 연금수령연차가 어떻게 되는가

**이전 가능 여부보다 이쪽이 실익을 가릅니다.** 2013.3.1 전 가입 계좌는 6년차부터
기산하는데, 이체하면 가입일이 **받는 계좌 기준**이 되어 그 특례를 잃을 수 있습니다.

| 옮기는 방향 | 이전 | 연차 | 판단 |
|---|---|---|---|
| 구 계좌 → 기존 구 계좌 | 가능 | 6년차 유지 | 무방 |
| 구 계좌 → 기존 신 계좌 | 가능 | **6년차 → 1년차** | **옮기지 말 것** - 한도가 몇 배 줄어듭니다 |
| 구 계좌 → 신규 개설 계좌 (전액) | 가능 | 승계 가능(미확인) | 가입일자 승계 여부를 반드시 확인 |
| 신 계좌 → 기존 구 계좌 | **불가** | - | Q23② 에 걸립니다 |
| 신 계좌 → 신 계좌 | 가능 | 1년차 그대로 | 무방 (수수료·상품만 보면 됩니다) |

> 세 번째 줄의 가입일자 승계는 원본 Q&A 를 확인하지 못했습니다. 소득세법 시행령 §40의4② 로
> 알려진 내용(새로 설정된 계좌에 전액 이체 시 이체 전 계좌 기준)이지만, **확인 전까지는
> 상담에 단정해 쓰지 마세요.**
