# 퇴직소득세 — 규칙에서 전개합니다

`이연 퇴직소득세` 는 원래 원천징수영수증에서 보고 손으로 옮겨 적는 칸이었습니다.
퇴직 **전** 상담에는 영수증이 없으므로 그 칸이 비고, 그러면 세액 비교와 인출 세액이
통째로 나오지 않습니다. 입사일·퇴직일·퇴직급여액에서 직접 산출합니다.

## 산식 (2023.1.1 이후 퇴직분)

```
① 퇴직소득금액   = 법정퇴직금 + 명예퇴직금 − 비과세 퇴직급여     (§22)
② 근속연수공제   = 근속연수 구간별 공제                          (§48①1)
③ 환산급여       = (① − ②) ÷ 근속연수 × 12                      (§48②)
④ 환산급여공제   = 환산급여 구간별 공제                          (§48③)
⑤ 과세표준       = ③ − ④
⑥ 환산산출세액   = ⑤ × 기본세율                                  (§55①)
⑦ 산출세액       = ⑥ ÷ 12 × 근속연수      ← 이연퇴직소득세(국세)
   지방소득세     = ⑦ × 10%                                       (지방세법 §103의3)
```

**퇴직급여 전체를 합해 한 번** 계산합니다. 법정퇴직금과 명예퇴직금을 따로 계산하지
않습니다 — 둘 다 퇴직소득이고 같은 과세표준에 들어갑니다. 계좌가 여럿이면 그 합계를
계좌 배정액 비율로 안분합니다(시행령 §202의2).

**근속연수는 1년 미만을 1년으로 올립니다**(시행령 §105②). 하루만 넘겨도 한 해가
올라가므로 세액이 눈에 띄게 갈립니다.

## 국세와 지방소득세

| | |
|---|---|
| `tax` | 국세. **원천징수영수증의 '이연퇴직소득세' 가 이 값**입니다 |
| `local` | 지방소득세 = 국세의 10% |
| `total` | 합계. **인출 시뮬레이션과 계좌 비교가 쓰는 값** |

합계를 쓰는 이유는 같은 칸에 더해지는 다른 세금과 기준을 맞추기 위해서입니다 —
연금소득세 5.5·4.4·3.3% 와 기타소득세 16.5% 는 이미 지방소득세를 품은 세율입니다.
퇴직소득세만 국세로 두면 '총 예상 세액' 한 칸 안에서 기준이 갈립니다.

## 중간정산

| | 계산 |
|---|---|
| **분리 (원칙)** | 근속연수를 **정산일 다음 날부터** 세고, 최종 퇴직급여만으로 계산 |
| **정산특례 (§148)** | 중간정산분과 합산하고 근속연수도 **입사일부터** 통산한 뒤, 중간정산 때 낸 세액을 **기납부세액으로 공제** |

대개 정산특례가 유리하지만 합산으로 과세표준 구간이 올라가면 뒤집힙니다.
**단정하지 않고 둘 다 계산해** 유리한 쪽을 표시합니다. 정산특례는 퇴직자가
원천징수의무자에게 신고해야 적용되므로 그 점도 함께 안내합니다.

## 파일

| 경로 | 역할 |
|---|---|
| `rules.js` | 공제표·세율표를 조문과 함께 **자료로**. 세법이 바뀌면 여기만 고칩니다 |
| `crosscheck.js` | 격자를 화면에 돌려 규칙표 계산과 대조 |

**화면(`app.jsx`)은 `rules.js` 를 가져다 쓰지 않습니다.** 같은 산식을 스스로 한 번 더
씁니다. 합치면 crosscheck 가 자기 자신을 비교하는 꼴이 되어 검산이 사라집니다.
세율표는 한 자리 틀려도 숫자가 그럴듯하게 나오고 그대로 고객에게 나갑니다.

```bash
node scripts/build-retirement-simulator.js
node tools/retirement-tax/crosscheck.js
```

격자는 **공제표가 바뀌는 자리를 반드시 지납니다** — 근속연수 5·10·20년, 환산급여
800만·7,000만·1억·3억원, 세율 구간 경계. 그리고 각 근속연수마다 **정확히 n년**과
**n년 + 1일**을 모두 넣습니다. 정확히 떨어지는 날짜만 쓰면 절상 코드를 통째로 빼도
거의 드러나지 않습니다 (실제로 그런 상태였고 음성 대조에서 드러났습니다).

## 하지 않는 것

- **임원 퇴직소득 한도**(§22③) 초과분의 근로소득 전환 — 임원 여부와 3년 평균보수가 필요합니다
- **2023.1.1 이후 퇴직분** 공제표만 적용합니다. 그 전 퇴직분은 표가 다릅니다
- 비과세 퇴직급여는 **입력받을 뿐** 무엇이 비과세인지 판단하지 않습니다
- 중간정산이 여러 번이면 가장 최근 1회만 받습니다
- 최종값은 **원천징수영수증으로 확인**해야 합니다. 회사가 잡는 퇴직급여액·근속기간이
  상담 입력과 다를 수 있습니다
