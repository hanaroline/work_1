보유자산 통합 브리핑 — 사용법 및 유의사항

검은 창(로컬 서버)을 켜고 브라우저로 시세를 조회하는 대시보드 · 최종 업데이트 2026-10-04

1준비 — 한 폴더에 모아두기

아래 핵심 파일 3개가 반드시 같은 폴더 안에 있어야 합니다.

파일이름 정확도역할
server.ps1정확히 일치시세를 받아오는 로컬 서버(엔진)
briefing.html정확히 일치메인 화면(대시보드)
서버실행 (브리핑 자동열림).bat이름 자유실행 버튼

★ server.ps1 과 briefing.html 두 이름은 글자 하나도 틀리면 안 됩니다. (연금 사용 시 search2.html도 같은 폴더에)

2실행 방법 (평소 사용)

1
.bat 더블클릭
서버실행 (브리핑 자동열림)
›
2
검은 창 자동 최소화
작업표시줄로 내려감
›
3
브리핑 화면 자동 열림
브라우저에 표시
참고
화면만 다시 열고 싶을 땐(검은 창은 켜진 상태) 브리핑 열기 바로가기, 또는 브라우저에 http://localhost:8899/ 직접 입력.

3종료 방법

  • 작업표시줄의 "Mirae local server" 항목 클릭 → 창이 올라오면 닫기(X)
  • 창을 닫으면 서버가 꺼져 시세 조회가 멈춥니다. (브라우저 화면만 닫는 건 종료가 아님)

4유의사항 (꼭 지키기)

가장 흔한 오류

파일 이름 뒤의 " (2)", " (3)" 주의

같은 파일을 여러 번 내려받으면 윈도우가 이름 뒤에 (2), (3)을 붙입니다. 예) server (2).ps1, briefing (3).html

그러면 실행기가 server.ps1을 못 찾아 "server.ps1 was NOT found" 오류가 납니다.

해결 — 파일 우클릭 → 이름 바꾸기(F2)로 뒤의 (숫자)를 지워 정확한 이름으로 맞추기.
예방 — 새로 받기 전에 폴더의 기존 파일을 먼저 지우고 받으면 숫자가 안 붙습니다.

항목내용
다운로드 차단 해제(MOTW)받은 .bat/.ps1은 회사 PC가 막을 수 있음 → 파일 우클릭 → 속성 → "차단 해제" → 확인
검은 창은 열어둔 채 사용검은 창 = 시세 엔진. 닫으면 시세가 멈춤 → 최소화해서 작업표시줄에 두기
시세가 안 나오면서버가 꺼졌거나 회사망 문제 → 작업표시줄에서 서버 확인, 없으면 재실행
고객정보 입력 금지고객 실명·계좌번호는 화면에 입력·저장하지 않음

5자주 겪는 문제 → 해결

증상원인해결
"server.ps1 was NOT found"이름에 (2)/(3) 붙음이름에서 (숫자) 지우기 → server.ps1
검은 창이 아예 안 뜸다운로드 차단(MOTW)우클릭 → 속성 → 차단 해제
브라우저 "연결할 수 없음"서버가 안 켜짐실행기 다시 더블클릭 / 주소 직접 입력
화면은 뜨는데 시세 빈칸서버 종료·회사망작업표시줄에서 서버 확인 후 재실행
브라우저가 자동으로 안 열림자동열기 지연·차단주소창에 http://localhost:8899/ 입력

6화면 간단 안내

  • 보유자산·수익률: 한 화면에서 조회
  • 수익률 상위(스크리너): 기간별 수익률 상위 종목 조회 — 국내주식 = 시장 전체 실시간 / 국내ETF = 거래소 실시간 + 대표 56종 / 해외·펀드 = 대표 프리셋
  • 연금 상품조회 버튼: 연금 화면(search2.html)으로 이동
  • 화면 상단 버전 표기 예: v2026.10.03-1

구분파일
