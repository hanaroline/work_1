빌드 도구 없이 HTML 파일만으로 동작하는 조회 화면 모음입니다.

| 화면 | 파일 | 내용 |
|------|------|------|
| **종목 통합 리포트** | `index.html` / `standalone.html` | 종목 하나의 시세·투자의견·뉴스·재무제표를 한 장의 리포트로 |
| **금융상품 통합조회** | `products.html` / `products-standalone.html` | 펀드·ETF·ELS·채권·RP·랩/신탁·연금 전 상품군 검색·필터·비교 |

# 1. 종목 통합 리포트 대시보드

주식 종목명 또는 종목코드를 입력하면 해당 종목의 **시세 · 증권사 투자의견/레포트 · 시황(뉴스) · 재무제표**를
**한 장의 리포트**처럼 보여주는 단일 HTML 대시보드입니다. 빌드 도구 없이 `index.html` 하나로 동작합니다.

## 화면 구성

| 섹션 | 내용 |
|------|------|
| **종목 요약** | 종목명·코드·시장(KOSPI/KOSDAQ), 현재가·등락, 시가총액, PER/PBR/EPS, **조회 기준 시각** |
| **시세 · 기술적지표** | 가격 차트(1M/3M/6M/1Y) + **이동평균 MA5/20/60** + **RSI(14)** + 거래량, 52주 최고/최저, **지수 대비 초과수익률** |
| **외국인 · 기관 수급** | 일별 순매수 대금(외국인/기관) 차트 + 외국인 지분율 추이, 5일/20일 누적 순매수 |
| **증권사 투자의견** | 목표주가 밴드(최저·평균·최고 vs 현재가), 상승여력, 매수/중립/매도 의견분포, 최근 레포트 목록 |
| **시황 · 뉴스** | 종목 관련 최신 뉴스 헤드라인 |
| **재무제표** | 연간 손익(매출·영업이익·순이익) 차트 + 표, 재무상태(자산·부채·자본), ROE·부채비율 |

### 주요 기능
- **관심종목 즐겨찾기(★)** — 브라우저에 저장(localStorage), 상단 칩에서 원클릭 조회
- **종목 비교(⇄)** — 최대 4종목을 기준=100 리베이스 차트 + 지표 표로 비교
- **지수 대비 보기** — 가격/지수대비(KOSPI·KOSDAQ 리베이스) 토글, 초과수익률 표시
- **PDF 저장/출력(🖨)** — 화면 그대로 A4 리포트로 저장·인쇄(`@media print`)
- 라이트/다크 테마 전환(◐), 종목명 자동완성, 6자리 코드 직접 입력

## 실행 방법

### 방법 1) 단일 파일 (가장 간단)

`standalone.html` **한 파일**에 CSS·JS·차트 라이브러리·데이터가 모두 인라인되어 있습니다.
별도 서버 없이 파일을 브라우저로 열기만 하면(더블클릭) 바로 동작합니다.

```
standalone.html  ← 이 파일만 열면 됨
```

### 방법 2) 분리 파일 + 로컬 서버 (개발용)

`index.html`은 `data/*.js`, `vendor/*.js`를 외부에서 로드하므로 로컬 서버로 열어야 합니다
(파일 프로토콜로 열면 브라우저 보안정책에 막힐 수 있음).

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> `standalone.html`은 `index.html` + `data/*.js` + `vendor/chart.umd.js`를 합쳐 생성한 산출물입니다.
> 소스를 수정할 때는 `index.html` / `data/*.js`를 고친 뒤 다시 합치면 됩니다.

## 데이터 소스

무료 공개 소스를 우선 사용하고, 실패 시 **섹션별로 샘플 데이터로 폴백**합니다.
각 섹션에는 `실시간` / `샘플` 배지가 표시됩니다.

| 섹션 | 실시간 소스 | 폴백 |
|------|-------------|------|
| 시세/현재가/차트 | **네이버 모바일 `m.stock.naver.com/api`** 우선, Yahoo `chart` 보조 | 내장 샘플 |
| 외국인/기관 수급 | 네이버 `api/stock/{code}/trend` | 내장 샘플 |
| 지수(KOSPI/KOSDAQ) | Yahoo `chart/^KS11 · ^KQ11` | 내장 샘플 |
| 재무제표 | Yahoo `quoteSummary` (손익/재무상태) | 내장 샘플 |
| 투자의견/목표주가 | Yahoo `quoteSummary` (financialData, recommendationTrend) | 내장 샘플 |
| 시황/뉴스 | Google News RSS(`news.google.com/rss/search`) | 내장 샘플 |
| 증권사 레포트 목록 | (실시간 API 부재) | 예시 데이터 + 네이버 리서치 딥링크 |

모든 소스는 **병렬 호출 + 4초 타임아웃**으로 요청하며, 실패한 섹션만 개별적으로 샘플로 대체합니다(전체 화면은 항상 정상 렌더). 요약 헤더에 조회 기준 시각과 출처가 표시됩니다.

> 증권사 원문 리포트(PDF)는 공개 API가 없어, 목록은 예시로 채우고
> [네이버 금융 리서치](https://finance.naver.com/research/)로 연결되는 딥링크를 제공합니다.

### 브라우저 CORS 안내

순수 브라우저(단일 HTML)에서 위 API를 직접 호출하면 **CORS로 차단**되는 경우가 많습니다.
이를 위해 `index.html`의 `PROXIES` 배열에 **CORS 프록시 폴백**이 설정되어 있습니다.

```js
var PROXIES = [
  function (u) { return u; },                                              // 1) 직접 호출
  function (u) { return "https://corsproxy.io/?url=" + encodeURIComponent(u); },      // 2) 프록시
  function (u) { return "https://api.allorigins.win/raw?url=" + encodeURIComponent(u); } // 3) 프록시
];
```

- 사내망/폐쇄망 등으로 외부 접근이 막히면 세 경로 모두 실패하고 **샘플 데이터**로 표시됩니다(화면은 항상 정상 렌더).
- 안정적인 실시간 연동이 필요하면, 자체 백엔드 프록시(예: `/api/proxy?url=...`)를 만들어 `PROXIES`에 추가하는 것을 권장합니다.
- 미래에셋 **사내 API**가 있다면 `fetchYahoo` / `fetchNews`를 사내 엔드포인트 호출로 교체하면 됩니다.

# 2. 금융상품 통합조회

미래에셋증권 홈페이지의 **금융상품 전 라인업을 한 화면에서 검색·필터·비교**하는 조회 화면입니다.
증권사 상품몰 / ETF 스크리너 / 펀드 평가사 화면의 공통 패턴(통합검색 → 상품군 탭 → 좌측 필터 → 결과 표 →
상세 패널 → 비교)을 따르고, 미래에셋 디자인 기준(오렌지 `#F58220` / 블루 `#043B72`, 1px 오렌지 섹션 룰,
`#FAB072` 표 헤더)을 적용했습니다.

## 화면 구성

위에서 아래로 **검색 → 요약 → 좁히기 → 결과 → 상세/비교** 순으로 배치해, 조회 목적이 뚜렷한 사용자는
검색 한 번으로, 둘러보는 사용자는 탭·필터로 도달하도록 했습니다.

| 영역 | 내용 |
|------|------|
| **헤더** | 한/영(KO·EN) 토글, CSV 저장, 인쇄, 종목 리포트 화면 링크 |
| **통합검색** | 상품명·상품코드·운용사/발행사·기초자산을 한 입력창에서 검색 + **자동완성 8건** |
| **빠른 조건** | 청약 진행중 / 마감 7일 이내 / 저위험(4~6등급) / 절세계좌 편입 / 온라인 전용 / 1년 수익률 상위 |
| **요약 지표** | 조회 결과 건수, 모집·청약중, 마감임박, 평균 1년 수익률, 관심상품 |

| **청약·모집 캘린더** | 기간이 정해진 상품(ELS/DLS 등)을 마감 임박순(D-)으로 8건 |

### 주요 기능
- **한/영 토글** — 우상단 KO/EN, 라벨·단위·날짜·상품명까지 전부 영문 전환, localStorage로 선택 유지

- **접근성** — 키보드 조작, `role="radiogroup"`/`tablist`, 차트 `aria-label`, WCAG AA 대비
- **반응형** — 데스크탑 2단 → 태블릿 필터 접기 → 모바일 1단(표는 가로 스크롤)

## 실행 방법

### 방법 1) 실행파일 — 실데이터가 들어오는 유일한 확실한 방법 ★

브라우저가 KRX 를 직접 호출하면 **CORS 로 막힙니다.** `serve-products.py` 는 파이썬이
**서버 대 서버**로 KRX 를 호출해 주기 때문에 CORS 가 아예 발생하지 않습니다.

| 환경 | 실행 |
|------|------|
| **윈도우** | `run-products.bat` **더블클릭** |
| macOS / Linux | `./run-products.sh` |
| 직접 실행 | `python serve-products.py` |

실행하면 로컬 서버가 뜨고 브라우저가 자동으로 열립니다. 설치할 패키지는 없습니다
(파이썬 표준 라이브러리만 사용). 종료는 실행 창에서 `Ctrl+C`.

```bash
python serve-products.py                # 서버 실행 + 브라우저 자동 열기
python serve-products.py --port 9000    # 포트 지정
python serve-products.py --check        # KRX 연결만 점검 (응답 키까지 출력)
python serve-products.py --snapshot     # 실데이터를 파일로 저장 (오프라인용)
python serve-products.py --krx-url ...  # 사내 프록시 경유
```

연결이 안 되면 `--check` 를 먼저 실행하세요. 실패 사유와 **KRX 응답 키 목록**을 그대로 출력합니다.
사내망 프록시가 필요하면 환경변수 `HTTPS_PROXY` 를 설정하거나 `--krx-url` 을 쓰면 됩니다.

### 방법 2) 오프라인 실데이터 (스냅샷)

망이 연결되는 곳에서 한 번 저장해 두면, 이후에는 **서버 없이 파일 더블클릭으로도** 실데이터가 보입니다.

```bash
python serve-products.py --snapshot        # data/krx-snapshot.js 생성
python build-products-standalone.py        # 스냅샷을 포함한 단일 파일 재생성
# 이제 products-standalone.html 을 더블클릭하면 저장된 실데이터로 조회된다
```

스냅샷은 **원본 응답을 그대로** 담고 파싱은 화면이 담당하므로, 실시간 조회와 결과가 동일합니다.
출처 바에는 `KRX 스냅샷 2026-08-05 14:22` 처럼 저장 시각이 표시됩니다.

### 방법 3) 단일 파일만 열기 (실데이터 없이 화면만)

`products-standalone.html` 더블클릭. 화면 구성·조작은 모두 확인할 수 있지만
KRX 호출은 CORS 로 막혀 **예시 데이터로 표시**됩니다(스냅샷이 포함돼 있으면 실데이터).

```bash
# 소스를 고친 뒤 단일 파일 다시 생성
python3 build-products-standalone.py
```

## 파일 구조

```
serve-products.py              # 실행파일: 로컬 서버 + KRX 서버측 호출(CORS 회피) + 스냅샷 생성
run-products.bat               # 윈도우 실행 런처 (더블클릭)

products.html                  # 화면 (레이아웃 + CSS + 앱 로직)

```

## 데이터 출처 (중요)

화면은 **상품군별로 실데이터인지 예시인지를 항상 표시합니다.** 히어로 아래 출처 바에
`실데이터 / 공개 소스 없음 / 연결 실패` 와 건수·출처 링크가 그대로 노출되고, 예시 데이터는
건수 앞에 `예시` 가 붙습니다. 임의 생성한 수치에 "실제" 라벨을 붙이지 않는 것이 이 화면의 원칙입니다.

### 실데이터 연동됨 — KRX 정보데이터시스템 공개 엔드포인트

| 상품군 | 엔드포인트 | 받는 항목 |
|--------|-----------|-----------|
| ETF | `MDCSTAT04601` 전종목 기본정보 | 종목명·코드·기초지수·운용사·상장일 |
| ETF | `MDCSTAT04301` 전종목 시세 | 종가·NAV·순자산총액·거래량 |
| ETF | `MDCSTAT04401` 전종목 등락률 | **실제 기간 수익률** 1M/3M/6M/1Y |
| ETF | `MDCSTAT04501` 개별종목 시세 | 일별 시계열 (상세 패널 열 때 지연 조회) |
| ETN | `MDCSTAT06701` / `MDCSTAT06401` | 기본정보 / 시세 |
| 채권 | `MDCSTAT09801` 전종목 시세 | 종목명·종가·매매수익률 |

요청은 `POST https://data.krx.co.kr/comm/bldAttendant/getJsonData.cmd` (form body `bld=...`).
엔드포인트 ID와 파라미터명은 [pykrx](https://github.com/sharebook-kr/pykrx) 에 공개된 KRX 메뉴
카탈로그(`path_bld_information.json`)에서 확인한 값입니다.

### 실데이터 연동 불가 — 공개 API가 존재하지 않음

| 상품군 | 사유 |
|--------|------|
| 펀드 수익률·보수 | 금융투자협회 전자공시(dis.kofia.or.kr) 공개 API 없음 |
| ELS·DLS 회차별 조건 | 발행사 홈페이지에만 존재, 공개 API 없음 |
| RP·CMA 금리 | 발행사 홈페이지에만 존재, 공개 API 없음 |
| 랩·신탁 | 공개 소스 없음 |
| 위험등급·세제혜택·판매채널 | 투자설명서 항목으로 KRX 공개데이터에 없음 (실데이터 행에서 `—` 로 표시) |

이 항목들은 **사내 상품 API 또는 CSV 임포트**로만 채울 수 있습니다. 값이 없으면 비워 두고,
추정해서 채우지 않습니다.

### 사내 데이터 넣는 방법

**1) CSV 임포트 (별도 개발 없이 즉시)** — 상단 `사내 데이터 올리기(CSV)` 버튼.
헤더는 한/영 모두 인식하고, 올린 상품군만 교체됩니다.

```csv
상품군,상품명,상품코드,운용사,위험등급,총보수,1년,최소가입금액,세제혜택
펀드,미래에셋 코어테크 증권자투자신탁,K99001,미래에셋자산운용,2,1.25,14.8,100,isa;pension
ELS,미래에셋증권 제99001회 ELS,S99001,미래에셋증권,1,,,100,
```

인식하는 컬럼은 `data/sources.js` 의 `CSV_MAP` 에 정의되어 있습니다. `상품명` 은 필수입니다.

**2) 사내 API 어댑터** — `data/sources.js` 의 `CATALOG` 에 항목을 추가합니다.
`run(asOfDate)` 이 MASP 스키마 배열을 반환하면 나머지(필터·정렬·표·상세·비교)는 그대로 동작합니다.

**3) 실행파일로 CORS 우회 (권장)** — `run-products.bat` / `python serve-products.py` 로 실행하면
파이썬이 서버 대 서버로 KRX 를 호출하므로 CORS 가 발생하지 않습니다. 화면은 로컬 프록시
`/api/krx` 를 자동으로 우선 사용합니다. 사내 프록시를 직접 넣고 싶으면
`data/sources.js` 의 `PROXIES` 맨 앞에 추가하세요.

```js
PROXIES.unshift({ name: '사내 프록시', wrap: function (u) { return '/api/proxy?url=' + encodeURIComponent(u); } });
```

### 조회가 실패하면

화면은 **항상 렌더됩니다.** 실데이터 조회가 실패한 상품군은 예시 데이터로 표시되고,
상단 `데이터 진단` 버튼을 누르면 엔드포인트별 실패 사유(HTTP 상태, CORS, 타임아웃, 응답 키 불일치)가
그대로 나옵니다. KRX 출력 필드명은 메뉴마다 달라서 후보 키를 여러 개 두고 매칭하며,
전부 실패하면 진단 패널에 **실제 응답 키 목록**을 찍어 주므로 `data/sources.js` 의 `K` 매핑만
고치면 됩니다.

> 참고: 개발 컨테이너 등 외부 망이 차단된 환경에서는 KRX 호출이 모두 실패하고 예시 데이터로
> 표시되는 것이 정상입니다. 사내망/사내 PC 에서 열어야 실데이터가 들어옵니다.

## 화면 로직 확장

- 필터를 추가·변경할 때는 `MASP.FILTER_SCHEMA` 에 항목만 추가하면 좌측 패널이 자동 렌더됩니다
  (`chips` = 다중선택, `range` = 최소/최대)
- 표 컬럼 구성은 `products.html` 의 `COLS` / `C` 정의에서 상품군별로 조정합니다
- 새 문자열은 `MASP.I18N`(또는 `products.html` 의 `EXTRA`)에 `[한국어, English]` 쌍으로 추가합니다

## 유의사항

본 화면은 정보 제공 목적의 참고 자료이며, 투자 판단과 그 결과에 대한 책임은 이용자에게 있습니다.
금융상품 통합조회 화면에서 `실데이터` 로 표시된 상품군(ETF·ETN·채권)은 KRX 공개데이터를 조회한
값이며, `예시` 로 표시된 상품군(펀드·ELS·RP·랩/신탁·연금)의 상품명·수익률·조건은 화면 검증용으로
생성된 값으로 실제 판매 상품 정보가 아닙니다. 어느 쪽인지는 화면 상단 출처 바에서 항상 확인할 수 있습니다.
