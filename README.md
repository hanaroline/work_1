# 종목 통합 리포트 대시보드

주식 종목명 또는 종목코드를 입력하면 해당 종목의 **시세 · 증권사 투자의견/레포트 · 시황(뉴스) · 재무제표**를
**한 장의 리포트**처럼 보여주는 단일 HTML 대시보드입니다. 빌드 도구 없이 `index.html` 하나로 동작합니다.

> 이 저장소에는 **매일 아침 자동 생성되는 증시시황 브리핑**도 함께 들어 있습니다 →
> [`briefing/index.html`](briefing/index.html) · 설명은 아래 [아침 증시시황 브리핑](#아침-증시시황-브리핑-briefing) 참고

## 화면 구성

| 섹션 | 내용 |
|------|------|
| **종목 요약** | 종목명·코드·시장(KOSPI/KOSDAQ), 현재가·등락, 시가총액, PER/PBR/EPS, **조회 기준 시각** |
| **시세 · 기술적지표** | 가격 차트(1M/3M/6M/1Y) + **이동평균 MA5/20/60** + **RSI(14)** + 거래량, 52주 최고/최저, **지수 대비 초과수익률** |
| **외국인 · 기관 수급** | 일별 순매수 대금(외국인/기관) 차트 + 외국인 지분율 추이, 5일/20일 누적 순매수 |
| **증권사 투자의견** | 목표주가 밴드(최저·평균·최고 vs 현재가), 상승여력, 매수/중립/매도 의견분포, 최근 레포트 목록 |
| **시황 · 뉴스** | 종목 관련 최신 뉴스 헤드라인 |
| **재무제표** | 연간 손익(매출·영업이익·순이익) 차트 + 표, 재무상태(자산·부채·자본), ROE·부채비율 |

### 주요 기능
- **관심종목 즐겨찾기(★)** — 브라우저에 저장(localStorage), 상단 칩에서 원클릭 조회
- **종목 비교(⇄)** — 최대 4종목을 기준=100 리베이스 차트 + 지표 표로 비교
- **지수 대비 보기** — 가격/지수대비(KOSPI·KOSDAQ 리베이스) 토글, 초과수익률 표시
- **PDF 저장/출력(🖨)** — 화면 그대로 A4 리포트로 저장·인쇄(`@media print`)
- 라이트/다크 테마 전환(◐), 종목명 자동완성, 6자리 코드 직접 입력

## 실행 방법

### 방법 1) 단일 파일 (가장 간단)

`standalone.html` **한 파일**에 CSS·JS·차트 라이브러리·데이터가 모두 인라인되어 있습니다.
별도 서버 없이 파일을 브라우저로 열기만 하면(더블클릭) 바로 동작합니다.

```
standalone.html  ← 이 파일만 열면 됨
```

### 방법 2) 분리 파일 + 로컬 서버 (개발용)

`index.html`은 `data/*.js`, `vendor/*.js`를 외부에서 로드하므로 로컬 서버로 열어야 합니다
(파일 프로토콜로 열면 브라우저 보안정책에 막힐 수 있음).

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> `standalone.html`은 `index.html` + `data/*.js` + `vendor/chart.umd.js`를 합쳐 생성한 산출물입니다.
> 소스를 수정할 때는 `index.html` / `data/*.js`를 고친 뒤 다시 합치면 됩니다.

## 데이터 소스

무료 공개 소스를 우선 사용하고, 실패 시 **섹션별로 샘플 데이터로 폴백**합니다.
각 섹션에는 `실시간` / `샘플` 배지가 표시됩니다.

| 섹션 | 실시간 소스 | 폴백 |
|------|-------------|------|
| 시세/현재가/차트 | **네이버 모바일 `m.stock.naver.com/api`** 우선, Yahoo `chart` 보조 | 내장 샘플 |
| 외국인/기관 수급 | 네이버 `api/stock/{code}/trend` | 내장 샘플 |
| 지수(KOSPI/KOSDAQ) | Yahoo `chart/^KS11 · ^KQ11` | 내장 샘플 |
| 재무제표 | Yahoo `quoteSummary` (손익/재무상태) | 내장 샘플 |
| 투자의견/목표주가 | Yahoo `quoteSummary` (financialData, recommendationTrend) | 내장 샘플 |
| 시황/뉴스 | Google News RSS(`news.google.com/rss/search`) | 내장 샘플 |
| 증권사 레포트 목록 | (실시간 API 부재) | 예시 데이터 + 네이버 리서치 딥링크 |

모든 소스는 **병렬 호출 + 4초 타임아웃**으로 요청하며, 실패한 섹션만 개별적으로 샘플로 대체합니다(전체 화면은 항상 정상 렌더). 요약 헤더에 조회 기준 시각과 출처가 표시됩니다.

> 증권사 원문 리포트(PDF)는 공개 API가 없어, 목록은 예시로 채우고
> [네이버 금융 리서치](https://finance.naver.com/research/)로 연결되는 딥링크를 제공합니다.

### 브라우저 CORS 안내

순수 브라우저(단일 HTML)에서 위 API를 직접 호출하면 **CORS로 차단**되는 경우가 많습니다.
이를 위해 `index.html`의 `PROXIES` 배열에 **CORS 프록시 폴백**이 설정되어 있습니다.

```js
var PROXIES = [
  function (u) { return u; },                                              // 1) 직접 호출
  function (u) { return "https://corsproxy.io/?url=" + encodeURIComponent(u); },      // 2) 프록시
  function (u) { return "https://api.allorigins.win/raw?url=" + encodeURIComponent(u); } // 3) 프록시
];
```

- 사내망/폐쇄망 등으로 외부 접근이 막히면 세 경로 모두 실패하고 **샘플 데이터**로 표시됩니다(화면은 항상 정상 렌더).
- 안정적인 실시간 연동이 필요하면, 자체 백엔드 프록시(예: `/api/proxy?url=...`)를 만들어 `PROXIES`에 추가하는 것을 권장합니다.
- 미래에셋 **사내 API**가 있다면 `fetchYahoo` / `fetchNews`를 사내 엔드포인트 호출로 교체하면 됩니다.

## 파일 구조

```
index.html            # 대시보드 (레이아웃 + CSS + 앱 로직)
vendor/chart.umd.js   # Chart.js 4.4.1 로컬 번들 (CDN 차단 환경 대비, 실패 시 CDN 폴백)
data/tickers.js       # 종목명↔코드↔시장 매핑 + 조회 함수
data/sample.js        # 샘플/폴백 데이터 생성기 (종목코드 시드 기반 결정적 생성)
```

## 종목 추가

`data/tickers.js`의 `TICKERS` 배열에 `{ code, name, market, aliases }` 항목을 추가하면
자동완성·조회에 반영됩니다. 미등록 종목도 6자리 코드로 조회할 수 있습니다.

# 아침 증시시황 브리핑 (`briefing/`)

매일 아침(평일 07:40 KST) 국내외 시황을 자동으로 수집·교차확인해
**고객에게 바로 브리핑할 수 있는 한 장짜리 HTML 리포트**를 생성합니다.

| 파일 | 내용 |
|------|------|
| `briefing/index.html` | **최신 브리핑** (가장 최근 일자) |
| `briefing/YYYY-MM-DD.html` | 일자별 브리핑 |
| `briefing/archive.html` | 일자 목록 |
| `briefing/data/YYYY-MM-DD.json` | 브리핑 원본 데이터 (수치 + 출처) |

## 브리핑 구성

| 섹션 | 내용 |
|------|------|
| **한눈에 보는 핵심** | 수치로 시작하는 핵심 5~6줄 — 그대로 읽어도 브리핑이 되는 문장 |
| **국내 증시** | 코스피·코스닥·주요 대형주 종가/등락 + 급등락의 원인 해석 |
| **수급** | 외국인·기관 순매수 금액, 종목별 집중도, 레버리지 상품 왜곡 요인 |
| **업종 · 종목 흐름** | 주도 업종 교체 여부, 개별 종목 코멘트 |
| **글로벌 증시** | 뉴욕 3대 지수 등락률 바 차트 + 표, 아시아·유럽 흐름 |
| **금리 · 환율 · 원자재** | 원/달러, 미 국채 10년물, WTI·브렌트 + 인과 사슬 해석 |
| **증권사 · 글로벌 하우스 시각** | 국내 증권가 종합 / 해외 하우스 / 해외 매체 / 정책 당국 — 반대 시각 포함 |
| **오늘의 일정 · 체크포인트** | 시각별 일정 + *무엇을 확인하면 판단이 되는지* |
| **리스크 점검** | 당일 기준 리스크 5개 |
| **고객 응대 포인트** | 실제 고객 질문 형태의 Q&A + 행동 지침 |
| **출처** | 모든 수치의 원문 링크 (고객 안내 전 확인용) |

한/영 토글, 인쇄(PDF 저장) 레이아웃, 모바일 반응형을 지원하며
미래에셋 디자인 시스템(오렌지 `#F58220` / 블루 `#043B72`, 1px 섹션 룰, `#FAB072` 표 헤더)을 따릅니다.
등락 색은 국내 관행대로 **상승 적색 / 하락 청색**입니다.

## 데이터 수집 방식

이 저장소가 도는 환경은 **직접 HTTP 호출이 프록시에서 차단**됩니다(금융 API 를 코드로 못 부름).
따라서 수집은 Claude 의 웹 검색 채널을 통해 이뤄지고, 다음 원칙을 강제합니다.

- **확인되지 않은 수치는 비워 둡니다.** (`—` 로 표시) 추정치를 채우지 않습니다.
- 지수 종가·등락률·수급 금액은 **서로 다른 언론사 2곳 이상 교차 확인**합니다.
- 검색 요약이 제시한 밴드·목표치는 기사 본문에서 확인되지 않으면 **버립니다**.
- 오피니언 칼럼과 하우스 투자의견을 **구분 표기**합니다.
- 휴장일 등으로 마감 수치를 확인할 수 없으면 **빈 브리핑을 만들지 않습니다.**

## 수동 실행

```bash
# 1) 수집 + JSON 작성  — Claude Code 에서
/market-briefing

# 2) JSON 만 있으면 렌더링은 오프라인으로 가능
python3 scripts/render_briefing.py briefing/data/2026-08-04.json
python3 scripts/render_briefing.py --all      # 전체 재생성
python3 scripts/render_briefing.py --schema   # JSON 스키마 확인
```

수집·작성 절차와 품질 기준은 [`.claude/skills/market-briefing/SKILL.md`](.claude/skills/market-briefing/SKILL.md) 에 정의되어 있습니다.
`scripts/render_briefing.py` 는 **네트워크를 쓰지 않는 순수 렌더러**라 언제든 재실행해도 결과가 동일합니다.

## 유의사항

브리핑은 공개된 시장 정보와 언론 보도를 자동 수집·요약한 **정보 제공 목적의 참고 자료**입니다.
특정 종목의 매매를 권유하지 않으며, 수치는 원출처 기준으로 정정·재집계될 수 있습니다.
**고객 안내 전 출처 섹션의 원문을 확인하십시오.**
