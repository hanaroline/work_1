# 부서 자료실

부서 공유 폴더에 쌓이는 자료를 **분류별로 정리해서 보여주는 단일 HTML 포털**입니다.
서버도, 계정도, 인터넷 연결도 필요 없습니다. 폴더를 공유 드라이브에 두고
`자료실.html` 을 더블클릭하면 됩니다.

접근 권한은 **공유 폴더의 권한이 그대로 통제**합니다. 부서 보안그룹에 폴더 권한을 주면
그 부서원만 열 수 있고, 외부 사람은 폴더 자체에 접근할 수 없습니다.

---

## 폴더 구조

```
부서자료실/
├─ 자료실.html        ← 이 파일을 더블클릭해서 엽니다
├─ _목록갱신.cmd      ← 목록을 다시 만들 때 더블클릭 (Windows)
├─ _목록갱신.ps1      ← 위 cmd 가 실행하는 실제 스크립트
├─ _목록갱신.py       ← 같은 기능의 Python 버전 (Mac / Linux)
└─ 자료/
   ├─ 01_리서치/
   ├─ 02_업무가이드/
   ├─ 03_회의자료/
   ├─ 04_데이터/
   └─ 05_교육자료/
```

---

## 쓰는 방법

### 1. 자료 추가

`자료/` 아래 해당 분류 폴더에 파일을 넣습니다. 형식 제한은 없습니다
(PDF, XLSX, PPTX, DOCX, HWP, CSV, HTML, 이미지 등).

분류 폴더 안에 하위 폴더를 만들어도 됩니다. 하위 폴더의 파일도 그 분류에 포함됩니다.

### 2. 목록 갱신

**Windows** — `_목록갱신.cmd` 를 더블클릭합니다.

**Mac / Linux** — 터미널에서 `python3 _목록갱신.py`

스크립트가 `자료/` 폴더를 훑어서 `자료실.html` 안의 목록을 다시 만듭니다.
자료를 추가하거나 지운 뒤에는 반드시 한 번 실행하세요.

### 3. 열기

`자료실.html` 을 더블클릭합니다. 분류별 목록에서 자료명을 누르면 파일이 열립니다.

---

## 분류 바꾸기

분류는 **폴더 이름이 곧 분류명**입니다. 별도 설정 파일이 없습니다.

- `자료/` 아래에 폴더를 만들면 새 분류가 생깁니다.
- 폴더 이름을 `01_리서치` 처럼 `숫자_이름` 으로 지으면, 숫자는 **정렬 순서**로만 쓰이고
  화면에는 `리서치` 만 표시됩니다.
- 숫자 없이 지어도 동작하며, 이 경우 이름순으로 뒤에 붙습니다.
- 분류 폴더 안에 `_설명.txt` 를 두면 **첫 줄**이 분류 설명으로 표시됩니다.

폴더 이름을 바꾸거나 순서를 조정한 뒤에도 목록 갱신을 한 번 실행하면 됩니다.

## 화면 기능

| 기능 | 설명 |
|------|------|
| 분류별 목록 | 분류마다 표로 정리. 자료명·형식·크기·수정일 표시 |
| 검색 | 자료명으로 실시간 필터링 |
| 정렬 | 최신순 / 이름순 / 용량순 |
| 분류 바로가기 | 상단 칩을 누르면 해당 분류로 이동 |
| 한/영 전환 | 우상단 KO / EN 버튼. 선택은 브라우저에 기억됨 |
| 인쇄 | 브라우저 인쇄로 목록을 PDF 저장 가능 |
| 모바일 | 좁은 화면에서는 표가 행 단위로 쌓여 표시됨 |

## 알아둘 점

**폴더를 통째로 옮기세요.** `자료실.html` 만 따로 복사하면 자료 링크가 전부 끊깁니다.
목록은 `자료/` 폴더 기준 상대경로로 연결되어 있습니다.

**목록은 자동으로 갱신되지 않습니다.** 브라우저는 보안 정책상 로컬 파일에서 폴더를
직접 읽지 못합니다. 그래서 목록을 HTML 안에 넣어두는 방식이며, 갱신 스크립트를
실행해야 반영됩니다.

**Office 파일은 다운로드됩니다.** 브라우저에서 XLSX·PPTX·DOCX 링크를 누르면
파일이 다운로드 폴더로 내려받아집니다. 원본을 직접 편집해야 할 때는 자료실 화면 대신
탐색기에서 공유 폴더의 파일을 여세요. PDF·HTML·이미지는 브라우저에서 바로 열립니다.

**임시 파일은 목록에서 제외됩니다.** `~$` 로 시작하는 Office 잠금 파일, 숨김 파일,
`.tmp` / `.lnk`, `Thumbs.db` 등은 자동으로 걸러집니다.

**한글·공백이 들어간 파일명도 그대로 씁니다.** 링크는 자동으로 URL 인코딩됩니다.

## 보안

- 이 폴더를 **부서 보안그룹 권한이 걸린 공유 드라이브**에 두세요.
  개인 클라우드나 외부 호스팅에 올리면 접근 통제가 사라집니다.
- 고객정보나 미공개 중요정보가 포함된 자료는 별도 승인 대상입니다.
  올리기 전에 정보보호팀 기준을 확인하세요.
- 이 폴더를 git 저장소에 함께 두는 경우, `자료/.gitignore` 가 실제 자료 파일의
  커밋을 막습니다. 저장소에는 폴더 구조와 `_설명.txt` 만 남습니다.
