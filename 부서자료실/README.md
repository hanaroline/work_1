# 부서 자료실

부서에서 만든 자료를 **분류별로 정리해 보여주는 단일 HTML 포털**입니다.
서버도 계정도 인터넷 연결도 필요 없습니다. `자료실.html` 을 브라우저로 열면 됩니다.

접근 권한은 **자료실이 놓인 곳의 권한이 그대로 통제**합니다.
저장소에 두면 저장소 권한이, 공유 드라이브에 두면 폴더 권한이 통제합니다.

---

## 부서원이 보는 방법

1. 저장소 첫 화면에서 **Code → Download ZIP**
2. 압축을 풀고 `부서자료실/자료실.html` 을 더블클릭
3. 분류별 목록에서 자료명을 누르면 해당 파일이 열립니다

> GitHub 웹 화면에서 `자료실.html` 을 직접 누르면 HTML 소스가 보입니다.
> GitHub이 저장소 안의 HTML을 렌더링해 주지 않기 때문이며, 위처럼 내려받아 열어야 합니다.

**저장소를 통째로 받으셔야 합니다.** 목록이 `../docs/briefings/...` 같은 상대경로로
연결되어 있어서, `자료실.html` 만 따로 저장하면 링크가 전부 끊깁니다.

## 지금 담겨 있는 것

| 분류 | 내용 | 원본 위치 |
|------|------|-----------|
| 시장 브리핑 | 일자별 모닝·장마감·해외 증시 브리핑 | `docs/briefings/` |
| 종목 대시보드 | 종목 통합 리포트 대시보드 단독 실행본 | `standalone.html` |
| 업무 가이드 | 브리핑 제작 플레이북, 사용 설명서 | `docs/`, 저장소 루트 |
| 시장 데이터 | 자동 수집한 일자별 시세 원본 | `data/market/` |
| 제작 소스 | 수집·생성 스크립트와 원본 파일 | `scripts/`, `data/` |

**자료를 복사해 오지 않습니다.** 원본을 제자리에 둔 채 목록에서만 연결하므로,
자동화가 새 브리핑을 만들면 사본이 낡을 걱정 없이 그대로 최신입니다.

## 목록 갱신

자료가 늘거나 줄면 목록을 다시 만들어야 합니다.

```bash
cd 부서자료실
python3 _목록갱신.py
```

`main` 브랜치에서는 **GitHub Actions 가 자동으로 처리**합니다
(`.github/workflows/archive-index.yml`). 브리핑이나 시세가 커밋되면 목록을 다시
만들고, 끊긴 링크가 있으면 커밋하지 않고 실패시킵니다.

## 분류 바꾸기

분류 정의는 **`분류.json`** 한 곳에 있습니다.

```json
{
  "name": "시장 브리핑",
  "desc": "일자별 모닝·장마감·해외 증시 브리핑 보관본",
  "sources": [
    {
      "path": "../docs/briefings",
      "include": ["*.html"],
      "date_from_name": "(\\d{4}-\\d{2}-\\d{2})",
      "rename": [["^(\\d{4}-\\d{2}-\\d{2})-morning$", "\\1 모닝 마켓 브리핑"]]
    }
  ]
}
```

| 항목 | 뜻 |
|------|-----|
| `path` | `자료실.html` 기준 상대 경로 |
| `include` / `exclude` | 포함·제외할 파일 패턴 (`*.html` 등) |
| `recursive` | 하위 폴더까지 훑을지 여부 |
| `files` | 파일을 콕 집어 넣을 때. `title` 로 표시 이름을 바꿉니다 |
| `rename` | `[정규식, 치환문자열]` 목록. 파일명을 읽기 좋은 제목으로 바꿉니다 |
| `date_from_name` | 파일명에서 날짜를 뽑아 '수정일' 로 씁니다 |

`date_from_name` 이 필요한 이유가 있습니다. git 으로 내려받으면 모든 파일의 날짜가
**내려받은 시각**이 되어버려서, 파일 날짜로는 최신순 정렬이 무의미해집니다.
날짜가 이름에 들어 있는 자료는 이 값을 쓰는 편이 정확합니다.

## 두 가지 동작 모드

`_목록갱신.py` 는 `분류.json` 이 있는지 보고 스스로 모드를 정합니다.

| 모드 | 조건 | 동작 |
|------|------|------|
| **설정 모드** | `분류.json` 있음 | 저장소 곳곳의 파일을 제자리에 둔 채 목록에만 모음 |
| **폴더 모드** | `분류.json` 없음 | `자료/` 아래 분류 폴더를 훑음 |

폴더 모드는 이 자료실을 **공유 드라이브에서 일반 문서함으로 쓸 때**를 위한 것입니다.
`자료/01_리서치/` 처럼 `NN_분류명` 폴더를 만들고 파일을 넣으면 됩니다. 숫자는 정렬
순서로만 쓰이고 화면에는 이름만 나옵니다. 분류 폴더에 `_설명.txt` 를 두면 첫 줄이
분류 설명이 됩니다.

### Windows 용 스크립트

`_목록갱신.cmd` (내부적으로 `_목록갱신.ps1` 실행) 는 **폴더 모드만** 지원합니다.
`분류.json` 이 있으면 잘못된 목록을 쓰는 대신 멈추고 Python 쪽을 안내합니다.

## 화면 기능

| 기능 | 설명 |
|------|------|
| 분류별 목록 | 자료명·형식·크기·수정일 |
| 검색 | 자료명으로 실시간 필터링 |
| 정렬 | 최신순 / 이름순 / 용량순 |
| 분류 바로가기 | 상단 칩을 누르면 해당 분류로 이동 |

| 인쇄 | 브라우저 인쇄로 목록을 PDF 저장 |
| 모바일 | 좁은 화면에서는 표가 행 단위로 쌓여 표시됨 |

한/영 전환은 화면 문구에 적용됩니다. 분류명과 자료명은 원본 그대로 둡니다.

## 알아둘 점

**목록은 저절로 갱신되지 않습니다.** 브라우저는 보안 정책상 로컬 파일에서 폴더를
직접 읽지 못합니다. 그래서 목록을 HTML 안에 넣어두는 방식이며, 갱신 스크립트를
돌려야 반영됩니다. `main` 브랜치는 Actions 가 대신 해줍니다.

**Office 파일은 다운로드됩니다.** 브라우저에서 XLSX·PPTX·DOCX 링크를 누르면 파일이
내려받아집니다. PDF·HTML·이미지·JSON 은 브라우저에서 바로 열립니다.

**임시 파일은 제외됩니다.** `~$` 로 시작하는 Office 잠금 파일, 숨김 파일, `.tmp`,
`.lnk`, `.pyc`, `Thumbs.db` 등은 자동으로 걸러집니다.

**한글·공백이 든 파일명도 그대로 씁니다.** 링크는 자동으로 URL 인코딩됩니다.

## 보안

- **저장소를 비공개(private)로 두고, 부서원을 Collaborator 로 초대**하십시오.
  공개 저장소에서는 이 자료가 인터넷 전체에 열립니다.
- GitHub Pages 를 켜면 **저장소가 비공개여도 페이지는 공개**됩니다
  (비공개 Pages 는 GitHub Enterprise Cloud 에서만 제공). 부서 전용으로 쓰실 거라면
  Pages 는 꺼두십시오.
- 고객정보나 미공개 중요정보가 담긴 자료는 외부 서비스에 올리기 전에 사내 승인이
  필요합니다. GitHub 은 사내 시스템이 아닙니다.
- 공유 드라이브에서 폴더 모드로 쓰실 경우, `자료/.gitignore` 가 실제 자료 파일의
  커밋을 막습니다. 저장소에는 폴더 구조와 `_설명.txt` 만 남습니다.
