## 다시 만들기

```bash
npm install pptxgenjs                       # 최초 1회
node docs/reports/build_work_report_deck.js "docs/reports/2026-09-09-업무자동화-구축결과보고.pptx"
```

텍스트·도형·차트가 모두 **편집 가능한 네이티브 요소**로 들어갑니다(이미지로 박은 슬라이드 없음).
브리핑 발행 실적 차트도 PowerPoint 네이티브 차트라 표를 열어 데이터를 직접 고칠 수 있습니다.
슬라이드마다 **발표 노트**가 붙어 있습니다.

### 확인해 두어야 할 두 가지

**① 기간의 앞쪽 — 6월.** 덱 표지는 `2026.06 – 09.09` 로 적었으나, 세션 기록으로
확인되는 작업은 **7월 9일부터**입니다. 6월은 별도 산출물 기록이 남아 있지 않아
2장에서 「도입 · 개별 요청 처리」 단계로만 적고, 각주에 그 사실을 밝혔습니다.
6월에 한 작업이 있으면 2장 1단계 설명과 표지 기간을 함께 고치면 됩니다.

**② 절감 약 60시간은 추정치입니다.** 시세 취합·작성·검증을 사람이 할 때 판당 60분으로
보고 발행 60판에 곱한 값이며, 실측이 아닙니다. 덱 7장 각주에도 같은 내용을 적었습니다.
