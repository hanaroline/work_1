# 업무 보고 자료

이 저장소에서 한 작업을 **위에 보고**하기 위한 발표 자료입니다.

| 파일 | 내용 |
|------|------|
| `2026-09-09-업무자동화-구축결과보고.pptx` | 5장 보고 덱 — 배경/접근 · 브리핑 자동화 성과 · 조회 화면 4종 · 정량 성과와 다음 단계 |
| `build_work_report_deck.js` | 위 덱을 만드는 생성기. 수치를 고치고 다시 돌리면 같은 서식으로 다시 나옵니다 |

## 다시 만들기

```bash
npm install pptxgenjs                       # 최초 1회
node docs/reports/build_work_report_deck.js "docs/reports/2026-09-09-업무자동화-구축결과보고.pptx"
```

텍스트·도형·차트가 모두 **편집 가능한 네이티브 요소**로 들어갑니다(이미지로 박은 슬라이드 없음).
주차별 발행 판수 차트도 PowerPoint 네이티브 차트라, 표를 열어 데이터를 직접 고칠 수 있습니다.
슬라이드마다 **발표 노트**가 붙어 있습니다.

## 서식 기준

미래에셋증권 디자인 시스템을 따릅니다 — 오렌지 `#F58220` / 블루 `#043B72`,
테이블 헤더 `#FAB072`, 1px 오렌지 섹션 룰, 국문 Spoqa Han Sans Neo.
차트 시리즈 색은 시리즈 1 = 오렌지 고정입니다.

## 실린 수치의 근거

덱의 숫자는 아래에서 직접 집계한 값입니다. 자료를 갱신할 때 같은 방법으로 다시 세면 됩니다.

| 수치 | 집계 방법 |
|------|-----------|
| 브리핑 60판 / 32일 | `docs/briefings/*.html` 중 `archive.html` 제외한 판 수와 서로 다른 날짜 수 |
| 구성 (모닝 24 · 장마감 13 · 핵심본 15 · 해외 8) | 같은 파일명의 접미사(`-morning` / `-close` / `-core` / `-global`) |
| 주차별 판수 | 파일명 날짜를 ISO 주차로 묶은 값. `9/07~` 은 9/7~9/9 3일치 |
| 워크플로 7종 | `.github/workflows/*.yml` |
| 하루 예약 2회 | `docs/briefing-playbook.md` 10절 (07:30 아침 · 16:10 장마감) |
| 작성 지침 1,870줄 | `wc -l docs/briefing-playbook.md` |
| 코드 25,400줄 | 뿌리 HTML 14,592줄 + `scripts/` 10,808줄 |
| 미국 100개 기업 | `us-top100.html` 의 `COMPANIES` 배열 |
| ELS 37개 상품 | `data/els.js` 의 `checkedCount` |
| 데이터 35계열 | `data/market/latest.json` 최상위 키 수 |

**절감 약 60시간은 추정치입니다.** 시세 취합·작성·검증을 사람이 할 때 판당 60분으로 보고
발행 60판에 곱한 값이며, 실측한 값이 아닙니다. 덱에도 그 사실을 각주로 적어 두었습니다.

## 유의

사내 보고용이며 대외 배포 자료가 아닙니다. 덱에 실린 조회 화면은 정보 제공 목적의
사내 참고 자료로, 고객에게 보여주는 자료로 쓸 경우 준법감시 부서 확인이 필요합니다.
