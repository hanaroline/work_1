# 자주 쓰는 프롬프트 모음

복사해서 그대로 쓰는 용도입니다. 예약 작업(Routine)의 프롬프트는 `ROUTINES.md`에 따로 있습니다.

---

## 새 대화 시작 — 부팅

```text
저장소 hanaroline/work_1 의 docs/claude-handoff/ 를 먼저 읽어줘.
HANDOFF.md(맥락·결정·규칙), ACCOUNT-SETUP.md(계정 설정 복원),
ROUTINES.md(예약 작업 프롬프트) 순서로 읽고, 요약하지 말고
"무엇을 이어서 하면 되는지"만 3줄로 말해줘.
```

작업을 바로 시킬 때:

```text
docs/claude-handoff/HANDOFF.md 의 작업 규칙을 지켜서 아래 일을 해줘.
기존 산출물은 그대로 두고, 새로 만드는 건 새 파일로.
[할 일]
```

## 시황 브리핑

```text
오늘 아침 마포WM 브리핑을 만들어 이 대화에 파일로 올려줘.
기억에 의존하지 말고 docs/briefing-playbook.md 를 처음부터 끝까지 다시 읽고 그대로 따라줘.
```

```text
방금 만든 브리핑에서 [수치/문구]가 이상해. 원출처로 다시 확인하고 고쳐줘.
고치기 전에 무엇이 틀렸는지 먼저 한 줄로 말해줘.
```

> 브리핑 **규칙**을 바꿀 때는 프롬프트가 아니라 `docs/briefing-playbook.md`를 고치라고 지시하세요.

## 자료·문서 만들기

```text
[주제]를 실무에서 바로 쓸 수 있게 정리해줘.
- 각 항목은 "왜 그런지 한 줄 + 바로 복사 가능한 수식/코드"
- 규정으로 바뀌는 값(세율·호가단위·약관)은 셀로 빼고 최신 기준 확인 문구를 달 것
- 단일 HTML 파일로, 서버 없이 열리게
```

```text
docs/claude-handoff/HANDOFF.md 의 "원장 디자인 시스템" 토큰과 서체를 그대로 써서 만들어줘.
라이트/다크 둘 다 되게 하고, 발행 전에 headless Chromium 스크린샷으로 렌더 확인해줘.
```

```text
미래에셋 브랜드 자료야. mas-design 기준(오렌지/블루, 승인 폰트, 표·차트 스타일)을 적용해줘.
```

```text
숫자가 들어가는 자료야. fin-data-integrity 절차대로
인쇄될 수치를 주장 대장에 먼저 등록하고 검산한 뒤에 만들어줘.
```

## 검증 요청

```text
만들기 전에 결정이 갈리는 지점만 먼저 물어보고, 나머지는 네가 판단해서 진행해줘.
```

```text
방금 만든 것 검증해줘.
- 렌더링: headless Chromium 스크린샷으로 레이아웃 깨짐 확인
- 검색 기능: 질의 20개 정도 돌려서 결과 수가 말이 되는지 확인
- 수치: 출처 대조
결과를 표로 보여주고, 고칠 것만 골라서 고쳐줘.
```

```text
이 파일 다시 읽고, 내가 요청한 것 중 빠진 게 있는지만 짚어줘. 없으면 "없음"이라고만.
```
