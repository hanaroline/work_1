데이터 합치기·뽑기

조건에 맞는 것만 합계·건수를 내고 싶다

조건이 여러 개면 SUMIFS, 조건 안에 계산이 들어가면 SUMPRODUCT입니다.

  1. 기간·구분 조건으로 합계

  2. 건수는 같은 문법으로
    =COUNTIFS(매매[구분],"매수", 매매[금액],">=1000000")
  3. 조건에 계산이 들어가면
    =SUMPRODUCT((YEAR(일자)=2026)*(구분="매수")*금액)
  4. 필터 결과만 합산
    =SUBTOTAL(109, 매매[금액])

한 셀에 LET으로 담으면 검산이 쉽습니다. 풋-콜 패리티로 반드시 확인하세요.

  1. 콜 가격
    =LET(S,$B$1,K,$B$2,r,$B$3,q,$B$4,v,$B$5,T,$B$6, d1,(LN(S/K)+(r-q+v^2/2)*T)/(v*SQRT(T)), d2,d1-v*SQRT(T), S*EXP(-q*T)*NORM.S.DIST(d1,TRUE)-K*EXP(-r*T)*NORM.S.DIST(d2,TRUE))
  2. 검산(풋-콜 패리티)
    콜 - 풋 = S*EXP(-q*T) - K*EXP(-r*T)
  3. 내재변동성은 역산
    데이터 → 가상 분석 → 목표값 찾기
