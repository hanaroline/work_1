엑셀 산식 원장

자주 쓰는 함수부터 수익률·채권·리스크·구조화상품 계산까지, 셀에 바로 붙여 쓸 수 있는 형태로 정리했습니다. 아래 검색창에 함수명이나 키워드(예: XIRR, 낙인, 영업일)를 넣으면 전체 항목이 걸러집니다.

표기 인자 중 [대괄호]는 생략 가능 버전 배지 없으면 대체로 2016 이상 공통 구분자 지역 설정에 따라 , / ; 차이 있음

01

참조·이름·표 — 수식이 깨지지 않게 만드는 토대

수식 실수의 대부분은 함수 선택이 아니라 참조 방식에서 생깁니다.

$A$1 / A$1 / $A1

절대·행고정·열고정 참조. 수식 입력 중 F4를 누르면 네 가지 상태가 순환합니다.

=B2/$B$10 ← 분모를 한 셀로 고정 =B$1*$A2 ← 곱셈표처럼 가로세로로 복사
이름 정의
수식 → 이름 관리자 (Ctrl+F3)

범위·상수·수식에 이름을 붙여 수식을 읽을 수 있게 만듭니다. 시트 이동·행 삽입에도 안전합니다.

=SUMPRODUCT(비중, 수익률) / SUM(비중)
표[열이름]
표[@열이름]
구조적 참조

표 안에서 [열이름]은 열 전체, [@열이름]은 같은 행의 값입니다. 데이터가 추가되면 범위가 자동 확장됩니다.

=SUM(매매[금액]) =[@수량]*[@단가] =SUBTOTAL(109, 매매[금액]) ← 필터된 결과만 합계
A2#
2021·365

스필(spill) 범위 연산자. 동적배열 수식이 뿌려낸 결과 전체를 크기와 무관하게 참조합니다.

=COUNTA(A2#) ← FILTER 결과 건수
=SUM(Sheet1:Sheet12!B5)

3D 참조. 서식이 동일한 여러 시트의 같은 셀을 한 번에 집계합니다. 월별 시트 합산에 유용합니다.

시트를 중간에 추가·삭제하면 범위가 조용히 바뀝니다. 시트 순서 자체가 데이터가 되므로 이름 규칙을 고정하세요.

INDIRECT(참조문자열, [A1형식])

문자열을 실제 참조로 바꿉니다. 시트명을 셀에서 받아 동적으로 참조할 때 씁니다.

=INDIRECT("'"&$A2&"'!B3")

휘발성 함수라 파일이 무거워지고, 참조 대상이 삭제돼도 #REF!로 경고해주지 않습니다. 가능하면 CHOOSE·XLOOKUP으로 대체.

OFFSET(기준, 행, 열, [높이], [너비])

기준 셀에서 이동·확장한 범위를 돌려줍니다. 최근 N개 구간 집계에 자주 쓰입니다.

=AVERAGE(OFFSET($C$2, COUNT($C:$C)-20, 0, 20, 1)) ← 최근 20일 평균

같은 일을 =AVERAGE(TAKE(C2:C9999, -20))으로 쓰면 비휘발성이라 훨씬 가볍습니다.

02

집계와 조건부 집계

조건이 둘 이상이면 SUMIFS 계열, 계산식이 조건에 들어가면 SUMPRODUCT.

SUMIF(범위, 조건, [합계범위])

조건 하나로 합계. 인자 순서가 SUMIFS와 반대라는 점만 주의합니다.

=SUMIF(C:C, "코스피", E:E) =SUMIF(D:D, ">="&$H$1, E:E) ← 비교연산자는 문자열로 결합
SUMIFS(합계범위, 조건범위1, 조건1, …)

다중 조건 합계. 합계범위가 맨 앞입니다. COUNTIFS·AVERAGEIFS·MAXIFS·MINIFS도 같은 문법입니다.

=SUMIFS(매매[금액], 매매[일자], ">="&$B$1, 매매[일자], "<="&$B$2, 매매[구분], "매수")

조건에 와일드카드: "*전자*"(포함), "?????"(5글자). 실제 별표를 찾으려면 "~*".

SUMPRODUCT(배열1, [배열2], …)

곱의 합. 가중평균, 조건 조합, 계산식이 들어간 조건 집계를 한 셀로 처리합니다. 구버전에서도 배열 계산이 됩니다.

=SUMPRODUCT(비중, 수익률) ← 가중평균 수익률 =SUMPRODUCT((YEAR(일자)=2026)*(구분="매수")*금액) ← 다중 조건 합계 =SUMPRODUCT(--(금액>0)) ← 조건 건수

조건식을 *로 묶으면 AND, +로 묶으면 OR입니다. 빈 셀·텍스트가 섞이면 #VALUE!가 나므로 범위 크기를 정확히 맞추세요.

SUBTOTAL(함수번호, 범위)

필터·숨김 행을 제외한 집계. 1xx번대는 수동으로 숨긴 행까지 제외합니다.

=SUBTOTAL(109, E2:E9999) ← 109=SUM, 101=AVERAGE, 103=COUNTA, 104=MAX
AGGREGATE(번호, 옵션, 배열, [k])

SUBTOTAL의 확장판. 오류 셀을 무시하고 집계할 수 있어 지저분한 원본 데이터에 강합니다.

=AGGREGATE(9, 6, E2:E999) ← 오류 무시 합계 =AGGREGATE(14, 6, E2:E999, 3) ← 오류 무시 3번째 큰 값

옵션 6=오류 무시, 7=숨긴 행+오류 무시. 번호 14=LARGE, 15=SMALL, 16=PERCENTILE.

GROUPBY(행필드, 값, 함수, …)
PIVOTBY(행, 열, 값, 함수, …)
365 최신

피벗테이블을 수식으로. 원본이 바뀌면 새로 고침 없이 즉시 반영됩니다.

=GROUPBY(매매[종목], 매매[금액], SUM, , 0, -2) =PIVOTBY(매매[종목], 매매[월], 매매[금액], SUM)

구버전 대체: =SUMIFS(...) + =UNIQUE(...) 조합, 또는 피벗테이블.

03

조회·매칭

XLOOKUP이 쓸 수 있으면 XLOOKUP, 아니면 INDEX+MATCH. VLOOKUP은 유지보수용으로만.

XLOOKUP(찾을값, 찾을범위, 반환범위, [없을때], [일치옵션], [방향])
2021·365

왼쪽 조회, 열 삽입 안전, 오류 대체값 내장. 조회는 이 함수 하나로 거의 정리됩니다.

=XLOOKUP($A2, 종목[코드], 종목[종목명], "미등록") =XLOOKUP($A2, 시세[일자], 시세[종가], , -1) ← 없으면 직전 영업일 값 =XLOOKUP($A2, 이력[코드], 이력[등급], , 0, -1) ← 아래에서부터 검색 = 최신값

일치옵션 0=정확, -1=작거나 같음, 1=크거나 같음, 2=와일드카드. 방향 -1=역방향(최신값 찾기), 2=오름차순 이진검색(대용량에서 빠름).

INDEX(범위, 행, [열])
MATCH(찾을값, 범위, [유형])

모든 버전에서 동작하는 표준 조합. 조회 열과 반환 열이 독립이라 열 삽입에 강합니다.

=INDEX(종목[종목명], MATCH($A2, 종목[코드], 0)) =INDEX(시세, MATCH($A2, 일자, 0), MATCH($B$1, 항목, 0)) ← 행·열 교차 조회

MATCH 유형 0=정확(미정렬 가능), 1=이하(오름차순 정렬 필수), -1=이상(내림차순 필수). 정렬 안 된 범위에 1을 쓰면 틀린 값이 조용히 나옵니다.

다중 조건 조회

키가 두 개 이상일 때. 보조열 없이 처리하는 세 가지 방법.

=XLOOKUP($A2&"|"&$B2, 이력[코드]&"|"&이력[일자], 이력[종가]) =INDEX(이력[종가], MATCH(1, (이력[코드]=$A2)*(이력[일자]=$B2), 0)) =FILTER(이력[종가], (이력[코드]=$A2)*(이력[일자]=$B2), "없음")
VLOOKUP(찾을값, 범위, 열번호, [유형])

여전히 많이 보이는 함수. 마지막 인자 FALSE(=0)를 반드시 넣습니다.

=IFERROR(VLOOKUP($A2, 종목표, 3, FALSE), "미등록")

왼쪽 조회 불가 · 열 삽입 시 열번호가 밀림 · 마지막 인자 생략 시 근사일치로 오답. 새로 쓰는 수식이라면 XLOOKUP이나 INDEX+MATCH를 쓰세요.

LOOKUP(값, 구간벡터, 결과벡터)

구간표 매칭에 강합니다(등급·수수료율·호가단위). 구간 벡터는 오름차순이어야 합니다.

=LOOKUP(B2, {0;1000;5000;10000}, {"소액";"일반";"우대";"VIP"})
04

동적배열 — 한 셀로 표를 만든다

결과가 여러 칸으로 자동 확장(spill)됩니다. 보조 시트·수동 복사 작업을 대체합니다.

FILTER(배열, 조건, [없을때])
2021·365

조건에 맞는 행만 추출. 자동 필터를 수식으로 대체합니다.

=FILTER(매매, (매매[구분]="매수")*(매매[금액]>=1000000), "해당 없음")

AND는 *, OR는 +. 조건 배열의 행 수가 원본과 같아야 합니다.

UNIQUE(배열, [열기준], [한번만])
SORT(배열, [기준], [순서])
SORTBY(배열, 기준배열, 순서, …)
2021·365

중복 제거·정렬. 조합하면 피벗 없이 요약표가 만들어집니다.

=SORT(UNIQUE(매매[종목])) =SORTBY(UNIQUE(매매[종목]), SUMIF(매매[종목], UNIQUE(매매[종목]), 매매[금액]), -1)
SEQUENCE(행, [열], [시작], [증분])
2021·365

연속 숫자·날짜·비율 배열 생성. 스케줄·배리어·시나리오 축을 만드는 기본 재료입니다.

=SEQUENCE(12, 1, DATE(2026,1,31)) ← 월별 축(말일 보정은 EOMONTH 사용) =SEQUENCE(6, 1, 0.9, -0.05) ← 90%→65% 스텝다운 배리어 =$B$1*(1+SEQUENCE(11,1,-0.25,0.05)) ← ±25% 가격 시나리오
TAKE / DROP
CHOOSECOLS / CHOOSEROWS
VSTACK / HSTACK
TOCOL / WRAPROWS
365

배열을 자르고 붙이는 도구들. 여러 시트를 한 표로 합칠 때 특히 유용합니다.

=TAKE(시세[종가], -20) ← 마지막 20개 =DROP(원본, 1) ← 헤더 행 제거 =VSTACK('1월'!A2:E200, '2월'!A2:E200) ← 월별 시트 통합 =CHOOSECOLS(매매, 1, 3, 5) ← 필요한 열만
SCAN(초기값, 배열, LAMBDA(누적, 값, …))
365

누적 계산을 배열로. 누적 수익률, 러닝 최고가, 누적 잔고를 한 셀에 담습니다.

=SCAN(1, 수익률, LAMBDA(a,v, a*(1+v)))-1 ← 누적 수익률 곡선 =SCAN(0, 종가, LAMBDA(a,v, MAX(a,v))) ← 러닝 최고가
BYROW / BYCOL / MAP / REDUCE
365

행·열·요소 단위 반복 계산. 보조열을 만들지 않고 계산을 끝냅니다.

=BYROW(종가배열, LAMBDA(r, AVERAGE(r))) ← 행별 평균 =MAP(종가, LAMBDA(p, IF(p>기준가, "상회","하회"))) =REDUCE(0, 금액, LAMBDA(a,v, a+v)) ← 조건 누적
이동평균 (MA20)

보조열 방식과 동적배열 방식 두 가지.

=IF(ROW()-ROW($C$2)+1<20, "", AVERAGE(C2:C21)) ← 아래로 채우기 =BYROW(SEQUENCE(ROWS(종가)-19), LAMBDA(i, AVERAGE(INDEX(종가,i):INDEX(종가,i+19))))
05

논리·오류 처리

중첩 IF가 3단을 넘어가면 IFS나 구간표 조회로 바꾸는 게 맞습니다.

IF(조건, 참, 거짓)
IFS(조건1, 값1, …)

IFS는 위에서부터 처음 참인 조건을 채택합니다. 마지막 조건에 TRUE를 두면 else 역할.

=IFS(B2>=0.1,"강세", B2>=0,"보합", B2>=-0.1,"약세", TRUE,"급락")
IFERROR(값, 대체값)
IFNA(값, 대체값)

오류를 대체값으로 치환. IFNA는 #N/A만 잡습니다.

=IFNA(XLOOKUP($A2, 코드, 종목명), "미등록")

IFERROR는 오타·형식 오류까지 함께 삼켜버립니다. 조회 누락만 처리하려면 IFNA를 쓰는 편이 안전합니다.

LET(이름1, 값1, …, 계산식)
365

수식 안에서 변수를 선언합니다. 같은 계산을 반복하지 않으므로 가독성과 속도가 함께 좋아집니다.

=LET(r, 종가/기준가-1, n, COUNT(r), ROUND(AVERAGE(r)*n, 4))
LAMBDA(인자, …, 계산식)
365

이름 관리자에 등록하면 사용자 정의 함수가 됩니다. VBA 없이 사내 표준 산식을 배포할 수 있습니다.

이름: CAGR 참조: =LAMBDA(기초, 기말, 연수, (기말/기초)^(1/연수)-1) 사용: =CAGR(B2, B10, 5)
SWITCH(값, 사례1, 결과1, …, [기본값])

값이 정확히 일치하는 경우 분기. 코드 → 명칭 변환에 깔끔합니다.

=SWITCH(LEFT(A2,1), "K","코스피", "Q","코스닥", "기타")
AND / OR / NOT / XOR

조건 결합. 배열 조건에는 동작하지 않으므로, 배열에서는 *와 +를 씁니다.

=IF(AND(B2>0, C2>0), "동반 상승", "") =FILTER(A:C, (B:B>0)*(C:C>0)) ← 배열에서는 곱셈
06

텍스트 다루기

외부에서 받은 데이터가 계산되지 않는 원인은 대개 공백·비출력문자·문자형 숫자입니다.

TEXT(값, "서식코드")

숫자·날짜를 정해진 표기의 문자열로. 보고서 라벨 만들 때 필수입니다.

=TEXT(A2, "000000") ← 종목코드 6자리(앞 0 유지) =TEXT(A2, "#,##0") ← 1,234,567 =TEXT(A2, "0.00%") ← 12.34% =TEXT(A2, "yyyy-mm-dd (aaa)") ← 2026-08-24 (월) =TEXT(A2, "+0.00%;-0.00%;0.00%")← 부호 강제 표기
TEXTJOIN(구분자, 빈칸무시, 범위)

여러 셀을 구분자로 이어붙입니다. 조건부와 결합하면 목록 요약이 됩니다.

=TEXTJOIN(", ", TRUE, FILTER(종목명, 수익률<-0.1))
TEXTSPLIT(텍스트, 열구분자, [행구분자])
TEXTBEFORE / TEXTAFTER
365

문자열 분해. LEFT/MID/FIND 조합을 대체합니다.

=TEXTSPLIT(A2, "/") =TEXTBEFORE(A2, "(") ← "삼성전자(005930)" → "삼성전자" =TEXTAFTER(A2, "(", 1) ← "005930)"
LEFT / RIGHT / MID / LEN

구버전에서도 쓸 수 있는 기본 절단 함수.

=MID(A2, FIND("(",A2)+1, 6) ← 괄호 안 코드 6자리
TRIM / CLEAN / SUBSTITUTE

눈에 보이지 않는 문자 제거. 웹·시스템에서 내린 데이터의 표준 전처리입니다.

=VALUE(SUBSTITUTE(SUBSTITUTE(TRIM(CLEAN(A2)), ",", ""), CHAR(160), ""))

CHAR(160)은 웹에서 자주 넘어오는 줄바꿈 없는 공백(&nbsp;)으로, TRIM으로 지워지지 않습니다.

VALUE / NUMBERVALUE

문자형 숫자를 숫자로. NUMBERVALUE는 소수점·천단위 기호를 지정할 수 있습니다.

=NUMBERVALUE(A2, ".", ",")

간단히는 =A2*1 또는 =--A2로도 됩니다. 대량이면 [데이터] → [텍스트 나누기] → 마침이 가장 빠릅니다.

FIND vs SEARCH

FIND는 대소문자 구분·와일드카드 불가, SEARCH는 구분 없음·와일드카드 가능.

=ISNUMBER(SEARCH("전자", A2)) ← 포함 여부 판정

날짜·영업일·결제일

엑셀의 날짜는 1900-01-01을 1로 하는 정수입니다. 그래서 날짜끼리 더하고 빼는 계산이 가능합니다.

EOMONTH(기준일, 개월수)
EDATE(기준일, 개월수)

해당 월의 말일 / 같은 날짜의 N개월 후. 월말 기준 데이터 정리의 기본입니다.

=EOMONTH(A2, 0) ← 당월 말일 =EOMONTH(A2, -1)+1 ← 당월 1일 =EDATE(A2, 6) ← 6개월 후 (말일 자동 보정)
WORKDAY.INTL(시작, 일수, [주말], [휴일범위])
NETWORKDAYS.INTL(시작, 종료, [주말], [휴일])

영업일 기준 이동·일수 계산. 휴장일 목록을 별도 시트에 두고 참조하면 국내 결제일 계산이 정확해집니다.

=WORKDAY(거래일, 2, 휴장일) ← 주식 결제일(T+2) =WORKDAY(EOMONTH(A2,0)+1, -1, 휴장일) ← 그 달의 마지막 영업일 =NETWORKDAYS(시작, 종료, 휴장일) ← 영업일수
YEARFRAC(시작, 종료, [기준])

두 날짜 사이를 연 단위 소수로. 이자·수익률 연율화의 분모로 씁니다.

=(기말/기초)^(1/YEARFRAC($B$1,$B$2,3))-1 ← 실제/365 기준 CAGR

기준(basis) 0=30/360(미국), 1=실제/실제, 2=실제/360, 3=실제/365, 4=30/360(유럽).

DATEDIF(시작, 종료, 단위)

경과 연·월·일. 함수 마법사에 나오지 않는 숨은 함수지만 잘 동작합니다.

=DATEDIF(입사일, TODAY(), "Y") & "년 " & DATEDIF(입사일, TODAY(), "YM") & "개월"
분기 · 주차 · 요일

기간 축을 만드는 짧은 산식들.

=ROUNDUP(MONTH(A2)/3, 0) ← 분기 ="'"&TEXT(A2,"yy")&"."&ROUNDUP(MONTH(A2)/3,0)&"Q" =ISOWEEKNUM(A2) ← ISO 주차 =TEXT(A2, "aaa") ← 월/화/수 =WEEKDAY(A2, 2) ← 1=월 … 7=일
날짜로 인식되지 않는 텍스트

20260824 같은 8자리 숫자를 날짜로 변환합니다.

=DATE(LEFT(A2,4), MID(A2,5,2), RIGHT(A2,2)) =DATEVALUE(SUBSTITUTE(A2, ".", "-"))

숫자·반올림·호가단위

금액 계산에서 ROUND를 생략하면 부동소수점 잔차가 검증 단계에서 튀어나옵니다.

ROUND / ROUNDUP / ROUNDDOWN

자릿수 인자는 음수도 가능합니다(-3 = 천 단위).

=ROUND(A2, -3) ← 천원 단위 반올림 =ROUNDDOWN(A2*세율, 0)
MROUND / FLOOR.MATH / CEILING.MATH

지정한 배수 단위로 맞춤. 호가단위·수량단위·계약단위 처리에 씁니다.

=FLOOR.MATH(A2, 10) ← 10원 단위 절사 =MROUND(A2, 5) ← 5원 단위 반올림 =CEILING.MATH(A2, 100) ← 100주 단위 올림
호가단위 적용

가격대별 호가단위를 구간표로 조회한 뒤 그 배수로 맞춥니다. 목표가·주문가 계산에 그대로 씁니다.

=LET(p, A2, u, LOOKUP(p, {0;2000;5000;20000;50000;200000;500000}, {1;5;10;50;100;500;1000}), FLOOR.MATH(p, u))

위 구간은 유가증권시장 기준의 예시입니다. 코스닥은 상위 구간이 다르고 규정도 개정되므로, 실제 업무에서는 거래소 최신 공시 기준으로 구간표를 셀에 두고 참조하세요.

INT / TRUNC / ABS / SIGN / MOD

INT는 음수에서 내림(-1.5→-2), TRUNC는 절단(-1.5→-1)입니다. 이 차이가 손익 계산에서 갈립니다.

=MOD(ROW(), 2)=0 ← 짝수 행 판정(조건부 서식)
부동소수점 잔차

0.1+0.2=0.3이 FALSE가 되는 문제. 비교 전에 반올림하거나 허용오차를 둡니다.

=ROUND(A2-B2, 2)=0 =ABS(A2-B2)<0.000001

통계·분포·회귀

표본(.S)과 모집단(.P)을 섞어 쓰면 결과가 미묘하게 틀립니다.

AVERAGE / MEDIAN / TRIMMEAN

이상치가 있는 데이터(목표주가, 컨센서스)는 중위값이나 절사평균이 더 안전합니다.

=TRIMMEAN(목표주가, 0.2) ← 상·하위 10%씩 제외한 평균
STDEV.S / STDEV.P
VAR.S / VAR.P

관측된 표본이면 .S(n-1로 나눔), 전체 모집단이면 .P. 수익률 시계열은 통상 .S를 씁니다.

PERCENTILE.INC / QUARTILE.INC
RANK.EQ / LARGE / SMALL

분위·순위. 백분위 순위는 PERCENTRANK.INC.

=PERCENTILE.INC(수익률, 0.05) ← 하위 5% 분위 =RANK.EQ(B2, $B$2:$B$200, 0) ← 내림차순 순위 =LARGE($B$2:$B$200, 3) ← 3번째 큰 값
CORREL / RSQ
SLOPE / INTERCEPT

상관과 단순회귀. 베타 추정에 그대로 쓰입니다.

=CORREL(주식수익률, 지수수익률) =SLOPE(주식수익률, 지수수익률) ← 베타 =INTERCEPT(주식수익률, 지수수익률) ← 알파(일간)
LINEST(y, x, [상수], [통계])
TREND / FORECAST.LINEAR

다중회귀 계수와 통계량을 배열로. 여러 팩터 회귀를 한 셀에서 처리합니다.

=LINEST(y범위, x범위, TRUE, TRUE) ← 계수·표준오차·R²·F값 =FORECAST.LINEAR(신규x, y범위, x범위)

계수는 오른쪽에서 왼쪽 순서로 반환됩니다(마지막 x의 계수가 첫 칸). INDEX(LINEST(...),1,k)로 필요한 값만 꺼내세요.

NORM.S.DIST / NORM.S.INV
NORM.DIST / STANDARDIZE

표준정규 누적확률과 그 역함수. VaR와 옵션 가격 계산의 재료입니다.

=NORM.S.INV(0.05) ← -1.645 =NORM.S.DIST(1.28, TRUE) ← 누적확률 =NORM.DIST(x, 0, 1, FALSE) ← 확률밀도(감마·베가 계산용)
FREQUENCY(데이터, 구간)

구간별 도수. 수익률 분포 히스토그램의 원천 데이터입니다.

=FREQUENCY(수익률, 구간경계)

수익률·현금흐름

기간이 불규칙하면 IRR이 아니라 XIRR, 현재가치도 NPV가 아니라 XNPV입니다.

기간수익률 · 누적수익률

단순 변화율과 기간 연결(누적) 수익률.

=B3/B2-1 ← 일간 수익률 =PRODUCT(1+수익률범위)-1 ← 기간 누적(기하 연결) =LN(B3/B2) ← 로그수익률(합산 가능)

로그수익률은 더하기가 되어 누적·연율화에 편하지만, 실제 투자 성과 표기는 단순수익률로 환산해서 보여줘야 합니다: =EXP(SUM(로그수익률))-1.

CAGR (연평균 성장률)
RRI(기간수, 현재값, 미래값)

연평균 복리 수익률. 두 방식의 결과는 같습니다.

=(기말/기초)^(1/연수)-1 =RRI(연수, 기초, 기말) =(기말/기초)^(365/(종료일-시작일))-1 ← 일수 기반
연율화 환산

주기 수익률을 연 단위로 맞춥니다. 단리 환산과 복리 환산을 혼용하지 않도록 기준을 문서에 명시하세요.

=(1+월수익률)^12-1 ← 월 → 연(복리) =(1+일수익률)^252-1 ← 일 → 연(거래일 기준) =(1+반기쿠폰)^2-1 ← 6개월 쿠폰 → 연
XIRR(현금흐름, 날짜, [추정])
XNPV(할인율, 현금흐름, 날짜)

불규칙한 입출금이 있는 계좌의 금액가중수익률(MWR)과 현재가치. 실무에서 가장 많이 쓰는 조합입니다.

=XIRR(C2:C40, B2:B40) =XNPV($B$1, C2:C40, B2:B40)

유출은 음수, 유입은 양수로 부호를 반드시 구분합니다. 부호가 한 종류뿐이면 #NUM!. 수렴하지 않으면 추정값(예: 0.1)을 넣어보세요.

NPV(할인율, 값…)
IRR(값, [추정])
MIRR(값, 조달금리, 재투자금리)

등간격 현금흐름 기준. NPV는 첫 값을 1기 후로 간주하므로 0기 현금흐름은 밖으로 빼야 합니다.

=NPV($B$1, C3:C12)+C2 ← C2가 0기(투자 시점) =IRR(C2:C12) =MIRR(C2:C12, 0.05, 0.03)
PV / FV / PMT / RATE / NPER

연금·대출의 5요소. 넷을 알면 나머지 하나가 나옵니다. 월 단위면 금리는 ÷12, 기간은 ×12.

=PMT($B$1/12, $B$2*12, -$B$3) ← 원리금균등 월 상환액 =IPMT($B$1/12, 회차, $B$2*12, -$B$3) ← 해당 회차 이자 =PPMT($B$1/12, 회차, $B$2*12, -$B$3) ← 해당 회차 원금 =FV($B$1/12, $B$2*12, -월적립액) ← 적립식 만기금액 =RATE($B$2*12, -월납, 원금)*12 ← 연환산 금리

부호 규칙: 내 주머니에서 나가는 돈은 음수. 결과가 음수로 나오면 인자에 -를 붙여 방향을 맞춥니다.

EFFECT(명목금리, 복리횟수)
NOMINAL(실효금리, 복리횟수)

표시금리와 실효금리 환산. 상품 비교에서 기준을 통일할 때 씁니다.

=EFFECT(0.05, 12) ← 명목 5% 월복리 → 실효 5.116%
수수료·세금 반영 순수익률

비용 항목은 반드시 셀로 분리해 두고 참조합니다. 세율·수수료율을 수식에 박아넣지 마세요.

=(매도가*수량*(1-매도수수료율-거래세율) - 매수가*수량*(1+매수수수료율)) / (매수가*수량*(1+매수수수료율))

채권·금리

채권 함수는 인자 순서가 길어 실수가 잦습니다. 인자마다 입력 셀을 만들고 참조하는 편이 안전합니다.

PRICE(정산일, 만기일, 표면금리, 수익률, 상환액, 연지급횟수, [기준])

액면 100 기준 채권 가격(클린 프라이스).

=PRICE($B$1, $B$2, $B$3, $B$4, 100, 2, 1)
YIELD(정산일, 만기일, 표면금리, 가격, 상환액, 빈도, [기준])

가격에서 만기수익률(YTM) 역산.

=YIELD($B$1, $B$2, $B$3, $B$5, 100, 2, 1)
DURATION(…)
MDURATION(…)

매콜리 듀레이션과 수정 듀레이션. 인자 구성은 YIELD와 같습니다(가격 대신 수익률).

=MDURATION($B$1, $B$2, $B$3, $B$4, 2, 1)
금리 변동 시 가격 변화

수정 듀레이션과 볼록도로 근사. 엑셀에 볼록도 함수가 없으므로 직접 산출하거나 근사식을 씁니다.

=-MD*Δy + 0.5*볼록도*Δy^2 ← 가격 변화율 근사 =(P(y-Δy) + P(y+Δy) - 2*P(y)) / (P(y)*Δy^2) ← 볼록도 수치 근사
ACCRINT(발행일, 첫이자일, 정산일, 이율, 액면, 빈도, [기준])

경과이자. 더티 프라이스 = 클린 프라이스 + 경과이자.

=PRICE(...) + ACCRINT(...)
COUPNCD / COUPPCD
COUPDAYBS / COUPDAYSNC / COUPNUM

다음·직전 이자지급일, 경과일수, 잔여 지급 횟수. 이자 스케줄 표를 만들 때 사용합니다.

=COUPNCD($B$1, $B$2, 2, 1) ← 다음 이자지급일
INTRATE / DISC / TBILLYIELD
YIELDMAT / PRICEDISC

할인채·단기물 계열. 발행 형태에 맞는 함수를 골라야 결과가 시장 관행과 맞습니다.

선도금리 · 보간

현물금리 커브에서 선도금리를 뽑고, 사이 만기는 선형보간합니다.

=((1+s2)^t2/(1+s1)^t1)^(1/(t2-t1))-1 ← 선도금리 =FORECAST.LINEAR(목표만기, 금리2개, 만기2개) ← 선형보간 =TREND(금리범위, 만기범위, 목표만기)
12

리스크 지표

모두 일간 수익률 시계열 하나에서 나옵니다. 연율화 계수(거래일 252일)를 문서 상단에 셀로 고정해 두세요.

연변동성

일간 수익률 표준편차에 √252를 곱합니다. 월간 데이터면 √12.

=STDEV.S(수익률)*SQRT(252)
샤프지수 · 소르티노

위험 한 단위당 초과수익. 소르티노는 하방 변동성만 분모로 씁니다.

=(AVERAGE(수익률)*252 - 무위험금리) / (STDEV.S(수익률)*SQRT(252)) =(AVERAGE(수익률)*252 - 무위험금리) / (SQRT(SUMPRODUCT((수익률<0)*수익률^2)/COUNT(수익률))*SQRT(252))
베타 · 알파

지수 대비 민감도. 두 방식 결과는 동일합니다.

=SLOPE(주식수익률, 지수수익률) =COVARIANCE.P(주식수익률, 지수수익률)/VAR.P(지수수익률) =AVERAGE(주식수익률)*252 - 베타*AVERAGE(지수수익률)*252 ← 연환산 알파
추적오차 · 정보비율

벤치마크 대비 초과수익의 변동성과 그 효율.

=STDEV.S(초과수익)*SQRT(252) ← 추적오차(TE) =AVERAGE(초과수익)*252 / (STDEV.S(초과수익)*SQRT(252)) ← 정보비율(IR)
최대낙폭 (MDD)

고점 대비 최대 하락률. 동적배열이면 한 셀로 끝납니다.

=MIN(종가/SCAN(0, 종가, LAMBDA(a,v, MAX(a,v))) - 1)

구버전: 보조열에 =MAX($C$2:C2)(러닝 최고가), 그 옆에 =C2/D2-1, 마지막에 =MIN(E:E).

VaR · CVaR

역사적 시뮬레이션과 모수적(정규분포 가정) 두 방식.

=-PERCENTILE.INC(수익률, 0.05) ← 역사적 VaR 95% =-(AVERAGE(수익률) + NORM.S.INV(0.05)*STDEV.S(수익률)) ← 모수적 VaR 95% =-AVERAGEIF(수익률, "<="&PERCENTILE.INC(수익률,0.05)) ← CVaR(기대손실) =VaR일간 * SQRT(보유기간) ← 기간 환산
포트폴리오 변동성 (행렬)

비중 벡터 w와 공분산 행렬 Σ로 √(wᵀΣw)를 계산합니다.

=SQRT(MMULT(MMULT(TRANSPOSE(비중), 공분산행렬), 비중))*SQRT(252)

공분산 행렬 칸: =COVARIANCE.P(INDEX(수익률,,ROW()-기준행), INDEX(수익률,,COLUMN()-기준열)) 형태로 채우면 자동 생성됩니다.

상관행렬 · 분산기여도

자산 간 상관과 각 자산의 위험 기여분.

=CORREL(INDEX(수익률,,$A2), INDEX(수익률,,B$1)) =비중*MMULT(공분산행렬, 비중)/포트분산 ← 위험기여도(%)
13

옵션·구조화상품

블랙-숄즈와 스텝다운 ELS 판정은 엑셀 함수만으로 충분히 구현됩니다.

블랙-숄즈 콜 가격

S=기초가, K=행사가, r=무위험금리, q=배당률, v=변동성, T=잔존만기(연).

=LET(S,$B$1, K,$B$2, r,$B$3, q,$B$4, v,$B$5, T,$B$6, d1, (LN(S/K)+(r-q+v^2/2)*T)/(v*SQRT(T)), d2, d1-v*SQRT(T), S*EXP(-q*T)*NORM.S.DIST(d1,TRUE) - K*EXP(-r*T)*NORM.S.DIST(d2,TRUE))
블랙-숄즈 풋 가격

풋-콜 패리티로 검증하면 계산 실수를 바로 잡을 수 있습니다.

=LET(S,$B$1, K,$B$2, r,$B$3, q,$B$4, v,$B$5, T,$B$6, d1, (LN(S/K)+(r-q+v^2/2)*T)/(v*SQRT(T)), d2, d1-v*SQRT(T), K*EXP(-r*T)*NORM.S.DIST(-d2,TRUE) - S*EXP(-q*T)*NORM.S.DIST(-d1,TRUE))

검증식: 콜 - 풋 = S*EXP(-q*T) - K*EXP(-r*T). 양변 차이가 0이 아니면 인자 단위(연율/일수)를 확인하세요.

델타 · 감마 · 베가 · 세타

민감도(그릭). 베가·세타는 관행상 1%p·1일 기준으로 나눠 표기합니다.

델타(콜) =EXP(-q*T)*NORM.S.DIST(d1,TRUE) 감마 =EXP(-q*T)*NORM.DIST(d1,0,1,FALSE)/(S*v*SQRT(T)) 베가 =S*EXP(-q*T)*NORM.DIST(d1,0,1,FALSE)*SQRT(T)/100 세타(근사)=(BS(T-1/252) - BS(T))
내재변동성

역산 전용 함수는 없습니다. [데이터] → [가상 분석] → 목표값 찾기로 BS 가격을 시장가에 맞추거나, 이분법을 REDUCE로 구현합니다.

목표값 찾기: 수식 셀 = BS 가격, 찾는 값 = 시장가, 바꿀 셀 = 변동성 입력 셀.

스텝다운 배리어 스케줄

6개월 단위 조기상환 행사비율(95-95-90-90-85-85 등)을 배열로 만듭니다.

={0.95;0.95;0.90;0.90;0.85;0.85} =SEQUENCE(6,1,0.95,-0.05) ← 균등 스텝다운
조기상환 판정 (worst-of)

관찰일 기준으로 기초자산 중 최저 성과가 행사비율 이상인지 봅니다.

=IF(MIN(관찰일종가범위/최초기준가범위) >= 행사비율, "조기상환", "이월") =IFERROR(XMATCH(TRUE, BYROW(성과행렬, LAMBDA(r, MIN(r)>=배리어)), 0), 0) ← 첫 상환 회차 번호(0=미상환)
낙인(KI) 여부 · 만기 상환율

전체 관찰기간의 최저치를 KI 수준과 비교하고, 만기 시나리오 손익을 계산합니다.

=IF(MIN(전기간최저가범위/최초기준가범위) < KI비율, "낙인 발생", "미발생") =LET(w, MIN(만기종가/기준가), IF(w >= 만기행사비율, 1+쿠폰총액, IF(낙인여부="미발생", 1+쿠폰총액, w))) ← 만기 상환율

실제 상품은 리자드·월지급·환율조건 등 약관 변형이 많습니다. 위 산식은 표준형 스텝다운 구조 기준이며, 반드시 해당 상품 약관과 대조해 검증하세요.

쿠폰 누적 · 연환산

회차별 쿠폰과 연환산 표기.

=연쿠폰율*회차/2 ← 6개월 단위 누적 쿠폰(단리) =(1+총쿠폰)^(1/보유연수)-1 ← 연환산 수익률
몬테카를로 (GBM 경로)

기하 브라운 운동 1스텝. 표를 아래로 채우면 경로가, [데이터 표]나 반복 계산으로 다수 시뮬레이션이 됩니다.

=이전가격*EXP((r-q-v^2/2)*dt + v*SQRT(dt)*NORM.S.INV(RAND()))

RAND()는 휘발성이라 매 재계산마다 값이 바뀝니다. 시뮬레이션 결과는 값으로 붙여넣기(Ctrl+Alt+V → 값)해서 고정하세요.

중복 · 누락 찾기

조건부 서식 수식으로도 그대로 쓸 수 있습니다.

=COUNTIF($A:$A, A2)>1 ← 중복 행 표시 =IF(COUNTIF(대조표[코드], A2)=0, "누락", "") =TEXTJOIN(", ", TRUE, FILTER(A:A, COUNTIF(B:B, A:A)=0)) ← 차집합 목록
형식 검증

계산이 안 되는 셀을 찾아냅니다.

=SUMPRODUCT(--ISTEXT($E$2:$E$999)) ← 숫자여야 할 열의 텍스트 개수 =COUNTA(E:E)-COUNT(E:E) ← 같은 목적의 짧은 버전 =SUMPRODUCT(--ISERROR($E$2:$E$999)) ← 오류 셀 개수 =SUMPRODUCT(--(TRIM(A2:A99)<>A2:A99)) ← 앞뒤 공백 포함 셀

보고서 상단에 두는 자체 검증 줄. 색으로 즉시 보이게 만드세요.

=IF(ROUND(SUM(상세[금액]) - 총계, 2)=0, "일치", "불일치 " & TEXT(SUM(상세[금액])-총계, "#,##0")) =IF(ABS(SUM(비중)-1)<0.0001, "비중 합 100%", "비중 합 오류")
