자동화하기 전에 정하고 갈 세 가지

  • 원본 시트는 건드리지 않는다 — 받은 데이터는 그대로 두고 가공은 별도 시트·별도 쿼리에서. 원본을 덮어쓰면 검증할 기준이 사라집니다.
  • 고객 정보는 마스킹 열로만 내보낸다 — 외부로 나가는 파일은 마스킹 열을 값으로 붙여넣은 뒤 원본 열을 삭제합니다.
  • 매크로는 사본에서 먼저 돌린다 — 매크로 실행은 되돌리기가 되지 않습니다.
01

파워 쿼리 — 매크로 없이 만드는 자동화

매일·매월 같은 형식의 파일을 받아 가공한다면, 그 작업은 VBA가 아니라 파워 쿼리의 몫입니다. 한 번 만들어 두면 이후로는 새로 고침 한 번입니다.

폴더에서 가져오기
데이터 → 데이터 가져오기 → 파일 → 폴더에서

폴더에 파일을 떨어뜨리기만 하면 전부 자동 취합됩니다. 일자별로 내려받는 원장·약정·잔고 파일 처리의 정석입니다.

파일명에 날짜가 있으면 Source.Name 열이 자동 생성되어 기준일 열로 쓸 수 있습니다.

열 피벗 해제 (Unpivot)
변환 → 열 피벗 해제

월이 가로로 늘어선 표를 항목·월·값 세로 구조로 바꿉니다. 피벗테이블이 먹는 형태가 바로 이 형태입니다. 파워 쿼리에서 가장 값어치 있는 기능 하나를 꼽으라면 이것입니다.

쿼리 병합 / 추가
홈 → 병합 · 추가

병합(Merge)은 VLOOKUP의 대체(왼쪽 외부 조인), 추가(Append)는 여러 시트·파일을 세로로 이어붙이기입니다. 수십만 행에서도 수식보다 훨씬 가볍습니다.

자주 쓰는 M 수식
사용자 지정 열 / 수식 입력줄

고급 편집기를 열지 않아도 이 정도만 알면 대부분 처리됩니다.

= Table.AddColumn(이전단계, "수익률", each [평가금액]/[매입금액]-1, type number) = Table.SelectRows(이전단계, each [구분] = "매수" and [금액] >= 1000000) = Table.TransformColumnTypes(이전단계, {{"일자", type date}, {"금액", Int64.Type}}) = Date.EndOfMonth([일자]) // 월말 = Date.ToText([일자], "yyyy-MM") // 월 구분 열 = Text.PadStart(Text.From([코드]), 6, "0") // 종목코드 6자리 복원 = try [금액]/[수량] otherwise null // 오류 방어
매개변수로 경로 관리
홈 → 매개 변수 관리

폴더 경로를 쿼리에 박아두면 다른 PC에서 전부 깨집니다. 경로를 매개변수(또는 시트의 셀)로 빼두면 담당자 이관·PC 교체에도 그대로 동작합니다.

새로 고침

Ctrl+Alt+F5 또는 [데이터] → [모두 새로 고침]. 연결 속성에서 파일을 열 때 새로 고침을 켜두면 파일을 여는 순간 최신 상태가 됩니다.

파워 쿼리 vs 매크로

선택 기준은 단순합니다.

파워 쿼리 — 데이터를 불러오고·정리하고·합치는 일. 코드 없이 단계가 기록되고, 원본이 바뀌어도 새로 고침이면 끝.
VBA — 서식 적용, 파일 분리 저장, PDF·메일 생성처럼 엑셀 조작이 필요한 일. 두 개를 굳이 경쟁시키지 말고 역할을 나누세요.

02

매크로·VBA

반복 작업을 없애는 최단 경로. 다만 매크로 실행은 실행 취소가 되지 않습니다 — 항상 사본에서 먼저 돌려보세요.

시작 설정
Alt+F11 편집기 · Alt+F8 실행

매크로를 쓰기 전 한 번만 해두면 되는 준비.

① 파일은 .xlsm으로 저장 ② 모든 파일에서 쓰려면 개인용 매크로 통합 문서(PERSONAL.XLSB)에 저장 ③ [개발 도구] 탭 표시(파일 → 옵션 → 리본 사용자 지정) ④ 회사 정책상 매크로가 차단되면 [신뢰할 수 있는 위치] 등록 여부를 IT에 문의 ⑤ 매크로 기록기로 뼈대를 만든 뒤 코드를 다듬는 방식이 가장 빠릅니다.

속도·안전 템플릿

모든 매크로의 겉껍질. 화면 갱신과 자동 계산을 끄면 수십 배 빨라지고, 오류가 나도 설정이 원복됩니다.

Sub 작업실행() Application.ScreenUpdating = False Application.Calculation = xlCalculationManual Application.EnableEvents = False On Error GoTo 정리 ' ─────── 여기에 실제 작업 코드 ─────── 정리: Application.EnableEvents = True Application.Calculation = xlCalculationAutomatic Application.ScreenUpdating = True If Err.Number <> 0 Then MsgBox "오류: " & Err.Description End Sub
폴더 안의 파일 전부 합치기

일자별로 내려받은 파일을 한 시트로 취합합니다.

Sub 폴더취합() Dim f As String, wb As Workbook, ws As Worksheet, 경로 As String, r As Long 경로 = ThisWorkbook.Path & "\원본\" Set ws = ThisWorkbook.Sheets("취합") r = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row + 1 f = Dir(경로 & "*.xls*") Do While f <> "" Set wb = Workbooks.Open(경로 & f) With wb.Sheets(1) .Range("A2:H" & .Cells(.Rows.Count, 1).End(xlUp).Row).Copy ws.Cells(r, 1) End With ws.Cells(r, 10).Value = f ' 어느 파일에서 왔는지 기록 wb.Close SaveChanges:=False r = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row + 1 f = Dir Loop MsgBox "취합 완료: " & r - 2 & "행" End Sub

같은 일을 파워 쿼리 [폴더에서 가져오기]로 하면 코드 없이 되고 유지보수도 쉽습니다. 파일 구조가 제각각일 때만 VBA를 쓰세요.

시트별로 파일 분리 저장

지점별·담당자별 시트를 각각의 파일로 떨궈 배포할 때.

Sub 시트별저장() Dim ws As Worksheet, 경로 As String 경로 = ThisWorkbook.Path & "\" Application.DisplayAlerts = False For Each ws In ThisWorkbook.Worksheets If ws.Visible = xlSheetVisible Then ws.Copy ActiveWorkbook.SaveAs 경로 & ws.Name & "_" & Format(Date, "yyyymmdd") & ".xlsx", _ FileFormat:=xlOpenXMLWorkbook ActiveWorkbook.Close False End If Next ws Application.DisplayAlerts = True End Sub
고객 보고서 PDF 일괄 생성

고객 목록을 돌면서 양식 시트의 값만 바꿔 PDF로 저장합니다. 월간 리포트 발송의 핵심 루틴입니다.

Sub 리포트PDF() Dim i As Long, 끝 As Long, 경로 As String 경로 = ThisWorkbook.Path & "\리포트\" If Dir(경로, vbDirectory) = "" Then MkDir 경로 끝 = Sheets("고객목록").Cells(Rows.Count, 1).End(xlUp).Row Application.ScreenUpdating = False For i = 2 To 끝 Sheets("양식").Range("고객코드").Value = Sheets("고객목록").Cells(i, 1).Value Sheets("양식").Calculate Sheets("양식").ExportAsFixedFormat _ Type:=xlTypePDF, _ Filename:=경로 & Sheets("고객목록").Cells(i, 2).Value & "_" & Format(Date, "yyyymm") & ".pdf", _ OpenAfterPublish:=False Next i Application.ScreenUpdating = True MsgBox 끝 - 1 & "건 생성 완료" End Sub
Outlook 메일 초안 일괄 생성

고객별 본문·첨부를 채운 초안을 띄웁니다. 내용 확인 후 사람이 보내는 구조로 만드는 것이 안전합니다.

Sub 메일초안생성() Dim ol As Object, mi As Object, i As Long Set ol = CreateObject("Outlook.Application") For i = 2 To Cells(Rows.Count, 1).End(xlUp).Row Set mi = ol.CreateItem(0) mi.To = Cells(i, 3).Value ' 이메일 mi.Subject = Cells(i, 2).Value & " 고객님 " & Format(Date, "m월") & " 자산현황 안내" mi.Body = Cells(i, 4).Value ' 미리 만들어 둔 본문 문구 If Cells(i, 5).Value <> "" Then mi.Attachments.Add Cells(i, 5).Value mi.Display ' .Send 로 바꾸면 즉시 발송 Next i End Sub

고객 정보·대량 발송은 회사 보안 및 개인정보 처리 규정을 먼저 확인하세요. 자동 발송(.Send)은 오발송 시 회수가 불가능하므로 .Display로 두는 편을 권합니다. 수신동의·광고 표기 등 준수사항은 컴플라이언스 확인 대상입니다.

사용자 정의 함수 (UDF)

사내 표준 산식을 함수로 만들어 배포합니다. 시트에서 =호가단위(A2)처럼 씁니다.

Function 호가단위(가격 As Double) As Double Select Case 가격 Case Is < 2000: 호가단위 = 1 Case Is < 5000: 호가단위 = 5 Case Is < 20000: 호가단위 = 10 Case Is < 50000: 호가단위 = 50 Case Is < 200000: 호가단위 = 100 Case Is < 500000: 호가단위 = 500 Case Else: 호가단위 = 1000 End Select End Function Function 주문가(가격 As Double) As Double 주문가 = Int(가격 / 호가단위(가격)) * 호가단위(가격) End Function

UDF를 받는 사람도 매크로 사용 파일이어야 동작합니다. 배포가 부담스러우면 LAMBDA(365)로 만들어 이름으로 공유하는 편이 간단합니다.

자잘하지만 매일 쓰는 것들

단축키를 지정해 두면 체감이 큰 짧은 매크로 모음.

Sub 값으로() ' 선택 영역 수식 → 값 Selection.Value = Selection.Value End Sub Sub 백업저장() ' 날짜 붙여 사본 저장 ThisWorkbook.SaveCopyAs Replace(ThisWorkbook.FullName, ".xls", _ "_" & Format(Now, "yyyymmdd_hhnn") & ".xls") End Sub Sub 조건행삭제() ' 잔고 0인 행 삭제 (아래→위) Dim i As Long For i = Cells(Rows.Count, 1).End(xlUp).Row To 2 Step -1 If Cells(i, 5).Value = 0 Then Rows(i).Delete Next i End Sub Sub 목차만들기() ' 시트 목차 + 링크 생성 Dim ws As Worksheet, i As Long: i = 2 For Each ws In ThisWorkbook.Worksheets Sheets("목차").Hyperlinks.Add Sheets("목차").Cells(i, 1), "", _ "'" & ws.Name & "'!A1", , ws.Name i = i + 1 Next ws End Sub

단축키 지정: Alt+F8 → 매크로 선택 → 옵션 → 바로 가기 키. Ctrl+Shift 조합을 써야 엑셀 기본 단축키와 충돌하지 않습니다.

입력 시각 자동 기록 (시트 이벤트)

고객 상담 기록처럼 "언제 입력했는지"가 중요한 표에서. 해당 시트 모듈에 붙여 넣습니다.

Private Sub Worksheet_Change(ByVal Target As Range) If Intersect(Target, Me.Range("E:E")) Is Nothing Then Exit Sub Application.EnableEvents = False Target.Offset(0, 1).Value = Now ' 옆 칸에 입력 시각 Application.EnableEvents = True End Sub

이벤트 매크로 안에서 값을 쓰면 다시 이벤트가 발생합니다. EnableEvents를 껐다 켜는 처리를 빼먹으면 무한 반복에 빠집니다.

쓰기 전 확인할 것

매크로 사고는 대부분 같은 자리에서 납니다.

매크로 실행은 실행 취소 불가 — 사본에서 먼저 테스트 · 출처가 불분명한 .xlsm은 열지 않기 · Rows.Delete는 반드시 아래에서 위로 · 고객 개인정보가 담긴 파일의 외부 저장·전송은 사내 규정 준수 · 완성한 매크로는 코드에 주석과 담당자명을 남겨 인수인계 가능하게 유지

03

지점 영업 ① 고객·계좌 관리

고객 목록 한 장을 표(Ctrl+T)로 만들어 두면, 아래 산식들이 그대로 콜 리스트와 관리 지표가 됩니다.

고객별 자산·손익 집계

잔고 원장에서 고객 단위로 끌어올립니다.

=SUMIFS(잔고[평가금액], 잔고[고객코드], $A2) =SUMIFS(잔고[평가금액], 잔고[고객코드], $A2, 잔고[상품군], B$1) ← 상품군별 =SUMIFS(잔고[평가금액],잔고[고객코드],$A2)/SUMIFS(잔고[매입금액],잔고[고객코드],$A2)-1
고객 수익률 — 입출금 반영

단순 평가손익률은 추가 입금이 있으면 왜곡됩니다. 기간 수익률은 XIRR로 계산합니다.

=XIRR(현금흐름, 일자) 현금흐름: 기초평가액 -음수, 입금 -음수, 출금 +양수, 기말평가액 +양수
자산배분 비중 · 리밸런싱 제안

현재 비중과 목표 비중의 차이를 금액으로 환산해 바로 제안서에 넣습니다.

=현재금액/총자산 ← 현재 비중 =목표비중*총자산 - 현재금액 ← 조정 필요 금액(+매수/-매도) =TEXT(ABS(조정금액),"#,##0")&"원 "&IF(조정금액>0,"매수","매도") =SUMPRODUCT(비중, 상품위험등급) ← 포트폴리오 가중 위험도
고객 등급 · 핵심고객 선별

자산·수수료 기여도로 등급을 자동 부여하고, 파레토(상위 20%) 고객을 뽑습니다.

=LOOKUP(총자산, {0;30000000;100000000;500000000;1000000000}, {"일반";"우대";"골드";"프리미엄";"VIP"}) =SCAN(0, SORT(수수료,,-1), LAMBDA(a,v, a+v))/SUM(수수료) ← 누적 기여도 곡선 =FILTER(고객명, 누적기여도<=0.8) ← 상위 80% 기여 고객
접촉 관리 · 콜 리스트

"오늘 누구에게 연락할 것인가"를 수식이 정하게 만듭니다.

=TODAY()-최근접촉일 ← 미접촉 경과일 =FILTER(CHOOSECOLS(고객,1,2,5), (TODAY()-고객[최근접촉일]>30)*(고객[총자산]>=100000000), "대상 없음") =SORTBY(콜대상, 우선순위점수, -1) =고객[총자산]/100000000*3 + (TODAY()-고객[최근접촉일])/30 ← 단순 우선순위 점수
생일·기념일 알림

연도를 무시하고 월·일만 비교합니다.

=TEXT(생년월일,"mmdd")=TEXT(TODAY(),"mmdd") ← 오늘 생일 =MOD(DATE(YEAR(TODAY()),MONTH(생일),DAY(생일))-TODAY(), 365) ← D-day =DATEDIF(생년월일, TODAY(), "Y") ← 만 나이
개인정보 마스킹

화면 공유·출력물·외부 전달 자료에는 마스킹한 열을 씁니다.

=REPLACE(A2, 2, 1, "*") ← 홍길동 → 홍*동 =LEFT(B2,3)&"-****-"&RIGHT(B2,4) ← 계좌·연락처 =REPT("*", LEN(C2)-4)&RIGHT(C2,4)

마스킹은 표시용일 뿐, 원본 열이 파일에 그대로 남아 있습니다. 외부로 나가는 파일은 마스킹 열만 값으로 붙여넣기 후 원본 열을 삭제하세요.

유휴자금·이탈 신호 감지

제안 기회와 위험 신호를 같은 방식으로 잡아냅니다.

=IF(예수금/총자산>0.3, "유휴자금 제안 대상", "") =IF(당월총자산/전월총자산-1 < -0.3, "잔고 급감 · 확인 필요", "") =IF(AND(총자산>0, 최근거래일<TODAY()-180), "휴면 전환 주의", "")
목록 정합성 점검

고객 데이터는 중복·공백에서 사고가 납니다. 목록 상단에 점검 줄을 고정하세요.

만기 D-day · 도래 목록

=EDATE($B$1, 6*SEQUENCE(6)) ← 6회차 평가일 =WORKDAY(EDATE($B$1, 6*n)+1, -1, 휴장일) ← 영업일 보정 =IF(TODAY()>=평가일-5, "평가일 임박 · 사전 안내", "")
고객 안내 문구 자동 생성

문자·알림톡·메일 본문을 셀에서 만들어 그대로 복사합니다. 조건에 따라 문장이 갈리게 하면 그대로 발송 목록이 됩니다.

=고객명&" 고객님, 보유하신 "&상품명&"의 "&TEXT(만기일,"m월 d일")& " 만기가 예정되어 있습니다. 재투자 상담 원하시면 회신 부탁드립니다." =IFS(수익률>=0.05, 고객명&"님 계좌가 "&TEXT(수익률,"0.0%")&" 수익 구간입니다.", 수익률>=0, 고객명&"님 계좌는 "&TEXT(수익률,"0.0%")&"로 안정적으로 유지 중입니다.", TRUE, 고객명&"님 계좌 점검이 필요합니다. 연락 부탁드립니다.") =TEXTJOIN(CHAR(10), TRUE, 문구범위) ← 여러 줄 합치기(셀 서식: 텍스트 줄 바꿈)

고객 대상 문구는 준법감시 승인 문안을 벗어나지 않아야 합니다. 수익률·전망 표현, 광고성 정보 표기, 수신 동의 여부는 발송 전 컴플라이언스 기준을 확인하세요.

투자성향 적합성 체크

고객 투자성향 등급과 상품 위험등급을 대조합니다. 판매 전 확인 절차를 표에 내장하는 방식입니다.

=IF(XLOOKUP(고객코드, 고객[코드], 고객[성향등급]) <= XLOOKUP(상품코드, 상품[코드], 상품[위험등급]), "적합", "부적합 · 확인 필요")

등급 체계(숫자가 클수록 공격적/위험한지)는 사내 기준에 맞춰 부등호 방향을 반드시 확인하세요. 이 수식은 사전 점검용이며 정식 적합성 판단은 사내 시스템 결과를 따릅니다.

=SUMIFS(보유[금액], 보유[만기일], ">="&EOMONTH(TODAY(),n-1)+1, 보유[만기일], "<="&EOMONTH(TODAY(),n)) =TEXT(EDATE(TODAY(), SEQUENCE(1,12,0)), "yy년 m월") ← 가로 월 축

지점 영업 ③ 실적·수수료·목표 관리

월말에 몰아서 집계하지 말고, 남은 영업일 기준 필요 페이스를 매일 보이게 만드는 편이 실적에 도움이 됩니다.

기간 실적 집계

일·주·월 단위 약정과 수수료. 기준일 두 개만 셀로 두면 전부 연동됩니다.

=SUMIFS(실적[수수료], 실적[일자], ">="&$B$1, 실적[일자], "<="&$B$2, 실적[담당], $A2) =SUMIFS(실적[약정], 실적[일자], ">="&EOMONTH(TODAY(),-1)+1) ← 당월 누계 =SUMIFS(실적[수수료], 실적[일자], ">="&TODAY()-WEEKDAY(TODAY(),2)+1) ← 이번 주
목표 달성률 · 필요 페이스

남은 영업일로 나눈 하루 필요 실적이 가장 현실적인 관리 지표입니다.

=실적/목표 ← 달성률 =NETWORKDAYS(TODAY(), EOMONTH(TODAY(),0), 휴장일) ← 남은 영업일 =(목표-실적)/MAX(NETWORKDAYS(TODAY(), EOMONTH(TODAY(),0), 휴장일),1) ← 일 필요 실적 =실적/(목표*경과영업일/전체영업일) ← 페이스 대비 진척
증감률 — 전월비·전년동월비

0으로 나누는 경우를 반드시 막아둡니다.

=IF(전월=0, "", 당월/전월-1) ← MoM =IFERROR(당월/SUMIFS(실적[금액], 실적[연월], EDATE(기준월,-12))-1, "") ← YoY =TEXT(증감률, "[빨강]+0.0%;[파랑]-0.0%;0.0%")
상품별 수수료 산출

요율표를 시트로 분리하고 조회해서 곱합니다. 요율을 수식에 박으면 개정 때 전수 수정해야 합니다.

=약정금액 * XLOOKUP(상품군, 요율표[상품군], 요율표[요율]) =SUMPRODUCT(약정범위, 요율범위) ← 합산 =MAX(계산수수료, 최소수수료) ← 최저 수수료 적용

조건부 서식·표시형식·인쇄

값을 바꾸지 않고 보이는 방식만 바꾸는 영역입니다. 표시형식은 실제 값을 건드리지 않는다는 점을 늘 기억하세요.

조건부 서식 — 수식 규칙
홈 → 조건부 서식 → 새 규칙 → 수식

행 전체를 칠하려면 열만 고정($A2)하고 범위를 행 전체로 지정합니다. 이 한 가지 규칙만 알면 나머지는 응용입니다.

표시형식 코드
Ctrl+1 → 사용자 지정

네 구역 양수;음수;0;텍스트로 구성됩니다. 국내 관행대로 상승 빨강·하락 파랑을 지정할 수 있습니다.

[빨강]▲#,##0;[파랑]▼#,##0;- ← 등락 표기 [빨강]+0.00%;[파랑]-0.00%;0.00% ← 등락률 #,##0,,"백만" ← 1,234,000,000 → 1,234백만 #,##0"원" ← 단위는 붙이되 값은 숫자 유지 000-00-000000 ← 계좌번호 자릿수 고정 [>=100000000]#,##0,,,"억";#,##0 ← 조건부 단위 전환 ;;; ← 화면에서 값 숨기기

표시형식은 보이는 모양만 바꿉니다. Ctrl+Shift+~로 실제 값을 확인하세요. 반올림된 화면 값으로 합계를 검증하면 어긋납니다.

REPT — 문자 게이지

차트 없이 셀 안에 진척도를 그립니다. 목표 달성률 표에서 특히 잘 읽힙니다.

=REPT("■", ROUND(MIN(달성률,1)*10, 0)) & REPT("□", 10-ROUND(MIN(달성률,1)*10, 0))
