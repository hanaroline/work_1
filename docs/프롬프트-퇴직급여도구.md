## 7. 시스템 설정 — 지금 걸려 있는 것

### `.claude/settings.json`

```json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "$CLAUDE_PROJECT_DIR/.claude/hooks/session-start.sh"
          }
        ]
      }
    ]
  }
}
```

### `.claude/hooks/session-start.sh` 가 하는 일

웹 세션에서만 돈다(`CLAUDE_CODE_REMOTE=true` 일 때). 이 저장소는
`package.json` 과 `node_modules` 를 `.gitignore` 로 빼기 때문에, 새 세션에는
그것들이 **없다.** 화면 검사·수집기·PDF 만들기가 전부 playwright 를 부르므로
없으면 세션이 시작하자마자 막힌다. 그래서 미리 깐다.

- **playwright 1.56.1** — 워크플로가 박아 쓰는 판과 같게 맞춘다
- 이미 같은 판이 있으면 건드리지 않는다
- 크로미움은 `/opt/pw-browsers` 에 이미 있어 내려받지 않는다

**이 둘은 GitHub 에 커밋되어 있다 — 계정이 바뀌어도 따라온다.**

### 환경에 없는 것

| | 그래서 |
|---|---|
| WebKit(사파리 엔진) | 아이폰 동작을 확인할 수 없다 |
| Microsoft Excel | `.xlsx` 가 실제로 열리는지 확인할 수 없다 |
| 외부망(일부) | 국세청 계산 사례 원문을 확인할 수 없다 |

이 셋은 **사람이 확인해 주어야 하는 자리**다.

## 9. 쓸 때 알아 둘 것

- 지점 배포는 **`-internal` 이 안 붙은 쪽** (`retire-payout.html`)
- 화면 구분법: 판단표 탭 맨 아래에 **`근거` 접힘 상자가 있으면 내부용**
- 휴대폰: 안드로이드는 Chrome, **아이폰은 Documents (Readdle) 앱**
- 미리보기(메신저·파일 관리자)로는 동작하지 않는다 — 스크립트를 안 돌린다
