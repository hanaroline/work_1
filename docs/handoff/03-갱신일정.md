## 지킬 것

- 숫자는 build_earnings.py 에서만 바꾼다. HTML 에 손으로 적지 않는다.
- 확인 못 한 값은 None 으로 두고 consnote 에 사유를 적는다. 추정으로 채우지 않는다.
- FACTS·GRAISE_TXT·REJECTED·*_NOTE 도 같이 갱신한다. 카드 문장은 건드리지 않는다
  — 그 값들을 읽어 스스로 다시 쓰인다.
- EN·CN_EN 영문도 같이 고친다. 한/영 토글에서 한글이 남으면 안 된다.
- ASOF 는 내용이 바뀐 날, CHECKED 는 다시 확인한 날. 갈라서 쓴다.
