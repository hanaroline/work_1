## 2. 분기 갱신 (가장 자주 쓰는 것)

> 2026년 3분기 시즌용 프롬프트는 [`03-갱신일정.md`](03-갱신일정.md) 에
> 일정과 함께 따로 있습니다. 아래는 어느 분기에나 쓰는 일반형입니다.

```
2026년 3분기(캘린더) 실적 시즌으로 전면 갱신해줘.

규칙:
- 숫자는 scripts/build_earnings.py 에서만 바꾼다. HTML 에 손으로 적지 않는다.
- 밸류에이션(VAL·LTM·MCAP·EVEB)과 PEERS 는 한 제공사·같은 날짜로 한 번에 받는다.
  한 번에 못 받으면 블록 전체를 종전 날짜에 묶어 두고 LIMITS 에 사유를 적는다.
- 확인 못 한 값은 None 으로 두고 consnote 에 사유를 적는다. 추정으로 채우지 않는다.
- FACTS·GRAISE_TXT·REJECTED·*_NOTE 도 같이 갱신한다. 카드 문장은 건드리지 않는다.
- EN·CN_EN 영문도 같이 고친다.

빌드 → check_claims.py 검산 → 브라우저로 한/영 두 모드를 눈으로 확인한 뒤 보고해라.
```

## 5. 화면 확인 (눈으로 봐야 찾는 버그가 있습니다)

```

- 치환 안 된 {토큰}, NaN, undefined 가 있는지
- 차트 라벨이 겹치거나 잘리는 데가 있는지
- 표가 가로로 넘치는지 (영문 모드 특히)
- 인쇄 모드와 모바일(390px)에서 깨지는 데가 있는지
스크린샷을 찍어서 눈으로 확인한 뒤 보고해라.
```

## 프롬프트를 쓸 때 효과가 컸던 표현

실제로 결과가 달라졌던 문구들입니다.

- **"지어내지 마라 / 추정으로 채우지 마라"** — 날짜·기관명·회차를 만들어 내는 것을
  막습니다. 가장 효과가 큽니다.
- **"못 하면 그대로 보고해라"** — 억지로 채워 넣는 대신 한계를 드러내게 합니다.
- **"눈으로 확인한 뒤 보고해라"** — 스크린샷을 찍게 만듭니다. 라벨 겹침·표 넘침은
  코드만 봐서는 안 보입니다.
- **"손으로 적지 마라 / 데이터에서 읽게 해라"** — 문장이 묵는 것을 막는 핵심입니다.
- **"아직 고치지 마라"** — 먼저 읽고 진단만 시킬 때 씁니다.
- **"같은 식으로 나머지도"** — 한 군데를 고친 방식을 전체에 퍼뜨릴 때 씁니다.
  실제로 카드 → 각주 → 섹션 문구 → README 로 이어졌습니다.
