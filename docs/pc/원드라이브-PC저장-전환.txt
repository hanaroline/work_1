원드라이브 동기화 오류 정리 — 파일을 PC에만 저장하도록 바꾸기
작성: 2026-10-03

────────────────────────────────────────
1. 무슨 일이 있었나
────────────────────────────────────────
증상
  - 파일 탐색기에서 문서·바탕 화면·사진 폴더와 그 안의 파일에
    빨간 원 안의 × 표시가 붙음 (상태 칸)
  - 원드라이브가 "저장 공간이 꽉 찼다"는 경고를 띄움 (무료 한도 5GB)

원인
  - 원드라이브의 "폴더 백업" 기능이 켜져 있음.
  - 이 기능이 켜지면 바탕 화면·문서·사진 폴더의 실제 위치가
      C:\Users\사용자이름\OneDrive\  아래로 옮겨진다.
  - 그래서 "바탕 화면에 저장"해도 실제로는 원드라이브 폴더에 저장되고,
    자동으로 클라우드에 올라간다.
  - 5GB가 꽉 차서 더 올리지 못한 파일마다 빨간 ×가 붙은 것이다.

빨간 ×의 뜻
  - "클라우드에 올리지 못했다"는 뜻이다. 파일이 지워진 것은 아니다.
  - 해당 파일의 원본은 이 PC에만 있다.

화면에 같이 보인 것
  - 99796200, 878E4200, 6AA05650 처럼 확장자 없는 8자리 이름
      → 엑셀이 저장하다 남긴 임시파일로 보인다.
        엑셀이 비정상으로 꺼지면 이런 파일이 남는다.
  - "건강보험료_강의안_30p.pptx [복구].pptx"
      → 파워포인트가 비정상 종료 뒤 복구한 파일이다.

────────────────────────────────────────
2. 시작 전에 (권장)
────────────────────────────────────────
  - 중요한 파일(고객제안서, 강의안 등)은 USB 등에 한 번 따로 복사해 둔다.
  - 엑셀·파워포인트·워드를 모두 닫는다.

────────────────────────────────────────
3. PC에만 저장하도록 바꾸는 순서  ※ 순서를 꼭 지킬 것
────────────────────────────────────────
[1단계] 클라우드에만 있는 파일을 먼저 PC로 내려받기
  1) 파일 탐색기 왼쪽에서 "OneDrive" 폴더를 오른쪽 클릭한다.
  2) "항상 이 디바이스에 유지"를 선택한다.
  3) 모든 파일의 상태가 초록 체크(✓)가 될 때까지 기다린다.
     (빨간 × 파일은 이미 PC에만 있으니 그대로 둔다.)
  ※ 이 단계를 건너뛰면 클라우드에만 있던 파일이 PC에서 안 보이게 될 수 있다.

[2단계] 폴더 백업 끄기
  1) 작업표시줄 오른쪽 아래 구름 아이콘을 누른다.
  2) 톱니바퀴 → 설정 → "동기화 및 백업" → "백업 관리"로 들어간다.
  3) 바탕 화면·문서·사진을 모두 끄고(백업 중지) 확인한다.
  → 이후 새로 저장하는 파일은 PC의 원래 위치(C:\Users\사용자이름\Desktop 등)에 저장된다.

[3단계] 기존 파일을 PC 폴더로 옮기기
  - 백업을 끄면 바탕 화면이 비어 보일 수 있다.
    파일은 지워지지 않았고 원드라이브 폴더에 그대로 남아 있다.
  - 아래처럼 "잘라내기 → 붙여넣기"로 옮긴다.
      C:\Users\사용자이름\OneDrive\바탕 화면  →  C:\Users\사용자이름\Desktop
      C:\Users\사용자이름\OneDrive\문서       →  C:\Users\사용자이름\Documents
      C:\Users\사용자이름\OneDrive\사진       →  C:\Users\사용자이름\Pictures
  - "바탕 화면"과 "바탕 화면1"이 둘 다 있었다.
    예전에 한 번 꼬여서 둘로 나뉜 것으로 보이니 두 폴더를 모두 확인한다.

[4단계] (원하면) 원드라이브를 완전히 끊기
  - 구름 아이콘 → 설정 → 계정 → "이 PC 연결 해제"
  - 반드시 1~3단계를 마친 뒤에 한다.

[5단계] 오피스 기본 저장 위치도 PC로 바꾸기
  - 엑셀/파워포인트/워드 → 파일 → 옵션 → 저장
  - "기본적으로 컴퓨터에 저장"에 체크한다.

────────────────────────────────────────
4. 막힐 때
────────────────────────────────────────
  - 2단계의 "백업 중지" 버튼이 회색이라 누를 수 없을 때
      → 회사 IT 정책으로 폴더 백업이 강제된 경우다.
        IT 헬프데스크에 "OneDrive 알려진 폴더 이동(폴더 백업) 해제"를 요청한다.

  - 원드라이브가 계속 꼬일 때 (재설정 — PC의 파일은 지우지 않음)
      Win + R 을 누르고 아래를 입력한다.
        %localappdata%\Microsoft\OneDrive\onedrive.exe /reset
      1~2분 뒤에도 구름 아이콘이 다시 나타나지 않으면
      시작 메뉴에서 OneDrive를 직접 실행한다.

  - 8자리 이름의 임시파일 (99796200 등)
      → 엑셀을 모두 닫은 뒤 지워도 된다. 옮길 필요는 없다.
        크기가 큰 것은 지우기 전에 엑셀로 한 번 열어서
        저장하지 못한 작업이 들어 있는지 확인한다.

────────────────────────────────────────
5. 함께 권하는 것
────────────────────────────────────────
  - "한투 API 키.docx"처럼 API 키가 든 파일은 원드라이브 같은
    클라우드 동기화 폴더에 두지 않는다.
    클라우드에 이미 올라갔을 수 있다면 한국투자증권에서 키를 재발급받는 것도 고려한다.
