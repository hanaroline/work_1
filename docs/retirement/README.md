# 은퇴자산 운용 제안서 (2026-09-07)

만 57세 남성 고객 가구(총자산 19.38억)를 대상으로, 신규 주식 편입 없이 이자·배당·옵션프리미엄
으로 월 현금흐름을 만드는 인컴 중심 포트폴리오 제안서. 표지 포함 6페이지.

상품 선정은 **국내 상장 ETF 1,167종 실측 데이터**(분배율·총수익·총보수·순자산)에 근거한다.
데이터 출처는 같은 저장소의 `claude/etf-holdings-lookup-tool-wwtz57` 브랜치
`data/etf-kr.js` (네이버 수집 2026-09-07, 수익률 기준일 2026-09-04).

## 산출물

| 파일 | 내용 |
|---|---|
| `은퇴자산_운용제안서_2026-09-07.pptx` | 제안서 본체 (편집 가능한 네이티브 표·차트) |
| `etf_data.json` | 사용한 ETF 19종의 실측 지표 (원본에서 추출) |
| `model.py` | 자산·현금흐름·포트폴리오 수익률 계산 모델 |
| `make_claims.py` | 주장 대장 생성기 |
| `claims.json` | 주장 대장 — 인쇄된 모든 수치의 출처·검증 상태 (생성물) |
| `deck_data.json` | 슬라이드용 값 (생성물) |
| `build_deck.js` | 슬라이드 생성기 (pptxgenjs, 미래에셋 디자인 시스템) |

## 재현 방법

```bash
python3 model.py                 # 수치 확인
python3 model.py --export        # deck_data.json 생성
python3 make_claims.py           # claims.json 생성
python3 <fin-data-integrity>/scripts/check_claims.py claims.json   # 검산
node build_deck.js               # PPT 생성
```

`claims.json` 과 `deck_data.json` 은 생성물이다. 손으로 고치지 말고 `model.py` 를 고친다.

## 설계의 핵심

고객 제약 세 가지를 그대로 두고 설계했다.

- 은행 5년 정기예금 3.70억(연 5%)은 만기까지 인출하지 않는다
- 보유 국내·해외주식 2.40억은 매도하지 않는다
- 신규 주식 편입은 0 — 직접 주식 비중 12.4%는 전부 기존 보유분

남은 13.28억(DC 6.40 + IRP 0.88 + 증권현금 2.00 + 배우자 4.00)이 재배치 대상이다.

시점별 5단계: 재직기(2026.9~2029.6) → 은퇴 브리지(2029.7~2031) →
예금 만기·자녀 결혼(2031) → 인컴 자립기(2031~2034) → 국민연금 개시(2034~).

### 상품 선정 기준

1. 분배율이 아니라 **총수익(TR)** 으로 판정 — 1년 총수익이 마이너스인 상품은 고분배라도 배제·축소
2. 3년 실측 총수익이 있는 상품 우선
3. 순자산 1,000억 이상, 총보수 낮은 순
4. 고분배 상품은 분배금이 과세되지 않는 연금계좌에 우선 배치

기대 총수익률은 3년 실측 TR을 49~68% 수준으로 감액해 설정했고, 감액 근거는
`model.py` 의 `EXPECTED` 에 상품별로 남겼다.

### 실데이터가 바꾼 판단

- **미국 30년국채 커버드콜 3종은 분배율 13%대인데 1년 총수익이 모두 마이너스**
  (476550 -2.3% / 481060 -1.6% / 473330 -1.5%). 분배금의 상당 부분이 원금 반환이다.
  당초 2.55억을 배분했던 것을 0.60억으로 축소했다.
- 순수 미국 장기국채(484790 -2.2% / 453850 -2.4%)도 마이너스여서 대안이 되지 않았다.
- **국내 종합채권(AA-이상)도 1년 총수익 -6.1%.** 안전자산 슬리브를 종합채권 대신
  머니마켓(0043B0, 실측 TR 3.13%)과 만기매칭 회사채(0119H0)로 바꿨다.
- 당초 안전자산 슬리브로 검토한 **채권혼합형 커버드콜은 현재 상장 상품이 전부
  개별종목(팔란티어·테슬라) 기반**이어서 노후자산에 부적합하다고 판단해 제외했다.
- KODEX 미국배당커버드콜액티브(441640)는 분배율 9.38%에 3년 총수익 17.3%, 총보수
  0.19%로 같은 유형 중 가장 우수해 세 트랙 모두에 편입했다.

## 결과와 목표 갭

| 구간 | 전체 기대수익률 | 목표 7% 대비 |
|---|---|---|
| 현 시점 ~ 2031 | 6.82% | −0.18%p |
| 2031년 예금 만기 후 | 7.23% | +0.23%p |

**목표에 0.18%p 못 미치는 원인은 규제다.** 연금계좌 7.28억 중 2.20억(30.2%)을
안전자산으로 채워야 하고 이 슬리브의 기대수익률이 3.18%다. 위험자산 수준(7.90%)을
적용할 수 있다면 전체 +0.54%p로 목표를 넘는다.

억지로 목표를 맞추려면 총수익이 마이너스인 고분배 상품을 다시 담거나 기대수익률을
과거 실적 수준까지 낙관적으로 잡아야 하므로, 그렇게 하지 않고 갭과 원인을 명시했다.

월 현금흐름은 실측 분배율 기준으로 전 구간 필요액(750만원)을 충족한다
(Phase 1 여유 4만원 / Phase 3 여유 107만원 / Phase 4 여유 357만원).
연금계좌 인출이 전 구간 불필요하므로 과세이연을 계속 유지할 수 있다.

## 알려진 이슈

실측 분배율이 당초 가정보다 높아 현금흐름은 개선됐지만, 그만큼 과세대상 금융소득도 늘었다.
부부 일반계좌 금융소득이 연 합산 약 5,693만원으로 금융소득종합과세 기준(2,000만원)을
크게 넘는다. 부부 ISA 한도를 매년 소진하면 약 1,007만원을 과세대상에서 뺄 수 있지만
초과분이 남는다. 은퇴 후 다른 소득이 없으면 세금 자체보다 **건강보험료 지역가입자 전환
영향이 더 클 수 있어**, 은퇴 전 공단 모의계산이 필요하다.

일반계좌 분배율을 낮춰 과세소득을 줄이는 것은 가능하지만(예: 458730처럼 분배율 2.89%에
총수익이 높은 상품 비중 확대), 그러면 "월 현금흐름 창출" 이라는 이 제안서의 전제와
충돌한다. 현금흐름을 우선하고 세제 대응은 계좌 배치와 ISA로 처리하는 쪽을 택했다.

## v2에서 새로 확인한 데이터 함정

**펀드는 모(母)펀드 레코드가 아니라 판매 클래스로 봐야 한다.** 데이터셋의
`iM에셋 월지급 미국달러하이일드` 모펀드 레코드는 1년 수익률 9.58%인데, 실제 매수
가능한 클래스는 A 2.18% / C 1.77% / C-e 1.88% / S 3.19%였다. 모펀드 수치를 그대로
쓰면 투자자가 얻을 수 없는 수익률을 제안하게 된다. v2의 펀드 수익률·총보수는 전부
판매 클래스 기준이며, 이 사실을 5페이지 주석에 명시했다.

**ETF 3년은 연율, 펀드 3년은 누적이다.** ETF 데이터셋은 `etf_lib.mjs`에서 3년·5년을
연율로 환산해 저장한다(코드로 확인). 펀드 쪽은 저장소의 검증 스크립트가 기준을
판정하지 못했고(`fund_returns_verify2.md`: "3년 기준 갈리지 않음"), 국내채권형의
3년/1년 비율이 3.3~3.9로 나와 누적으로 판정했다. 두 계열을 섞지 않기 위해 펀드
3년을 연율로 환산해 인쇄했고, 환산식은 `claims_v2.json`의 `D_ANN_*` 파생 항목에서
검산한다.

## v2 검증 상태

`check_claims.py` 통과 (주장 148건 / 파생 25건).

**추가된 미확인 항목**

- 재간접형·이머징 채권형 펀드의 퇴직연금 안전자산 분류: 금융기관 내부기준에 따라
  갈릴 수 있어 매수 전 확인 필요
- 펀드 순자산: 모펀드 레코드의 순자산이 판매 클래스 규모를 대표하지 않아 인쇄하지 않음

**v2에서 늘어난 리스크**
이머징 채권·아시아 하이일드 편입으로 신용·환 리스크가 커졌다. 해외채권 펀드 비중을
신규 운용자산의 21.5% 이내로 유지하고 반기 1회 재점검하는 것을 전제로 한다.
펀드 총보수(0.22~1.05%)는 ETF(0.01~0.39%)보다 높아, 같은 전략에 더 싼 클래스가
있으면 교체해야 한다.
