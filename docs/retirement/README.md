# 은퇴자산 운용 제안서 (2026-09-07)

만 57세 남성 고객 가구(총자산 19.38억)를 대상으로, 신규 주식 편입 없이 이자·배당·옵션프리미엄
으로 월 현금흐름을 만드는 인컴 중심 포트폴리오 제안서. 표지 포함 6페이지.

## 산출물

| 파일 | 내용 |
|---|---|
| `은퇴자산_운용제안서_2026-09-07.pptx` | 제안서 본체 (편집 가능한 네이티브 표·차트) |
| `model.py` | 자산·현금흐름·포트폴리오 수익률 계산 모델 |
| `claims.json` | 주장 대장 — 슬라이드에 인쇄된 모든 수치의 출처·검증 상태 |
| `build_deck.js` | 슬라이드 생성기 (pptxgenjs, 미래에셋 디자인 시스템 적용) |

## 재현 방법

```bash
python3 model.py                                    # 수치 재계산
python3 <fin-data-integrity>/scripts/check_claims.py claims.json   # 대장 검산
node build_deck.js                                  # PPT 재생성
```

## 설계의 핵심

고객 제약 세 가지를 그대로 두고 목표 연 7%를 맞춘 구조.

- 은행 5년 정기예금 3.70억(연 5%)은 만기까지 인출하지 않는다
- 보유 국내·해외주식 2.40억은 매도하지 않는다
- 신규 주식 편입은 0 — 직접 주식 비중 12.4%는 전부 기존 보유분

남은 13.28억(DC 6.40 + IRP 0.88 + 증권현금 2.00 + 배우자 4.00)만으로 연 7.38%를 내야
전체 7%가 성립하며, 설계안의 가중 기대수익률은 7.39%(전체 7.01%)다.

시점별 5단계로 구성: 재직기(2026.9~2029.6) → 은퇴 브리지(2029.7~2031) →
예금 만기·자녀 결혼(2031) → 인컴 자립기(2031~2034) → 국민연금 개시(2034~).

## 검증 상태

`check_claims.py` 통과 (주장 42건 / 파생 25건). 다만 다음은 **미확인 항목**으로,
슬라이드에서 단정하지 않고 표기했다.

**확인된 것**
- 자산·지출·연금 금액: 고객 제공 자료(2026-09-07)
- ETF 종목코드 7건: 2개 이상 출처 교차확인. 특히 TIGER 종합채권(AA-이상)액티브는
  451540이며 356540(ACE 종합채권)과 다른 상품
- 세제: 이연퇴직소득 연금수령 시 퇴직소득세율의 70%(10년차까지)/60%(11년차~),
  사적연금 1,500만원 기준, 금융소득종합과세 2,000만원 기준, DC·IRP 안전자산 30% 의무

**미확인 (실행 전 확인 필요)**
- ETF 분배율: 발행사 1차 페이지가 네트워크 정책상 접근 불가(egress 차단)해 집계 사이트
  스니펫에 의존. 집계 기준일이 명시되지 않은 건이 3건(458760·476550·329200)
- 채권혼합형 커버드콜 ETF의 퇴직연금 위험자산 분류: 증권사 내부기준에 따라 달라짐
- 2026-08-31 퇴직연금감독규정 개정의 시행일·대상 상품 범위: 금융위 보도자료 접근 실패
- ISA 2026년 납입한도 개정 여부
- 사적연금 인출액의 건강보험료 부과 여부: 공단 1차 자료 미확인이므로
  "부과되지 않는다"고 쓰지 않고, 건보료 영향 사전 점검을 실행 항목으로만 기재

**가정 (보장 아님, 슬라이드에 '가정'으로 표기)**
- 보유 주식 기대 총수익률 8.00%, 현금배당률 1.50%
- DC 대기성 현금 2.50%
- 상품별 기대수익률·현금분배율 (트랙 A 7.25% / B 7.98% / C 7.36%)
- 은행예금 만기: 가입 시점 미확인. 자녀 결혼 시점과 일치한다는 고객 진술에 따라 2031년,
  단리·이자소득세 15.4% 차감 기준으로 원리금 4.48억 산정

## 알려진 이슈

설계안대로 실행하면 부부 일반계좌 금융소득이 연 합산 약 5,170만원으로
금융소득종합과세 기준(2,000만원)을 넘는다. 부부 각자 ISA 납입한도를 매년 소진하는
조치를 제안서에 포함했으나, 이전 가능액이 은퇴 전 약 1.13억으로 제한되어
초과분을 완전히 해소하지는 못한다. 세율·건보료 최적화를 더 밀어붙이면
목표 7%와 상충하므로, 목표 달성을 우선하고 이슈를 명시하는 쪽으로 정리했다.
