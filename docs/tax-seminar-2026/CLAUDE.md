# 작업 규칙 — 2026 세제 세미나 자료

이 폴더의 자료를 다룰 때는 먼저 `HANDOFF.md`를 읽으십시오. 재사용 스크립트와 환경 설정은 `PROMPTS.md`에 있습니다.

## 반드시 지킬 것

1. **pptx는 zip을 다시 만들지 말고** 대상 슬라이드 XML만 문자열 치환해 재압축한다. 서식·네이티브 차트·레이아웃이 보존된다.
2. 치환 전 `old` 문자열이 **정확히 1회** 나타나는지 단언한다.
3. 수정한 슬라이드는 **반드시 PNG로 렌더링해 눈으로 확인**한다. 좌표 기반 자동 검사만으로는 겹침을 못 잡는다.
4. 조문 근거를 찾지 못하면 수치를 고치지 말고 **주의 문구만** 추가한다.
5. 블로그·요약 기사로 수치를 확정하지 않는다. 부처 보도자료·법령·고시가 우선이다.
6. `HANDOFF.md` §5 "바꾸지 말 것" 목록은 **이미 검증을 마친 항목**이다. 다시 고치지 않는다.
7. `HANDOFF.md` §6 소득월액 산식은 과거에 한 번 틀렸던 지점이다. 손대기 전에 반드시 읽는다.

## 환경

`apt-get update` 를 먼저 하지 않으면 `libreoffice-impress` 설치가 404로 실패한다.
impress 없이는 pptx가 열리지 않고 `source file could not be loaded` 만 나온다.
