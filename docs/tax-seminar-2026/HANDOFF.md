### 2차 — 렌더링 검수 + 최신화 (11건)

## 6. ⚠️ 과거에 한 번 틀렸던 지점 — 재발 주의

**건강보험 소득월액 산식 (d3 p.7).** 1차 수정에서 평가율 곱하는 순서를 바꿨다가 2차에서 되돌렸습니다.

```
올바른 식 (국민건강보험법 제71조):
  소득월액 = ( 연간 보수 외 소득 − 2,000만원 ) × 1/12 × 소득평가율
  → 2,000만원을 먼저 빼고, 12로 나누고, 평가율은 마지막
잘못된 식 (절대 쓰지 말 것):
  소득월액 = ( 보수 외 소득 × 소득평가율 − 2,000만원 ) × 1/12
```
소득평가율: 이자·배당·사업·기타 100%, 근로·연금 50%.
같은 슬라이드의 계산 실습 `(5,000만 − 2,000만) ÷ 12 = 250만원` 이 검증 기준입니다.

지역가입자는 식이 다릅니다 — 2,000만원 공제 없이 `연소득 × 평가율 ÷ 12 × 요율`.

## 7. 재현 가능한 검증 절차

`PROMPTS.md`의 "환경 재구축"과 "재사용 스크립트"를 그대로 쓰면 됩니다. 요지:

1. `apt-get update && apt-get install -y libreoffice-impress fonts-noto-cjk` — **update를 먼저 하지 않으면 404로 실패**
2. pptx → PDF → PNG 렌더링 후 **육안 검수** (자동 검사만으로는 겹침을 못 잡음)
3. 좌표 기반 넘침 검사기는 **오탐이 많음**(불릿 글리프 겹침 등). 1.4배 이상만 실제 결함일 확률이 높고,
   최종 판정은 반드시 렌더 이미지로 함
4. 수정은 **원본 zip을 풀지 않고** 대상 슬라이드 XML만 문자열 치환 후 재압축 —
   서식·네이티브 차트·레이아웃이 100% 보존됨
5. 치환 전 `count(old) == 1` 단언으로 오치환 방지
