# 베타 판

여기 있는 것은 **정식 브리핑이 아닙니다.** 레이아웃·구성·분량을 바꿔 본
시안이고, 쓸지 말지는 아직 정해지지 않았습니다.

## 정식판과 무엇이 다른가

| | 정식 (`docs/briefings/`) | 베타 (`docs/briefings/beta/`) |
|---|---|---|
| 파일 이름 | `<날짜>-<판>.html` | `<날짜>-<판>-beta.html` |
| `index.json` | 오릅니다 | **오르지 않습니다** — 사이드바를 건드리지 않으려고 |
| 사이드바 「지난 브리핑」 | 나옵니다 | 나오지 않습니다 |
| 아티팩트 | 날짜마다 하나 | 따로 냅니다. 제목에 「베타」를 답니다 |
| 예약 Routine | 매일 만듭니다 | **자동으로 만들지 않습니다.** 요청이 있을 때만 |
| 고객에게 | 건넵니다 | **건네지 마십시오** |

## 규칙 셋

1. **정식판을 건드리지 마십시오.** 베타를 만들다 공용 스크립트
   (`inline_notes` · `fold_perf` · `print_fit` · `build_archive_nav`)를
   고쳐야 하면, 정식판에서도 돌려 보고 결과가 같은지 확인한 뒤에 고칩니다.
2. **검증은 정식판과 똑같이 받습니다.** 시안이라고 느슨하게 내면 비교가
   안 됩니다 — 폭 훑기·중복·JS·열 수와 `recheck.py`·`audit_numbers.py` 를
   모두 통과해야 합니다.
3. **정식으로 올릴 때**는 파일을 `docs/briefings/` 로 옮기고 이름에서
   `-beta` 를 떼고 `index.json` 에 넣은 뒤 `build_archive_nav.py` 를
   돌립니다. 그때 이 폴더의 같은 날짜 파일은 지웁니다.

## 지금 시안이 담고 있는 것

`docs/briefing-review.md` 의 여섯 가지 안 가운데 넷을 넣었습니다.

- 죽어 있던 오른쪽 340px 패널을 걷어내고 본문을 넓혔습니다
- 세 층으로 나눴습니다 — 판단 / 본문 / 근거
- 접는 기준을 「오늘의 축에 필요한가」로 바꿨습니다
- 증권업·미래에셋증권 동향 절을 새로 넣었습니다
- 외국계 IB 언급을 1층에 한 줄 목록으로 세웠습니다

절 순서 재배치는 **넣지 않았습니다** — 위험이 커서 따로 판단하실 일입니다.
