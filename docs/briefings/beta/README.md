# 베타 판

여기 있는 것은 **정식 브리핑이 아닙니다.** 레이아웃·구성·분량을 바꿔 본
시안이고, 쓸지 말지는 아직 정해지지 않았습니다.

## 정식판과 무엇이 다른가

| | 정식 (`docs/briefings/`) | 베타 (`docs/briefings/beta/`) |
|---|---|---|
| 파일 이름 | `<날짜>-<판>.html` | `<날짜>-<판>-beta.html` |
| `index.json` | 오릅니다 | **오르지 않습니다** — 사이드바를 건드리지 않으려고 |
| 사이드바 「지난 브리핑」 | 나옵니다 | 나오지 않습니다 |
| 아티팩트 | 날짜마다 하나 | 따로 냅니다. 제목에 「베타」를 답니다 |
| 예약 Routine | 매일 만듭니다 | **자동으로 만들지 않습니다.** 요청이 있을 때만 |
| 고객에게 | 건넵니다 | **건네지 마십시오** |

## 규칙 셋

1. **정식판을 건드리지 마십시오.** 베타를 만들다 공용 스크립트
   (`inline_notes` · `fold_perf` · `print_fit` · `build_archive_nav`)를
   고쳐야 하면, 정식판에서도 돌려 보고 결과가 같은지 확인한 뒤에 고칩니다.
2. **검증은 정식판과 똑같이 받습니다.** 시안이라고 느슨하게 내면 비교가
   안 됩니다 — 폭 훑기·중복·JS·열 수와 `recheck.py`·`audit_numbers.py` 를
   모두 통과해야 합니다.
3. **정식으로 올릴 때**는 파일을 `docs/briefings/` 로 옮기고 이름에서
   `-beta` 를 떼고 `index.json` 에 넣은 뒤 `build_archive_nav.py` 를
   돌립니다. 그때 이 폴더의 같은 날짜 파일은 지웁니다.

## 지금 시안이 담고 있는 것

`docs/briefing-review.md` 의 여섯 가지 안을 **모두** 넣었습니다.

- 죽어 있던 오른쪽 340px 패널을 **마크업·스크립트·CSS 까지 걷어냈습니다.**
  숨기기만 하면 낭독기에는 그대로 읽히고, 표를 누를 때마다 없는 패널을

- 외국계 IB 언급을 1층에 한 줄 목록으로 세웠습니다
- **절 차례를 다시 세웠습니다** — 축(금리·환율·원자재) → 마감(미·유·아·한)

  국내가 지역 끝에 오는 것은 지침 7-3 의 「국내는 되짚기」와 같습니다.

### 요약 PDF 를 고르는 방식

전에는 3층만 뺐습니다 — 27쪽이 19쪽이 되었을 뿐입니다. 이제는 절마다
`data-brief` 를 달아 **그날의 축을 말하는 데 필요한 절만** 싣습니다.
«요약 PDF» 단추를 누르면 `body.brief-print` 가 붙고 `data-brief="0"` 이
인쇄에서 빠집니다. 화면과 «전체 PDF» 는 그대로입니다 — **지우는 것이
아니라 요약본에서만 빼는 것**입니다. 목차에서 &bull; 가 붙은 절이
요약본에 실리는 절입니다.

「일정」은 요약본에서 뺐습니다. 17건짜리 표가 1.3쪽인데 요약본에 필요한
세 건은 이미 1층 판단의 ③에 이름까지 적혀 있습니다.

### 증권회사 동향 절 — 무엇을 싣고 무엇을 빼는가

「증권업계 동향은 **증권회사**의 동향」이라는 주문에 맞춰, 업권 제도가
아니라 회사가 주인입니다.

- **수치가 뼈대입니다** — 미래에셋증권과 동종 6곳의 주가·기간 수익률,
  증권 업종 등락률. 메리츠증권(008560)은 메리츠금융지주로 합병돼
  상장폐지라 뺐습니다(야후 404).
- **기사는 `kind=about` 만** — 회사가 한 일(주관·인수·제재·인사)과
  회사의 사업이 가는 방향(퇴직연금·자산관리·IB 등). 동종은 회사별로
  묶습니다.
- **뺀 것을 절 안에 밝힙니다** — 그 회사 연구원을 논평자로 인용했을 뿐인
  시황·종목 기사 건수를 적어 둡니다. 그 회사가 *낸* 의견이지 그 회사의
  *동향*이 아닙니다.
- **업권 전반 갈래는 이 절에서 뺐습니다.** 8/22 자료로 시험해 보니 두 건이
  나왔는데 하나는 위의 NH 회사 기사였고 하나는 「금융투자업계에 따르면 …
  증권사 7곳」 — 출처를 대는 말투였습니다.
