 0. 계정을 바꾸면 무엇이 넘어가고 무엇이 안 넘어가는가   ★ 먼저 읽으십시오
-------------------------------------------------------------------------------

결론 : GitHub 저장소에 커밋된 것은 전부 넘어옵니다. Claude 계정에 묶인 것은 안 넘어옵니다.

[ 넘어온다 ] — 새 계정을 같은 GitHub(hanaroline/work_1)에 연동하면 그대로
  - 완성 파일        irp-proposal.html
  - 인계 문서        docs/handover/IRP제안서-인계.md
  - 이 평문 사본     docs/handover/IRP제안서-프롬프트와설정.txt
  - 저장소 전체 규칙 CLAUDE.md, README.md
  - 세션 준비 설정   .claude/settings.json, .claude/hooks/session-start.sh

[ 안 넘어온다 ] — 옛 계정 소유
  - 과거 대화 기록·프롬프트   → 이 파일과 인계 문서가 그 자리를 대신합니다
  - 예약(Routine)             → 저장소에 없습니다. 필요하면 새 계정에서 다시 만드십시오
  - 발행한 Gamma 링크 주소    → HTML 은 저장소에 멀쩡. 잃는 것은 Gamma 링크뿐

즉, "과거 프롬프트·작업내용·완성파일이 그대로 계승되느냐"의 답은:
  완성파일·작업규칙·인계문서  → 예 (GitHub 에 있으니 그대로)
  대화기록·예약·Gamma 링크    → 아니오 (계정에 묶임 → 이 문서들로 복원)

 3. 프로젝트 지침 (이 저장소에서 꼭 지키는 것)
-------------------------------------------------------------------------------

 - 날짜·숫자를 지어내지 않는다. 제도 수치는 사실, 상품·보수·수익률은 "예시".
 - 화면은 단일 HTML, CSS·JS 인라인. 파이썬은 표준 라이브러리만.
 - 작업은 claude/... 가지에서, main 에는 병합으로.
 - 시세·브리핑 자료는 GitHub Pages 로 공개하지 않는다(pages.yml 지침).
 - 비밀·API 키는 저장소 파일에 넣지 않는다(GitHub Actions Secrets 만).
 - 미래에셋 브랜드 산출물은 anthropic-skills:mas-design 기준을 따른다
   (오렌지 #F58220 / 블루 #043B72, 1px 오렌지 룰, FAB072 테이블 헤더).
 - 브라우저가 필요하면 playwright 1.56.1, 크로미움은 /opt/pw-browsers 에 이미 있음
   (playwright install 다시 부르지 않는다).

 4. 시스템 설정 메모
-------------------------------------------------------------------------------

 - 테마 저장 키 : localStorage 'irp-theme' (값 'dark' | 'light')
 - 외부 의존성  : Google Fonts (Noto Sans KR, Inter) — 그 외 자급자족
 - 인쇄        : @media print 로 토바 숨김 + 색 보존(print-color-adjust: exact)
 - 커밋 트레일러(이 저장소 관례) :
     Co-Authored-By: Claude <noreply@anthropic.com>
   (모델 식별자는 커밋·코드·푸시 산출물에 넣지 않습니다. 대화에서만.)
 - 작업 가지 예 : claude/ipr-account-products-akf151
