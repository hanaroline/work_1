# 사용자 PC 환경 — 산출물을 건넬 때 알아 둘 것

마지막 갱신 2026-10-01 · 확인한 날 2026-09-18~19.

이 파이프라인은 **엑셀·워드 파일을 만들어 사람에게 건넵니다**
(`고객제안서_월배당ETF.xlsx`, `고객제안서_자산배분.xlsx`,
`고객제안서_자산배분_매크로.xlsm`). 받는 PC 에 제약이 있는데, 그것을 모르면
«왜 안 열린다는 거지» 로 시간을 버립니다. 실제로 한 차례 그랬습니다.

## 2. 그래서 산출물을 만들 때 지킬 것 ★

### 2-1. `.xlsm`(매크로 판)을 **유일한 산출물로 두지 않습니다**

Office 가 막히면 대안은 LibreOffice Calc 인데, **VBA 매크로는 거기서 거의
돌지 않습니다.** `고객제안서_자산배분_매크로.xlsm` 만 있고 매크로 없는 판이
없으면 그 시점에 쓸 수 없는 파일이 됩니다.

**매크로 없는 `.xlsx` 판을 항상 함께 유지하십시오.** 지금은 그렇게 돼 있습니다
(`고객제안서_자산배분.xlsx`).

### 2-2. HTML 판을 유지하는 까닭이 하나 더 있습니다

`docs/etf-proposal.html` 같은 HTML 판은 **브라우저만 있으면 열립니다.**
오피스 인증·라이선스와 무관합니다. 엑셀 판이 막히는 날에도 고객 전달은
됩니다 — 「엑셀은 담당자, HTML 은 고객」이라는 기존 구분에 **이 이유를
덧붙여** 두십시오.

두 판의 셈이 어긋나면 안 되므로 `scripts/check_etf_html.mjs` 가 원 단위까지
맞춰 봅니다. 그 검사기를 빼지 마십시오.

### 2-3. 파일을 건넬 때 저장 위치를 **`C:\Users\theli\Documents` 로** 안내합니다

바탕 화면은 OneDrive 폴더라, 저장할 때마다 업로드가 끝나기를 기다립니다.
**멈춘 것처럼 보일 만큼 느립니다.** `문서` 폴더는 로컬이라 즉시 저장됩니다.

## 3. 겪은 증상과 그 원인 — 같은 길로 다시 들어가지 않도록

2026-09-18~19 에 「엑셀·워드가 저장이 안 된다」로 한참을 헤맸습니다.
**원인이 둘이었고, 하나로 착각해 두 번 잘못 짚었습니다.** 판정 순서를
적어 둡니다.

### 증상

- 저장하려 하면 **「로그인」 창**이 뜨고, 「계정을 찾지 못했습니다 / 네트워크
  문제로 오류가 발생했습니다」가 함께 나옴
- Word 상단에 **「업로드 실패 — 이 위치에 변경 내용을 업로드하려면
  로그인해야 합니다」** 노란 막대
- 작업 표시줄에 **Microsoft Office 업로드 센터** 아이콘이 떠 있고 실패 항목이 쌓임

### 판정 순서 (이대로 하면 한 번에 갈립니다)

1. **다른 폴더에 저장해 봅니다.** `C:\Users\theli\Documents` 에 저장해 보십시오.
   - **거기는 되고 다른 곳은 안 된다 → 폴더 문제**(OneDrive). 2번으로.
   - **어디에 저장해도 똑같이 막힌다 → 오피스 인증 문제.** 4절로.
2. 안 되는 폴더의 경로를 봅니다. **경로에 `OneDrive` 가 들어 있으면** 그것이 원인입니다.
   - 탐색기 왼쪽 `바탕 화면` 우클릭 → **속성 → 위치** 탭에서 실제 경로를 봅니다.
   - 탐색기 「홈」 화면의 **「로컬에 저장됨」 표시는 믿을 것이 못 됩니다** —
     실제로는 OneDrive 로 리디렉션돼 있는데 그렇게 적혀 있었습니다.
     **행동으로 판정하십시오**(저장이 되는가, 안 되는가).
3. OneDrive 에 로그인하면 그 폴더에도 저장이 됩니다. 다만 **느립니다**(3절 끝).

### 두 번 잘못 짚은 것 — 기록해 둡니다

- 처음에 **OneDrive 문제로만** 보았습니다. Excel 제목의 `(제품 인증 실패)` 를
  놓쳤습니다.
- 그 뒤 **인증 문제로만** 보았습니다. 그런데 `Documents` 에는 정상 저장됐습니다
  — 인증이 저장을 막고 있었다면 어느 폴더든 막혔어야 합니다.
- **결론: 저장을 막고 있던 것은 OneDrive 였고, 인증 실패는 따로 떠 있는
  별개의 시한폭탄이었습니다.** 둘을 갈라 보지 않으면 계속 헛짚습니다.

### 한국투자증권 API 키와는 **무관합니다**

시점이 겹쳐 「API 키 발급 뒤부터 그런 것 같다」는 의심이 있었으나, API 키는
웹에서 받는 문자열일 뿐 PC 설정을 건드리지 않습니다. **인과가 없습니다** —
다시 의심하지 마십시오.

## 4. 그 PC 에 적용해 둔 설정

사용자가 직접 적용했습니다. 새로 안내할 일이 있으면 이것을 기준으로 하십시오.

### Excel · Word · PowerPoint 각각 (프로그램마다 따로 있습니다)

**파일 → 옵션 → 저장**

| 항목 | 설정 |
|---|---|
| 파일을 열거나 저장할 때 **Backstage 표시 안 함** | ☑ 켬 — 로그인을 요구하던 파란 화면을 건너뜁니다 |
| **로그인이 필요하더라도 추가 저장 위치 표시** | ☐ 끔 |
| 기본적으로 **컴퓨터에 저장** | ☑ 켬 |
| 기본 로컬 파일 위치 | `C:\Users\theli\Documents` |

> **「기본 로컬 파일 위치」에는 찾아보기 단추가 없는 판이 있습니다.** 칸을 비우고
> 경로를 **직접 타이핑**해야 합니다. 찾아보기로 하려다 안 된다고 본 것이
> 그 때문입니다.

### 알아 둘 동작

- **`Ctrl+S` 로 저장창이 안 뜨는 것은 정상입니다.** 이미 저장된 적 있는 파일은
  조용히 덮어씁니다. 위치를 고르려면 **`F12`**(다른 이름으로 저장)입니다.
- 저장창 왼쪽 **즐겨찾기**에 `Documents` 를 고정해 두었습니다
  (폴더 우클릭 → 즐겨찾기에 고정).
- Office 업로드 센터: 실패 항목은 **동작 → 복사본 저장**으로 먼저 꺼낸 뒤
  **동작 → 삭제**합니다. 알림 세 가지를 꺼 두면 아이콘이 사라집니다.

| 디스크 여유 13% | 지켜볼 것. 10% 아래로 가면 OneDrive 동기화가 눈에 띄게 느려집니다 |

**대비해 두십시오.** 인증이 끝내 막히면 받는 쪽은 LibreOffice Calc 로
`.xlsx` 를 열게 됩니다. 그때 깨지지 않도록 산출물을 **매크로 없이, 평범한
수식과 서식으로** 유지하는 것이 2-1 의 요지입니다.
