# 계정 이전 체크리스트

쓰던 Claude 유료 계정을 끝내고 새 계정에서 이어 갈 때의 실행 순서.

> **핵심: GitHub 저장소에 커밋된 것만 넘어온다.**
> "GitHub를 연동하면 과거 프롬프트·작업내용도 계승된다"는 **사실이 아니다.**
> 대화 기록은 Claude 계정에 묶여 있어 계정을 바꾸면 사라진다.

## 2. 스킬 — 가장 놓치기 쉬운 것 ★

이 프로젝트는 두 스킬에 의존한다.

| 스킬 | 역할 | `CLAUDE.md` 근거 |
|---|---|---|
| `fin-data-integrity` | 숫자 들어가는 자료의 검산 절차 | 2절 (금소법) |
| `mas-design` | 미래에셋 브랜드 색·폰트·레이아웃 | 4절 (평판) |

**둘 다 계정에 설치된 것이라 새 계정에서는 없다.** 없는 채로 작업하면
`CLAUDE.md` 규칙을 지킬 수 없다.

**권장: 저장소 `.claude/skills/` 로 옮겨 커밋한다.** 그러면 계정과 무관하게
저장소를 따라다닌다. 이번 이전을 계기로 정리해 두면 다음에 같은 문제가 없다.
(옮기지 않을 거면 새 계정에서 같은 스킬을 다시 추가할 것)

## 3. 새 계정 설정 순서

1. **새 계정 생성 · 유료 플랜 등록**
   (Cowork는 유료 플랜 전용. 웹에서는 사이드바가 아니라 **홈 화면**에서 시작)

2. **GitHub 연동**
   - claude.ai 설정 → 커넥터 → GitHub 연결
   - 연결이 안 되면: <https://claude.ai/connect-github>

3. **Claude GitHub App을 저장소에 설치**
   - <https://github.com/apps/claude/installations/select_target>
   - `hanaroline/work_1` 에 접근 권한 부여

4. **스킬 복구** — 2절 참고

5. **커넥터 재연결** — 쓰던 것만 (Gmail, Gamma 등)

6. **예약(Routine) 재생성**
   - 지시문 전문: `시스템설정-백업.md` 2절
   - 평일 11:00 KST = cron `0 2 * * 1-5` (UTC 기준)
   - **09:25 아침 배포는 만들지 않는다** (껐던 이유는 해당 문서에)

7. **첫 대화 시작**
   - 첫 말: `자주쓰는-프롬프트.md` 3절
   - Claude Code 세션은 `CLAUDE.md` 를 자동으로 읽는다

## 5. 설정 후 검증

새 계정 첫 세션에서 이것들이 되는지 확인한다.

```bash
# 저장소가 붙었는가
git log --oneline -3

# 훅이 도는가 (세션 시작 시 "준비 끝" 출력)
# 수집이 도는가 — 워크플로 수동 실행
```

- Claude가 `CLAUDE.md` 를 읽고 있는가 → "이 저장소 작업 수칙 요약해줘"로 확인
- `fin-data-integrity` 가 동작하는가 → 숫자 들어간 자료를 만들어 보고 검산 단계가 뜨는지
- 예약이 제 시각에 도는가 → 첫 평일 11:00 결과 확인

  `git -c core.quotepath=false ls-files` 를 쓸 것. (이것 때문에 한 번 오판한 적이 있다
