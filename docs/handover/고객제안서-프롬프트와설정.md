## 3. 갱신을 시킬 때 — **이 말을 꼭 붙이십시오** ★

유니버스는 자료 가지를 안 받으면 **끝상태 0 으로 조용히 비어버립니다**
(운영인계 4절). 그래서 시킬 때 확인을 함께 요구합니다.

```
제안서 최신치로 업데이트해줘.
단, 유니버스를 다시 모은 뒤 자산군별 종목수를 반드시 보여주고,
0 종인 자산군이 하나라도 있으면 커밋하지 말고 멈춰줘.
기준선은 펀드 약 1,050 · 국내주식 100 · 해외주식 100 · 국내ETF 247 · 해외ETF 19 야.
```

## 4. 거드는 말 — 상황별

### 수치의 근거를 물을 때
```
이 숫자 어디서 온 거야? 실측이야 가정이야?
```
> 받는 쪽은 `src` 와 `asOf` 를 들어 답해야 합니다. 「아마 …일 것입니다」로
> 답하면 안 됩니다.

### 기대수익률을 넣을 때
```
기대수익률은 ○○% 로 놓고 보여줘. 이게 가정이라는 걸 화면에도 적어줘.
```

### 상품 순서가 이상해 보일 때
```
왜 이 순서야? 무엇으로 줄 세운 건지 식을 적어줘.
```

### 도넛과 실제 노출이 달라 보일 때
```
포장지 말고 실제 노출로 다시 보여줘.
```

### 되돌려야 할 때
```
방금 것 되돌려줘. git checkout 으로 원래 파일로 돌려놔줘.
```

## 5. 이 사람과 일할 때의 결

브리핑 쪽 문서(`자주쓰는-프롬프트.md` 5절)와 같습니다. 제안서에서 특히 센 것만:

- **지어낸 숫자를 가장 싫어합니다.** 모르면 빈칸으로 두고 빈칸이라고 말합니다.
- **근거의 등급을 갈라서 말합니다.** 실측인지 가정인지, 언제 기준인지.
- **틀렸으면 틀렸다고 적습니다.** 길게 자책하지 않고 바로 고칩니다.
- **먼저 묻기보다 먼저 재어 봅니다.** 「이렇게 하면 어떨까?」에는 짐작이 아니라
  실제로 돌려 본 숫자로 답합니다.
- 작업이 끝나면 **무엇이 바뀌었는지 표로** 한 번 보여 줍니다.

## 6. 저장소 설정 — 그대로 넘어옵니다

### 6-1. `.claude/settings.json`

```json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "hooks": {
    "SessionStart": [
      { "hooks": [ { "type": "command",
        "command": "$CLAUDE_PROJECT_DIR/.claude/hooks/session-start.sh" } ] }
    ]
  }
}
```

### 6-2. `.claude/hooks/session-start.sh` 가 하는 일

- 웹 세션(`CLAUDE_CODE_REMOTE=true`)에서만 돕니다.
- `playwright 1.56.1` 을 깝니다 (워크플로가 박아 쓰는 판과 같게).
- **브라우저는 내려받지 않습니다** — `/opt/pw-browsers` 에 이미 있습니다.
- 파이썬 쪽은 표준 라이브러리만 쓴다고 적혀 있지만, **제안서 엑셀은 예외로
  `openpyxl` 이 필요합니다.** 훅이 깔아 주지 않으므로 손으로 깝니다.

```bash
pip install openpyxl
```
