## 1. 무엇을 만들었나

고객·내부 검토용 **단일 HTML 제안서**입니다. CSS·JS 인라인, 외부 의존성은
Google Fonts(Noto Sans KR·Inter)뿐이고 그 외엔 자급자족합니다.

- 파일: **`irp-proposal.html`** (저장소 루트, 약 24KB)
- 성격: **투자권유가 아닌 자산배분 가이드**. 상품명·보수·수익률은 모두 예시로 명시.
- 디자인: 미래에셋 브랜드(오렌지 `#F58220` / 블루 `#043B72`), 1px 오렌지 섹션 룰,
  FAB072 테이블 헤더 — `anthropic-skills:mas-design` 스킬 기준을 따름.
- 라이트/다크 토글(`localStorage` 키 `irp-theme`) + 인쇄용 CSS(`@media print`)로
  브라우저에서 바로 PDF 저장 가능. 저장소의 다른 화면과 같은 관례.

## 2. 반드시 지켜야 할 내용 규칙 (숫자·규제)

제안서의 **규제 수치는 사실**, **상품·보수·수익률은 예시**입니다. 이 경계가 흐려지면 안 됩니다.

### 사실로 적는 것 — IRP 제도 (집행 시점 최신 규정 재확인 전제)
- 세액공제: 연 **900만원** 한도(연금저축 합산)
- 공제율: 총급여 5,500만원 이하 **16.5%** / 초과 **13.2%** → 최대 환급 **148.5만원**
- 과세이연: 운용 중 매매차익·배당 비과세, 수령 시점으로 이연
- 위험자산 **70% 한도**, 안전자산 **30% 이상** 의무 편입
- 레버리지·인버스 ETF **편입 불가**
- 연금수령(만 55세+·가입 5년+) 연금소득세 **3.3~5.5%**
- 중도해지·일시금: 기타소득세 **16.5%** + 공제분 추징

### 예시로만 적는 것 (반드시 "예시" 꼬리표)
- 구체 상품명·티커(TIGER 200, 미국S&P500, 전략배분TDF2045 등)
- 총보수(TER) 수치
- 기대수익률(안정 4~5% / 중립 5~6.5% / 성장 6.5~8%, 세전·비보장)
- 포트폴리오 배분 비율

### 포트폴리오 설계 불변식
세 유형 모두 **위험자산(국내+선진국+신흥국·테마+리츠·대체) ≤ 70%**,
**안전자산(채권·TDF+예금) ≥ 30%**. 배분 막대 조각 합은 항상 100%.
→ 수정 시 `python3`로 `width:NN%` 합이 100이고 위험 합이 70 이하인지 꼭 재검산.

## 3. 왜 이렇게 결정했나 (의사결정 기록)

- **"IPR"은 "IRP"의 오타로 확정.** 최초 요청의 "IPR계좌"는 사용자 확인을 거쳐
  **IRP(개인형퇴직연금)**로 결론. 모호할 때 지어내지 않고 물어본 결과다.
- **산출물 = 저장소에 커밋하는 HTML 문서**로 확정(사용자 선택).
- **감마(Gamma) 프레젠테이션**도 한 번 생성한 이력이 있음. 단, Gamma MCP는
  기존 gamma를 **수정하지 못함** — 바꾸려면 Gamma 편집기에서 직접 하거나 재생성.
- 디자인은 저장소 대시보드 계열(라이트/다크·인쇄)과 미래에셋 브랜드 양쪽을 만족하도록,
  브랜드 토큰(오렌지/블루)을 쓰되 다크·인쇄 토글을 더함.

## 4. 이 일을 이어받을 때 — 작업 순서

1. `CLAUDE.md` + 이 문서를 읽는다.
2. 브라우저(크로미움)로 `irp-proposal.html`을 열어 라이트/다크·인쇄 미리보기를 확인한다.
3. 수치를 손대면 §2의 사실/예시 경계와 배분 불변식을 지킨다.
4. 디자인 변경은 `anthropic-skills:mas-design` 기준을 따른다.
5. 작업 가지 `claude/...`에서 하고, 커밋·푸시 후 `main` 병합은 기존 관례대로.

> 있었고 **이 저장소에는 반영되지 않았다.** 2026-10-01 세션에서 사양을 바탕으로
> 재작성해 저장소에 커밋한 것이 현재 `irp-proposal.html` 이다.
