## 4. 갈래를 가리지 않고 지켜 온 작업 규칙

각 갈래 문서에 흩어져 있는 것 가운데 **전부에 해당하는 것**만 모았습니다.

### 4-1. 값에 관한 것

- **지어내지 않습니다.** 모르는 값은 `—` 로 비우고, 왜 비웠는지 적습니다.
  추정치에 «실제» 라벨을 붙이지 않습니다.
- **예시 데이터와 실데이터를 화면에서 항상 구분**해 표시합니다.
- **표는 자료에서, 글은 기사에서.** 숫자를 문장에 손으로 적으면 다음 날 어긋납니다.
- 확인되지 않은 인과(「왜 올랐나」)는 **비워 둡니다.** 지수를 따라 움직인 종목에
  이야기를 붙이면 그 자체가 틀린 정보입니다.

### 4-2. 검산

- 갈래마다 검산기가 있고, **어긋나면 나가는 값 1 + 산출물을 내지 않습니다.**
- 검산기는 서로 **겹치지 않습니다.** 하나만 돌리고 넘어가지 마십시오.
- 오탐이 섞입니다. 개수만 보지 말고 **하나씩** 보십시오.

### 4-3. 저장소

- 운영 가지는 **`main`**. GitHub 의 `schedule` 은 기본 가지의 워크플로만 발동합니다.
- 커밋 꼬리에 붙입니다:
  ```
  Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_…
  ```
- **모델 이름을 저장소에 밀어 넣지 않습니다** — 커밋·PR·주석 어디에도.
- **요청하지 않은 PR 을 만들지 않습니다.**
- 꼬리말에 **사람 이름을 싣지 않습니다**(2026-09-23 결정, 개인정보).
  단, 기사에 나오는 애널리스트 이름은 그대로 둡니다.
- **컨테이너는 회수됩니다. 남길 것은 반드시 커밋**하십시오.

### 4-4. 실행 환경

- 세션은 네이버·다음·KRX·야후 등 **원천에 직접 못 붙습니다**(CONNECT 403).
  러너가 받아 커밋하고 세션이 읽습니다.
- **`workflow_dispatch` 를 API 로 부르지 마십시오**(403). `REFRESH` 파일을
  밀어 넣는 방식(`scripts/request_*_refresh.sh`)을 쓰십시오.
- **`gh` CLI 가 없습니다.** GitHub 작업은 MCP 도구(`mcp__github__*`)로.
- **TLS 검증을 끄거나 `HTTPS_PROXY` 를 지우지 마십시오.**
- 크로미움은 `/opt/pw-browsers` 에 이미 있습니다. `playwright install` 을 다시 부르지 마십시오.
- 세션 시계가 **UTC** 입니다. 한국 날짜는 `TZ=Asia/Seoul date` 로 반드시 다시 확인하십시오.

### 4-5. 보고

- **막히면 조용히 끝내지 마십시오.** 무엇이 어디서 막혔는지 한국어로 적습니다.
- 자료가 덜 들어왔으면 포기하지 말고, **무엇이 언제 기준인지 명시한 뒤**

| `data/sources.js` | 실데이터 어댑터(미래에셋·KRX·CSV) |

| `build-package.py` | 배포 zip 생성 ★ |

`__pycache__/serve-products.cpython-311.pyc` 는 **실수로 커밋된 것**입니다. 가져가지 마십시오.

### 5-3. 실데이터가 들어오는 곳

| 상품군 | 엔드포인트 | 상태 |
|---|---|---|
| ELS·DLS·ELB | `POST /hks/hks4022/a01.json` | 연동됨 (계정 불필요) |
| 펀드 | `POST /search/getTotalSearch.jsp` | 연동됨 (계정 불필요) |
| 채권 기준수익률 | `POST /hks/hks4037/a01.json` | 지표금리. 판매 상품 아님 |
| ETF·ETN | KRX 정보데이터시스템 | **보조**. KRX 무료 계정 필요 |
| RP·랩/신탁·연금 | — | **공개 엔드포인트 없음**(34개 페이지 수집으로 확인). 예시 데이터 |

- 응답이 **EUC-KR** 입니다. `serve-products.py` 가 cp949 로 디코딩해 전달합니다.
- ELS 는 파라미터 조합을 **둘 시도**합니다. 청약중 조합(`prgs_scd=01`,
  referer `/hks/hks4023/n01.do`)이 되면 종목번호까지 받아 상품별 상세 링크를
  만들 수 있고, 안 되면 청약 일정 조합으로 되돌립니다.

### 5-4. 이 갈래에서 겪은 함정

- **KRX 로 새지 마십시오.** 한때 KRX 를 주 소스로 붙이다가 «미래에셋 홈페이지
  상품을 조회한다»는 원래 목적에서 벗어났습니다. KRX 는 **ETF 보조**로만 씁니다.
- **서류 링크를 지어내지 마십시오.** 투자설명서 버튼 셋이 모두 같은
  카테고리 메인(`financeMain.do`)으로 가던 결함이 있었습니다. 지금은
  화면 소스에서 확인한 상품별 주소만 버튼으로 만들고, 없으면 없다고 적습니다.
- **`lwrk_bar_rt` 는 「최저」 배리어입니다.** 한때 「최초 배리어」로 적고
  손익구조도에 없는 스텝다운 계단을 그렸습니다. 회차별 일정은 공개 응답에
  없으므로 **그 한 줄만** 그립니다.
- **낙인 여부가 없으면 「노낙인」이라고 단정하지 마십시오.**
- **배포 zip 은 반드시 `build-package.py` 로 만드십시오.** 리눅스 `zip` 은
  파일명 UTF-8 플래그를 세우지 않아 윈도우에서 **한글 이름 파일이 사라집니다**
  (`조회화면 실행.bat`, `시작하기.txt` 가 실제로 사라졌습니다).
- 윈도우 `.bat` 은 ASCII 로, 한 줄씩, `chcp` 없이 씁니다. 한글을 넣으면
  cmd.exe 가 조용히 멈춥니다. **이 환경에서는 시험할 수 없습니다** — 윈도우가 없습니다.

### 5-5. 열려 있는 일

- RP·랩/신탁·연금은 예시 데이터입니다. 사내 API 나 CSV 로만 채울 수 있습니다.
- ELS 기준가 회차별 조회(`/hks/hks4023/a01.json`)는 아직 화면에 붙이지 않았습니다.
