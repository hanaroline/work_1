## 2. 새 계정에서 하는 순서

1. **저장소 연동** — `hanaroline/work_1` 을 새 계정의 Claude Code 에 붙인다.
2. **이 파일을 읽힌다**, 그다음 아래 3절에서 **할 일에 맞는 문서**를 읽힌다.
3. **예약을 다시 만든다** — `docs/handover/예약-프롬프트-전체.md` §10 의 차례대로.
   고정 창부터 만들고, cron 은 UTC 그대로, 프롬프트는 **글자 그대로**.
4. **주소가 박힌 두 곳을 고친다** — 세션 산출물 색인 아티팩트, `index.json` 의
   `archive_page.url`. 둘 다 옛 계정 주소다.
5. **하루치를 끝까지 돌려 본다.** 검산이 통과하면 인계가 끝난 것이다.

## 4. 모든 일에 공통으로 유지해야 할 작업 규칙

여러 파이프라인에서 되풀이해 굳어진 규칙이다. **새 대화에서도 그대로 지킨다.**

### 자료를 다루는 결

- **숫자를 손으로 옮겨 적지 않는다.** 표에 있는 값을 문장에 베끼면 다음 날 어긋난다.
  빌더가 자료에서 만들게 한다.
- **요약은 발췌(extractive)다.** 본문 문장을 그대로 옮기고, 새로 쓰거나 셈을 새로 하지 않는다.
- **확인한 것만 적는다.** 「사유」·「때문에」는 근거가 있을 때만. 지수를 따라 움직였을 뿐인
  종목에 이야기를 붙이면 그 자체가 틀린 정보다.
- **낡은 값을 오늘 값처럼 쓰지 않는다.** 신선도를 먼저 확인하고, 낡았으면 그 사실을 적는다.
- **검산을 통과하지 못한 결과는 올리지 않는다.**

### 셈을 대조하는 결

- **건수만 보지 않는다.** 들어온 것과 빠진 것이 같은 수면 건수는 그대로다.
  **이름·코드로 맞댄다.** 늘어난 것과 줄어든 것을 **함께** 센다.
- **커밋이 생겼다고 갱신된 것이 아니다.** 변경이 `updatedAt` 뿐인 경우가 흔하다.
  **날짜가 아니라 블롭 해시를 본다.**
- 수천 건이 한꺼번에 「바뀜」으로 나오면 대개 색인이 밀린 것이지 실제 변화가 아니다.

### 보고하는 결

- **조용히 끝내지 않는다.** 막혔으면 무엇이 어디서 막혔는지 한국어로 적는다.
  「성공」으로 기록됐는데 아무 일도 없었던 적이 실제로 있었다(us100 9/20·9/27).
- **잡음도 만들지 않는다.** 변화가 없으면 한 줄, 또는 아무 말도 하지 않는다 —
  어느 쪽인지는 예약마다 정해져 있다.
- **미확인 항목을 반드시 밝힌다.**

### 저장소를 다루는 결

- **지정된 브랜치에만 push 한다.** 다른 브랜치는 건드리지 않는다.
- **PR 은 사용자가 요청할 때만 만든다.**
- **빈 커밋을 만들지 않는다.**
- 푸시가 네트워크 오류로 실패하면 2·4·8·16초 간격으로 최대 4회 재시도한다.
- `workflow_dispatch` 를 세션 토큰으로 부르면 **403**이다. `REFRESH` 파일을 고쳐 push 해서
  워크플로를 깨운다.

### 환경의 결

- **세션은 사내 이그레스 정책 때문에 외부 원천에 직접 못 붙는다.**
  러너(GitHub Actions)가 받아 저장소에 커밋하고, 세션은 커밋된 JSON 을 읽는다.
- **컨테이너는 회수된다.** `out/` 는 저장소에 없다. 매번 새로 받은 상태에서 시작한다.
- **크로미움은 `/opt/pw-browsers` 에 이미 있다.** 다시 내려받지 않는다.
- **세션 시계는 UTC 다.** 한국 날짜와 하루 어긋나 보일 때가 있으니
  `TZ=Asia/Seoul date` 로 반드시 다시 확인한다.
- GitHub 예약(cron)은 **지연된다.** ELS 자동 빌드는 10:10 로 걸려 있어도 실제로는
  15:40 쯤 돈다. 「8분 넘으면 멈춘 것」이라 단정하지 말고 실행 기록을 먼저 열어 본다.

## 6. 이 세션(2026-09-11 ~ 10-01)에서 한 일

작은 건이라 따로 문서를 두지 않고 여기에 적는다.

- **자기소개 프로필 카드** — `profile/index.html` · `profile/style.css` · `profile/main.js`
  - 요청: 아바타(👤) · 홍길동 · 프론트엔드 개발자 · 취미 3종 · 보라색 테마(`#667eea`) ·
    중앙 정렬 카드 · 깔끔하고 심플하게. `main.js` 는 빈 `initApp()` 만.
  - **루트가 아니라 `profile/` 에 둔다.** 루트 `index.html` 은 「종목 통합 리포트」
    대시보드이고 이 저장소의 주력 산출물이다. 한때 작업 브랜치에서 루트로 옮겼었으나,
    브랜치를 최신 `main` 위로 다시 세우면서 **대시보드를 지키는 쪽으로 되돌렸다.**
    프로필 카드를 루트에 두면 대시보드가 사라진다 — 그렇게 하지 말 것.
  - 아티팩트로도 발행했으나 **그 주소는 옛 계정 소유**라 새 계정에서는 열리지 않는다.
    파일이 저장소에 있으니 다시 발행하면 된다.

### 이 세션에서 확인한 사실 — 기록해 둘 만한 것

- **`main` 의 히스토리가 재작성(force-push)됐다.** 2026-09-11 에 끊긴 작업 브랜치는
  `main` 과 **공통 조상이 없어 merge 가 거부된다**(`refusing to merge unrelated histories`).
  오래 묵은 브랜치는 merge 하려 들지 말고 **최신 `main` 위로 다시 세우는 편**이 맞다.
- **등록된 예약이 18개(활성 10)였는데 기존 문서에는 3개만 적혀 있었다.**
  나머지 8개 전문을 `예약-프롬프트-전체.md` 에 받아 적었다.
- **ELS 신규 회차 점검·검증 예약이 2026-10-01 실행에서 실패했다**(6초 만에 종료).
  새 계정에서 만든 뒤 손으로 한 번 돌려 봐야 한다.
