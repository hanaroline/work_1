## 2. 새 계정에서 할 일 — 순서대로

1. **저장소 연동** — `hanaroline/work_1` 을 새 계정의 Claude Code 에 붙입니다.
2. **아무것도 안 해도 `CLAUDE.md` 가 자동으로 읽힙니다.** 거기에 「무슨 일에
   무슨 문서를 읽을지」가 적혀 있습니다. 2026-10-01 에 만들었습니다 —
   예전에는 사람이 매번 「playbook 을 읽어라」라고 말해 줘야 했습니다.
3. **예약 12개 다시 만들기** — `예약-프롬프트-전체백업.md` 2절.
   전용 창이 필요한 것은 **창을 먼저 열고** 그 세션 ID 로 만듭니다.
   **프롬프트는 글자 그대로.** 요약하면 그만큼 품질이 떨어집니다.
4. **옮기며 고쳐야 하는 자리 넷**을 처리합니다 — 같은 문서 3절.
5. **아티팩트** — `../HANDOVER.md` 3절에서 선택지 셋 중 하나를 고릅니다.
   (권함: ① 앞으로 것만 발행. 지난 판은 저장소 파일로 열람)
6. **시험 운행** — 하루치를 끝까지 돌려 봅니다.
   `docs/briefing-playbook.md` 의 0번부터 12번까지가 한 번에 돌면 끝난 것입니다.
