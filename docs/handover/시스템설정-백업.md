## 1. 저장소에 있는 설정 — 그대로 넘어온다

### 1-1. `.claude/settings.json`

```json
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "$CLAUDE_PROJECT_DIR/.claude/hooks/session-start.sh"
          }
        ]
      }
    ]
  }
}
```

### 1-2. `.claude/hooks/session-start.sh` — 하는 일

웹 세션이 시작될 때 돈다(`CLAUDE_CODE_REMOTE=true` 일 때만).

- **playwright 1.56.1** 을 깐다. 저장소가 `package.json` 을 `.gitignore` 로 빼기 때문에
  새 세션에는 `node_modules` 가 없다. PDF·화면 시험이 전부 playwright 를 부르므로
  이게 없으면 시작하자마자 막힌다. 판 번호는 **워크플로가 쓰는 것과 같게** 맞춰 둔다.
- **크로미움은 내려받지 않는다.** 이 실행 환경에는 `/opt/pw-browsers` 에 이미 있다.
  다시 받으면 수백 MB 를 세션 몫 디스크에 또 쌓는다.

### 1-3. `.github/workflows/reports.yml` — 수집 워크플로

```yaml
on:
  schedule:
    - cron: '40 23 * * 0-4'   # ① 08:40 KST
    - cron: '25 0 * * 1-5'    # ② 09:25 KST  ← 아침 본진
    - cron: '0 4 * * 1-5'     # ③ 13:00 KST
    - cron: '20 8 * * 1-5'    # ④ 17:20 KST
    - cron: '10 1 * * 1-5'    # ②' 10:10 KST — 본진이 흘렀을 때 메움
    - cron: '20 5 * * 1-5'    # ③' 14:20 KST
    - cron: '40 9 * * 1-5'    # ④' 18:40 KST
  push:
    paths:
      - 'data/reports/REFRESH'
      - 'scripts/fetch_reports.py'
      - 'scripts/probe_reports.py'
  workflow_dispatch:

permissions:
  contents: write
concurrency:
  group: reports-data
  cancel-in-progress: false
```

**알아 둘 것 셋:**

1. **`schedule` 은 기본 브랜치(main)의 워크플로만 발동한다.** 다른 가지에서는 push·수동만 된다.
   운영을 `main` 에서 하는 까닭이 이것이다.
2. **세션은 `workflow_dispatch` 를 부를 권한이 없다**(403). 그래서 `data/reports/REFRESH`
   에 한 줄 적어 밀어 넣는 방식으로 수집을 부른다 — `scripts/request_reports_refresh.sh`.
3. **보조 슬롯(②'·③'·④')은 장식이 아니다.** GitHub cron 은 +65~74분 늦거나 아예
   거르기도 한다. 실제로 본진이 흐른 날을 보조 슬롯이 메운 적이 있다.

### 1-4. 손으로 부르는 수집

```bash
bash scripts/request_reports_refresh.sh "왜 부르는지 한 줄"
```

- `data/reports/REFRESH` 에 요청 줄을 붙이고 커밋·푸시한다 → push 트리거가 워크플로를 깨운다
- 커밋 꼬리에 `Co-Authored-By` / `Claude-Session` 을 자동으로 붙인다
- 푸시 실패 시 `0 2 4 8 16` 초 간격으로 다시 시도
- `.github/workflows/reports.yml` 이 현재 가지에 없으면 **거부**한다
- `data/reports/REFRESH` 에 커밋 안 된 변경이 있으면 **거부**한다

### 1-5. 주요 스크립트

| 파일 | 하는 일 |
|---|---|
| `scripts/fetch_reports.py` | 원천 여덟 곳에서 받아 `data/reports/<날짜>.json` · `latest.json` 작성 (**러너에서만 돈다**) |
| `scripts/verify_reports.py` | **검산 42개.** 어긋나면 나가는 값 1 + 「산출물을 내지 말 것」 |
| `scripts/make_reports_outputs.sh` | 한 파일 HTML + PDF 셋을 `out/` 에 만든다 |
| `scripts/make_reports_standalone.py` | 자료를 박아 넣은 한 파일 HTML |
| `scripts/reports_to_pdf.mjs` | 크로미움으로 A4 PDF 셋 (요약/주간인기/전체) |
| `scripts/request_reports_refresh.sh` | 수집 호출 |
| `scripts/probe_reports.py` | 원천 탐색(작업 가지 전용) |
| `docs/reports/index.html` | 화면 + **인쇄 CSS**(쪽 나눔이 여기 있다) |

### 1-6. 실행 환경에서 알아 둘 것

- 세션은 **원천에 직접 못 붙는다**(사내 이그레스 정책). 러너가 받아 커밋하고 세션이 읽는다.
- 바깥 HTTPS 는 대리 서버를 지난다. **TLS 검증을 끄거나 `HTTPS_PROXY` 를 지우지 않는다.**
  CA 묶음: `/root/.ccr/ca-bundle.crt`
- 크로미움: `/opt/pw-browsers` (`PLAYWRIGHT_BROWSERS_PATH`). `playwright install` 을 다시 부르지 않는다.
- 임시 파일은 세션 전용 스크래치패드에 둔다. `/tmp` 를 직접 쓰지 않는다.
- `out/`·`out-test/` 는 `.gitignore`. **컨테이너는 회수되므로 만든 파일은 같은 세션에서 건네야 한다.**

## 2. 계승되지 않는 것 — 예약(Routine) ★

**예약은 Claude 계정에 묶여 있다. 저장소에는 없다. 새 계정에서 다시 만들어야 한다.**

### 2-1. 지금 쓰고 있는 예약

| | |
|---|---|
| 이름 | 증권사 리포트 자동 배포 (평일 11:00 KST · 이 대화로 전달) |
| cron | `0 2 * * 1-5` (UTC 02:00 = 한국 11:00, 평일만) |
| 전달 | **쓰고 있는 대화로 전달**(persistent session) |
| 상태 | 켜짐 |
| 지시문 | `자주쓰는-프롬프트.md` 의 2절 전문 |

**옛 ID는 적어 두지 않는다** — 새 계정에서는 쓸모가 없다.

### 2-2. 꺼 둔 예약

평일 09:25 아침 배포가 있었으나 **껐다.** 11:00 판 하나로 충분하고,
두 번 돌면 어느 것이 최신인지 헷갈린다. 새 계정에서는 **만들지 않는다.**

### 2-3. 예약을 만들 때 주의할 점

- **「쓰고 있는 대화로 전달」을 고른다.** 매번 새 대화를 띄우는 방식은
  저장소에 밀어 넣을 자격이 없어 **아무것도 만들어 내지 못했다.**
- **서버가 「분」을 만든 시각에 붙잡는다.** 11:00 으로 걸어도 11:06 에 돈다.
  (10:30 으로 걸었을 때는 10:31 이었다.) 정시 고정 방법은 확인하지 못했다.
- **만든 뒤 돌아온 다음 발사 시각을 반드시 확인한다.** 예약이 거절됐는데
  확인하지 않아 약속한 산출물이 하루 늦은 적이 있다.
- 예약은 **하루 한 번**으로 둔다. 더 필요하면 그때그때 말로 부르는 편이 낫다
  — 수집부터 파일까지 4분이면 끝난다.

### 2-4. 예약이 흘렀을 때

2026-09-19(금)에 **계정의 모든 예약이 하나도 발사되지 않은 날**이 있었다.
리포트뿐 아니라 상품설명의무·ELS·마포WM 장마감까지 전부 비었다 —
파이프라인 결함이 아니라 플랫폼 쪽 공백이었다. 그런 날은 **손으로 부르면 된다.**
