## 1. 무엇인가

AI 데이터센터 한 곳이 세워질 때 **돈이 흘러가는 순서대로 9단계**를 나누고,
각 단계에서 시장 지위를 확보한 **국내 38 · 해외 46, 모두 84종목**을 배치한
한/영 단일 화면입니다. 종목을 누르면 사업 내용·데이터센터 연관 포인트와
**시세·수익률·변동성 지표**가 상세 패널에 열립니다.

9단계: `chip` 칩 → `memory` 메모리 → `board` 기판·후공정 → `server` 서버 →
`network` 네트워크·광통신 → `power` 전력 → `cooling` 냉각 → `epc` 건설·EPC →
`ops` 운영·코로케이션·클라우드.

## 3. 시세·지표가 어디서 오는가

### 경로 — `file://` 로 열어도 되게 만든 것이 이 갈래의 핵심

브라우저는 다른 출처 응답을 CORS 로 막기 때문에 파일을 그냥 열면 `fetch` 가
거의 다 실패합니다. 그래서 **JSONP(`<script>` 태그) 경로를 1순위**로 둡니다 —
`<script>` 로드는 CORS 검사 대상이 아니라서 **서버 없이 파일만 열어도 조회됩니다.**

| 순서 | 경로 | `file://` | 비고 |
|---|---|---|---|
| 1 | JSONP (`api.allorigins.win`) | **O** | 이것 하나로 파일 단독 실행이 성립 |
| 2 | 직접 호출 | 대상이 CORS 허용 시 | |
| 3 | 공개 프록시 5종 | 서비스별 | codetabs · corsproxy.io · allorigins · cors.eu.org · thingproxy |
| 4 | 로컬 프록시 `/api/proxy` | X | `serve.py` 로 접속했을 때만. 외부 중계를 전혀 안 거침 |

모두 **병렬로 던지고 먼저 성공한 응답을 채택**합니다. 시도 기록은 전부 남아
화면의 **`시세 진단`** 버튼에서 경로별 성공/실패와 까닭을 복사할 수 있습니다.

### 소스 — 항목별 순차 폴백

| 항목 | 국내 | 해외 |
|---|---|---|
| 현재가·등락 | 네이버 `/basic` → `polling` → `/price` → Yahoo → Stooq | Yahoo `chart` → Stooq |
| 12개월 일별 종가 | 네이버 `siseJson` → Yahoo → Stooq | Yahoo → Stooq |
| 시가총액·PER·PBR·배당 | 네이버 `/integration` | 네이버 해외종목(미국 `.O`/`.N`, 일본 `.T`)**만** |
| 벤치마크 | Yahoo `^KS11` → 네이버 `KOSPI` | Yahoo `^GSPC` |

수익률·변동성·샤프·MDD·52주는 **일별 종가에서 화면이 직접 계산**합니다
(샤프는 무위험수익률 3.0% 가정). 그래서 전 종목에서 채워집니다.
반면 시가총액·PER·PBR·배당은 **대만·유럽 종목에서 비어 있습니다** — 네이버
해외종목이 미국·일본만 다루기 때문입니다. 비는 자리는 `-` 로 둡니다.

## 4. 겪은 함정 — 되풀이하지 마십시오

- **네이버 등락폭은 절대값입니다.** 방향은 `compareToPreviousPrice.code` ·
  `risefall` · 폴링의 `rf` 가 알려 줍니다(**4·5 = 하락**). 부호를 안 뒤집으면
  하락이 상승으로 표시됩니다 — 실제로 그렇게 나갔다가 고쳤습니다.
- **`serve.py` 를 유일한 해법으로 안내하지 마십시오.** 「파일만 열면 되게 해
  달라」는 요구가 먼저 있었고, JSONP 로 실제로 됩니다. `serve.py` 는 사내망이
  중계 서비스까지 막을 때의 **선택지**입니다.
- **응답 필드명이 시장마다 다릅니다.** 후보 키를 여러 개 두고 한글 항목명까지
  훑는 관용 파서를 씁니다. **못 찾은 값은 지어내지 말고 `-` 로 두십시오.**
- **주식에 위험등급을 붙이지 마십시오.** 금융상품 쪽 「위험등급 1~6」을 그대로
  옮기면 틀린 정보가 됩니다. 변동성으로 계산한 **「변동성 구간 1~6」**으로
  이름을 바꾸고, 화면과 README 에 «자체 산출, 규제 등급 아님»을 적어 두었습니다.
- **84종목 지표를 한 번에 조회하지 마십시오.** 중계 경로가 버티지 못합니다.
  `표`/`카드` 보기로 바꾸거나 `지표 불러오기` 를 눌렀을 때 **화면 순서대로
  동시 3건씩** 돌고, 진행률이 보이며 같은 버튼으로 중단합니다. `맵` 보기에서는
  누른 종목만 조회합니다.

## 5. 검증 방법 (세션에서 원천에 못 붙으므로)

세션은 네이버·Yahoo 에 직접 못 붙습니다(CONNECT 403). 그래서 **Playwright 로
응답을 가짜로 물려** 확인했습니다 — `page.route()` 로 `fetch` 경로를 전부
`abort` 하고 **JSONP URL 만 `fulfill`** 하면, 파일 단독 실행이 정말로 되는지
증명됩니다. 마지막 확인(2026-08-05): 표 84행 16열, 상세 차트 2계열,
비교표 16항목, CSV 85행, EN 전환 시 잔여 한글 0, 가로 넘침 없음, JS 오류 0.

**실제 API 응답으로는 검증하지 못했습니다.** 특히 네이버 `/integration` 의
필드명은 확인하지 못했습니다. 시가총액·PER 이 계속 `-` 로 나오면 그 파서부터
보십시오.

## 6. 열려 있는 일

- 네이버 `/integration` 실응답 대조 — 위와 같은 까닭.
- 대만·유럽 종목의 시가총액·PER 공급처가 없습니다. 사내 엔드포인트가 있다면
  그쪽으로 돌리는 것이 가장 깨끗합니다.
- `main` 합류 여부 미정. 합친다면 `--allow-unrelated-histories` 로 하되
  **2절 다섯 파일만** 가져오고 겹치는 여섯은 `main` 쪽을 남기십시오.
