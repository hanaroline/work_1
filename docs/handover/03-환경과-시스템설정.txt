[4] 도구
-------------------------------------------------------------------------------

  · gh CLI 는 없습니다. GitHub 작업은 전부 mcp__github__* 도구로 합니다.
    (PR 보기, 만들기, 코멘트, CI 확인, 저장소 탐색)
  · 러너 결과 읽기 : mcp__github__get_job_logs
  · 워크플로 돌리기 : mcp__github__actions_run_trigger
  · 세션/환경 보기 : mcp__Claude_Code_Remote__*  (list_repos, get_session, list_environments …)
  · 긴 작업 중 자기 호출 : mcp__Claude_Code_Remote__send_later

[7] 새 계정에서 환경을 다시 만들 때 할 일
-------------------------------------------------------------------------------

 1. claude.ai 설정 → Connectors 에서 GitHub 를 연결합니다.
 2. hanaroline/work_1 에 접근 권한을 줍니다.
    (조직 소유 저장소라면 조직 소유자가 claude.ai 관리자 설정에서 허용해야 합니다)
 3. Claude Code on the web 에서 이 저장소로 환경을 만듭니다.
 4. 새 세션을 열고 docs/handover/02-자주-쓰는-프롬프트.txt 의 [0] 번을 붙여 넣습니다.
 5. 검사가 도는지 한 번 확인합니다:
       node tools/verify/audit-stored.mjs
       node tools/verify/reg.mjs

    ※ 네트워크 정책은 환경을 만들 때 고르는 것이라 새 환경에서는 다를 수 있습니다.
      막힌 곳이 달라졌으면 docs/handover/03 의 [3] 을 고쳐 주십시오.
