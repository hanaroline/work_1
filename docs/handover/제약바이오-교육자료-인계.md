## 2. 지켜 온 작업 규칙

### 2-1. 검증 절차 (순서를 바꾸지 마십시오)

`fin-data-integrity` 스킬의 절차를 그대로 씁니다. **빌드가 검산보다 먼저 오면 안 됩니다.**

```
1. 리서치 (출처 URL 필수)
2. docs/deck/pharma-claims.json 에 등록
3. python3 <스킬>/scripts/check_claims.py docs/deck/pharma-claims.json
4. 검산 통과 후에만 pptx 수정
5. 인도 전 게이트 확인
```

대장에 없는 숫자는 슬라이드에 쓰지 않습니다. 2026-10-01 판은 **주장 32건·파생 7건,
1차 출처 10건, 미확인 5건**으로 검산을 통과했습니다.

### 2-2. pptx 를 고치는 방법

**python-pptx 로 텍스트를 대입하지 마십시오.** `text_frame.text = "..."` 는 문단을
서식 없는 런 하나로 뭉갭니다. 쓰는 방법은 이것뿐입니다:

```
1. unzip → ppt/slides/slideN.xml
2. <a:t> 를 순서대로 뽑아 인덱스를 매긴다
3. (슬라이드, 인덱스, 기존문자열, 새문자열) 로 치환 — 기존문자열이
   정확히 일치할 때만 바꾸고, 아니면 즉시 중단
4. 뒤에서부터 적용 (오프셋이 밀리지 않게)
5. unpacked 안에서 zip -Xrq ../out.pptx .
6. validate.py out.pptx --original 원본.pptx
```

8/3 세션은 이 방식으로 **59건을 전부 정확 일치 치환**했습니다. 오조작이 한 건도
없었던 이유가 3번입니다.

XML 안에서는 `&` 가 `&amp;`, `'` 가 `&apos;` 로 들어 있습니다. 치환 문자열도
이스케이프된 형태로 써야 합니다.

### 2-3. 차트를 고칠 때

차트 수치는 **두 군데**에 있습니다. 하나만 고치면 PowerPoint 에서 「데이터 편집」을
눌렀을 때 옛 숫자가 나옵니다.

- `ppt/charts/chartN.xml` — 화면에 그려지는 캐시값
- `ppt/embeddings/Microsoft_Excel_WorksheetN.xlsx` — 원본 워크북
  (`xl/sharedStrings.xml` 의 라벨, `xl/worksheets/sheet1.xml` 의 값)

워크북은 openpyxl 로 다시 저장하지 말고 **zip 수준에서 해당 XML 만 교체**하십시오.
표(`xl/tables/table1.xml`)가 들어 있어 round-trip 하면 깨질 수 있습니다.

### 2-4. 글자가 길어질 때 (오버플로우)

이 실행 환경의 **LibreOffice 는 이 pptx 를 열지 못합니다**(`source file could not be
loaded`). 원본·수정본 모두 실패하므로 파일 문제가 아니라 환경 문제입니다.
**렌더링 이미지로 눈으로 보는 검증을 할 수 없습니다.**

대신 계산으로 확인합니다. 한글은 전각이므로 `폰트크기 1pt = 가로 1자`로 잡고:

```
한 줄에 들어가는 글자수 = (도형 너비pt - 안쪽여백) / 폰트크기pt
필요한 줄수            = 글자폭합 / 한 줄 글자수
수용 가능한 줄수        = 도형 높이pt / (폰트크기pt × 1.25)
```

표는 행 높이가 자동으로 늘어나므로 **표 하단이 각주를 밀어내는지**를 따로 봅니다.
8/3 판에서 p13 아리바이오 칸이 1.08행이 되어 표가 7pt 내려앉았고, 문구를 줄여
원래 여유(각주까지 +15pt)를 되돌렸습니다.

### 2-5. 숫자에 관한 것

- **환율은 자료 전체에서 하나로 통일합니다.** 8/3 이전 판은 슬라이드마다
  1,382~1,544원이 섞여 있었습니다. 현재 정책은 **1달러 = 1,500원 고정**이고
  각주에 명시합니다
- **기관 전망은 기관·발표일·대상시점·조정방향을 한 칸에 같이 적습니다**
- **부정 단정을 만들지 않습니다.** 못 찾은 것은 "공개 자료에서 확인되지 않음(기준일)"
  이지 "없다"가 아닙니다
- **비상장사는 반드시 표기합니다.** 교육자료를 본 고객이 종목을 찾다가
  **대리 매수**로 가는 것을 막는 장치입니다 (3-3 참조)
