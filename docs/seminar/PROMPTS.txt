[E] 제작 기술 메모 (pptxgenjs)
-------------------------------------------------------------------------------
• 도구: pptxgenjs (Node). LAYOUT_WIDE = 13.33" x 7.5" (16:9).
• 슬라이드 순서 = p.addSlide() 호출 순서. 블록을 옮기면 순서가 바뀜.
• 페이지 번호 자동 카운터 패턴:
    let __pn = 1;
    function pageNum(s) {
      __pn++;
      s.addText(String(__pn).padStart(2, "0"),
        { x: 12.35, y: 6.95, w: 0.7, h: 0.35, align: "right",
          fontFace: KR, fontSize: 11, color: MUTED, bold: true, margin: 0 });
    }
  (타이틀 1p 에는 pageNum 호출 없음 → 첫 호출이 02)
• 빌드 출력:  node gen.js "<저장소경로>/반도체_투자_세미나_20260728.pptx"
• 검증:  pptx 스킬 validate.py + python-pptx 오버플로 체크(경계 13.33x7.5)
• ★ 중요: 다음에 gen.js 를 다시 만들면 반드시 저장소 안(예: tools/seminar/gen.js)에
  커밋할 것. 지난번엔 저장소 밖에서 빌드해 생성기 소스가 소실됨
  (저장소엔 결과 .pptx 만 남아 있음 — 네이티브 편집은 가능).
