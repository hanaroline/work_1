## 2. 어떻게 만들었나 (제작 방식)

### ① 생성 도구
- **pptxgenjs (Node)** 로 네이티브 편집 가능한 PPTX를 코드로 생성.
- 레이아웃 `LAYOUT_WIDE` = 13.33" × 7.5" (16:9).
- 폰트 `KR = "Spoqa Han Sans Neo"`.

### ② 슬라이드 순서 = 코드 실행 순서
- `p.addSlide()` 호출 **순서대로** 슬라이드가 배치됨. 코드 블록을 물리적으로 위아래로 옮기면 순서가 바뀜.
- **페이지 번호는 자동 카운터**로 처리 → 블록을 옮겨도 번호가 자동 교정됨:
  ```js
  let __pn = 1;
  function pageNum(s) {
    __pn++;
    s.addText(String(__pn).padStart(2, "0"),
      { x: 12.35, y: 6.95, w: 0.7, h: 0.35, align: "right",
        fontFace: KR, fontSize: 11, color: MUTED, bold: true, margin: 0 });
  }
  ```
  (타이틀(1p)에는 `pageNum` 호출을 넣지 않으므로, 첫 호출이 자동으로 02번이 됨.)

### ③ 검증 절차
- pptx 스킬의 `validate.py` (office validator).
- python-pptx 로 오버플로 체크 (경계 13.33×7.5 안에 도형이 들어오는지).
- 미리보기는 HTML Artifact 로 테마 대응 렌더링해 사람이 눈으로 확인.

### ④ ⚠️ 생성기 소스가 소실된 이유와 대처
- `gen.js` 는 저장소 **밖**(세션 스크래치패드)에서 빌드했음. 이유: stop-hook 이 저장소 내 미추적(untracked) 파일을 문제 삼는 것을 피하려고.
- 그 결과 컨테이너가 반납되면서 `gen.js` 가 사라졌고, 저장소에는 결과물 `.pptx` 만 남음.
- **앞으로 내용을 고칠 때 선택지 2가지:**
  1. **`.pptx` 를 직접 편집** — PowerPoint 로 수기 수정하거나, `python-pptx` / pptx 스킬로 프로그램 수정. (가장 간단)
  2. **생성기를 다시 세움** — pptxgenjs `gen.js` 를 새로 작성. 이때는 **반드시 저장소 안(예: `tools/seminar/gen.js`)에 커밋**해서 다시는 잃어버리지 않게 할 것.
- **권고:** 다음에 큰 개편이 필요하면 선택지 2로 가되, 생성기를 커밋하십시오. 소소한 수정이면 선택지 1이 빠릅니다.
