## 3. 아티팩트를 어떻게 할 것인가 — 선택지 셋

판 **131개**(발행본 81개)의 HTML 은 저장소에 그대로 있습니다. 주소만
새로 받으면 됩니다.

| 방법 | 품 | 결과 |
|---|---|---|
| **① 앞으로 것만 발행** (권함) | 없음 | 오늘부터 만드는 판만 새 주소. 지난 판은 저장소 파일로 열람 |
| ② 최근 것만 다시 발행 | 10~20분 | 최근 2~4주치만 링크 복구 |
| ③ 81판 전부 다시 발행 | 수십 분 + 토큰 많이 | 목록 한 장이 전부 살아남 |

②③ 을 고르면 이렇게 합니다.

```bash
# 단독 HTML 만들기 (브라우저 없이, 빠름)
python3 scripts/make_standalone.py docs/briefings/<판>.html
# → 만들어진 파일을 Artifact 로 발행하고, 받은 주소를
#   docs/briefings/index.json 의 그 판 url 에 적는다
python3 scripts/build_archive_nav.py     # 판마다 실리는 목록 다시 생성
python3 scripts/build_archive_page.py    # 목록 한 장 다시 생성
```

**①을 고르면** `index.json` 의 옛 주소를 그대로 두되, 목록 한 장 상단에
«이 아래 주소들은 옛 계정 것이라 열리지 않습니다»를 적어 두는 편이 낫습니다.
안 그러면 열어 보고 당황합니다.
