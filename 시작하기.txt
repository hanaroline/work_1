금융상품 통합조회 - 실행 방법
========================================

[실행]  '조회화면 실행.bat' 을 더블클릭하세요.
        검은 창이 뜨고 브라우저가 자동으로 열립니다.
        검은 창은 닫지 마세요. 종료는 그 창에서 Ctrl+C

        * 한글 이름 파일이 안 보이면 'START.bat' 또는 'run-products.bat' 을
          더블클릭하세요. 셋 다 완전히 같은 동작입니다.

        * 브라우저 주소창이 127.0.0.1 로 시작해야 정상입니다.
        * C:/ 로 시작하면 파일을 직접 연 것이라 실데이터가 안 들어옵니다.

[주의] serve-products.py 를 더블클릭하지 마세요.
        .py 파일은 편집기(PyCharm 등)에 연결돼 있어 실행이 아니라 열기만 됩니다.
        products-standalone.html 도 더블클릭하면 예시 데이터만 보입니다.

[상품 데이터]
  ELS/DLS      미래에셋증권 공개 상품 API 실시간 조회 (계정 불필요)
               상품명/종류/제시수익률/최저 배리어/낙인여부/기초자산/위험등급/
               모집한도/청약금액/숙려대상 마감/청약마감(D-)/온라인청약 여부
  펀드         미래에셋증권 펀드검색 API 실시간 조회 (계정 불필요)
               펀드명/운용사/위험등급/1·3·6·12개월 및 설정후 수익률/
               선취수수료/순자산/설정일/온라인 판매 여부
  ETF/ETN/채권 KRX 공개데이터 (보조, 선택사항). KRX 무료 계정 필요
               -> 검은 창 대신 명령창에서: python serve-products.py --krx-login
  RP/랩·신탁/연금  공개 API 가 없어 예시로 표시됩니다.
               화면 상단 '사내 데이터 올리기(CSV)' 로 실제 상품을 넣을 수 있습니다.

[상품명 클릭 시 나오는 상세 화면]
  - 핵심지표/위험등급/손익구조/비용·가입조건 순으로 표시됩니다.
  - '수신 원문 항목' 을 펼치면 미래에셋증권 응답에서 받은 값을 그대로 볼 수 있습니다.
    화면에 비어 있는 항목은 응답에 그 값이 없다는 뜻입니다.
  - '서류·공시' 의 링크는 상품별 실제 주소로 연결됩니다.
      펀드  -> 펀드 상세 팝업 (hks4116/p11.do?fd_cd=펀드코드)
              투자설명서·간이투자설명서 원문은 이 팝업 안에서 내려받습니다.
      ELS   -> 종목번호가 응답에 오면 상품 상세 팝업 (hks4023/p02.do)
              오지 않으면 '청약중인 ELS/DLS' 목록으로 연결합니다.
      ETN   -> 투자설명서 PDF (public/hks4000/T종목번호.pdf)
      채권  -> 채권 상세 (hks4036/v01.do?itemCode=표준코드)
    예시 데이터 상품은 실제 서류가 없으므로 카테고리 안내 화면만 연결합니다.

[문제가 있을 때]
  검은 창이 바로 닫히거나 오류가 보이면, 폴더 주소창에 cmd 를 입력해
  명령창을 열고 아래를 실행한 뒤 그 출력을 알려주세요.
        python serve-products.py
        python serve-products.py --report
        python serve-products.py --mas-probe

----------------------------------------
화면 상단 출처 바에서 상품군별로 실데이터/예시가 항상 구분 표시됩니다.
값이 없는 항목은 추정하지 않고 '-' 로 비워 둡니다.
