# 출처 등급과 주요 1차 출처

## 등급 판정

| 등급 | 정의 | 사용 규칙 |
|---|---|---|
| **1차** | 발표 주체가 직접 낸 것. 중앙은행·통계기관 공표, 기관 리포트 원문, 공시, 국제기구 데이터베이스 | 그대로 인용 가능 |
| **2차** | 언론 보도, 뉴스 요약, 데이터 벤더 페이지 | 인용 가능하나 **발표일·화자를 원문 기준으로 따로 확보**해야 함 |
| **3차** | 위키, 블로그, 환율 집계 사이트, AI 요약 | **단독 근거로 쓰지 않음.** 1·2차로 교차확인하거나 자료에서 뺀다 |

## 2차 출처를 쓸 때 반드시 분리할 것

언론 보도에서 수치를 가져올 때 다음 두 가지가 조용히 뒤바뀝니다.

**보도일 ≠ 발표일.** 8월 23일 기사가 8월 20일 보고서를 재인용한 경우가 흔합니다. 4월에 낸 전망을 8월에 다시 기사화한 경우, 그것을 "8월 전망"으로 적으면 4개월 묵은 숫자를 최신으로 제시하게 됩니다. 대장의 `announced_on` 은 **원 보고서 발표일**이며, 기사 날짜와 다를 수 있습니다. 다르면 기사 안에서 "지난 4월", "최근 보고서에서" 같은 표현을 찾거나 기관 사이트를 확인합니다.

**한 기사 = 여러 화자.** 한국 경제 기사의 표준 형식은 은행 연구원 + 대학 교수 + 당국자 발언을 한 편에 엮는 것입니다. 요약본만 보면 발언이 뭉쳐 보입니다. 인용할 발언은 기사 본문에서 "누가"를 직접 확인한 뒤 `attributed_to` 에 기관+이름으로 적습니다.

**조정방향은 별개 정보입니다.** "12개월 5.00"만 옮기면 그 기관이 강세를 보는지 약세를 보는지 알 수 없습니다. 종전 전망치(`revision_from`)를 함께 확보해서 상향/하향을 명시합니다. 방향을 뒤집으면 전망의 의미가 정반대가 됩니다.

## 주요 1차 출처

**한국**
- 한국은행 ECOS (통계) / 경제전망보고서 — 성장·물가·경상수지를 전망하며 **환율 전망치는 공표하지 않음**(전망 항목 목록으로 확인 가능)
- KOSIS, 관세청(수출입), 금융감독원 전자공시(DART)
- 예탁결제원 SEIBro (해외증권 보관금액), 금융투자협회
- 국민연금기금운용본부 (자산군별 현황·외환관리 정책)
- KDI 경제전망 — 환율은 "최근 수준 유지"를 **전제(assumption)**로만 언급. 전제와 전망은 다름
- 국제금융센터(KCIF) — 자체 전망은 없으나 **해외 IB 환율전망을 주간 집계로 공표**. "전망을 공표하지 않는다"고 쓰면 틀림
- 자본시장연구원(KCMI) — 반기 전망 공개

**미국**
- Federal Reserve (FOMC 성명·의사록·점도표), FRED (DEXKOUS 등 환율 시계열)
- BEA, BLS, Treasury

**브라질**
- Banco Central do Brasil (BCB) — Focus Market Readout(주간 서베이), COPOM 성명, PTAX 환율
- IBGE — IPCA(물가), PIB(성장)
- B3 — 거래소 자금흐름
- Tesouro Nacional — 국채·재정

**글로벌**
- IMF (WEO, Article IV) — **환율 전망은 공표하지 않음**
- OECD, World Bank, BIS (실효환율), Eurostat

## 접근이 막히는 출처와 대안

이 환경에서 자주 막히는 것들입니다. 막혔을 때 정답은 "추정해서 채우기"가 아니라 **`verdict: unverified` 로 남기고 사용자에게 확인 경로를 알려주기**입니다.

| 막히는 출처 | 증상 | 대안 |
|---|---|---|
| BCB Focus 공식 PDF | 404 / JS 렌더링 | 브라질 언론 2곳 이상 교차확인(InfoMoney, Rio Times, TrendsCE) + 사용자에게 bcb.gov.br 직접 확인 권고 |
| 해외 IB 리포트 원문 (GS, MS 등) | 403 / 유료 | 2차 보도로 인용하되 `announced_on`·`revision_from` 확보. 원문 미확인임을 각주에 명시 |
| KDI, KIEP, korea.kr | robots.txt 차단 | 보도자료 요약 또는 언론 보도. 확인 실패 시 해당 항목 제외 |
| Reuters / Bloomberg 컨센서스 | 단말 필요 | KCIF 주간 IB 집계로 대체 (공개·주간 갱신) |
| 한국은행 ECOS 원계열 | API 키 필요 | 언론 인용 수치 + 계열 편차를 각주에 명시 |

## 환율 계열의 함정

같은 통화쌍에 최소 4가지 계열이 돌아다닙니다: **장중(intraday)** / **종가(close)** / **뉴욕 정오(FRB)** / **월·연평균**. 서로 수십 원 차이가 납니다.

- "사상 최고"류 표현은 계열을 명시하지 않으면 검증 불가능합니다. 장중 고점과 종가 고점은 다릅니다
- 교차환율(A/B ÷ A/C = C/B)은 **세 값의 기준일이 같아야** 맞습니다. 하루만 어긋나도 0.5% 이상 벌어질 수 있으니 대장의 `cross` 검사로 확인합니다
- 집계 사이트(exchange-rates.org, Wise, Investing.com)는 서로 다른 피드를 씁니다. 하나를 골라 `series_policy` 에 선언하고 끝까지 그것만 씁니다
