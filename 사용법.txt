========================================
 보유자산 통합 브리핑 - 사용법
========================================

[준비]
아래 파일들을 "같은 폴더"에 함께 두세요.
  - briefing.html            : 브리핑 화면
  - server.ps1               : 로컬 서버 (Python 불필요)
  - 브리핑시작(창없음).vbs   : 검은 창 없이 실행 (권장)
  - 브리핑종료.vbs           : 서버 종료
  - 실행.bat                 : (예비) 검은 창으로 실행
  - 사용법.txt               : 이 문서

[실행 - 방법 A : 검은 창 없이 (권장)]
1) '브리핑시작(창없음).vbs' 더블클릭
2) 검은 창 없이 서버가 켜지고 브라우저가 자동으로 열립니다
   (주소: http://localhost:8899/)
3) 다 쓰면 '브리핑종료.vbs' 를 더블클릭해 서버를 끄세요
   ※ 창이 없으니 반드시 종료 파일로 꺼야 합니다
   ※ 시작 파일은 한 번만 누르세요(여러 번 누르면 중복 실행)

[실행 - 방법 B : 검은 창으로 (예비)]
1) '실행.bat' 더블클릭
2) 검은 창에 "Holdings briefing server is running..." 이 뜨고
   브라우저가 자동으로 열립니다
3) 종료: 검은 창 닫기 또는 Ctrl+C
   ※ .vbs 실행이 회사 정책으로 막혔을 때 이 방법을 쓰세요

[갤럭시탭 등 다른 기기에서 보기 (같은 와이파이)]
서버 실행 시 창(또는 배너)에 표시되는
  "On tablet/phone:  http://192.168.x.x:8899/"
주소를 탭 브라우저에 입력하면 됩니다. (PC는 켜져 있어야 함)

[주의]
- 'briefing.html' 을 직접 더블클릭하지 마세요.
  반드시 시작 파일(.vbs 또는 실행.bat)로 열어야 시세가 나옵니다.
- 인터넷 연결이 필요합니다 (네이버/야후/KRX 실시간 데이터).

[시작 파일이 안 될 때]
인터넷에서 받은 파일이 차단된 경우입니다.
  - '실행.bat' / '.vbs' 우클릭 > 속성 > 하단 "차단 해제" 체크 > 확인

[지원 자산 / 기능]
국내/미국/홍콩/중국/베트남 등 주식 · ETF · 펀드(실시간),
채권(직접입력: 만기수익률/듀레이션/세후/중도매도 시뮬레이션).
종목 뉴스·시황, 목표주가/컨센서스, 수급, 52주 위치, 고객별 저장,
PDF/인쇄(상담용 카드 출력).

[개인정보]
고객명·계좌번호 등은 입력/저장하지 마세요.
입력 데이터는 이 브라우저에만 저장되며 외부로 전송되지 않습니다.
