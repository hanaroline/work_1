팀 자료실 — 실행 방법 (사내망 전용)

압축을 반드시 먼저 푼 뒤, 아래 방법 중 하나로 실행하세요.
zip 미리보기 안에서 바로 실행하면 동작하지 않습니다.


[방법 1] run.bat 더블클릭
        - 서버가 뜨고 브라우저가 자동으로 열립니다.
        - .bat 실행이 막혀 있으면 run.cmd 를 더블클릭해 보세요.

[방법 2] server.py 더블클릭
        - 파이썬이 설치돼 있으면 이것만으로 실행됩니다.
        - 메모장으로 열리면: 우클릭 → 연결 프로그램 → Python

[방법 3] 명령 프롬프트 (가장 확실)
        1. 이 폴더를 탐색기로 엽니다.
        2. 위쪽 주소 표시줄을 클릭해 경로를 지우고  cmd  입력 후 Enter
        3. 검은 창에 아래를 입력
              py -3 server.py
           (py 를 못 찾으면)  python server.py


실행되면 검은 창에 이렇게 표시됩니다.

    접속 주소   : http://localhost:8080
                  http://10.x.x.x:8080   <- 팀원에게 알려줄 주소
    관리자 비밀번호 : xxxx-xxxx-xxxx   (최초 1회만 표시)
    조회용 비밀번호 : xxxx-xxxx-xxxx

관리자 비밀번호로 로그인한 뒤 [설정] → [비밀번호] 에서 두 비밀번호를
원하는 값으로 바꾸면 준비 끝입니다.

주의: 검은 창을 닫으면 서버도 종료됩니다. 켜둔 채로 두세요.


[파이썬이 없다면]
  명령 프롬프트에서  py -V  와  python -V  를 입력했을 때
  둘 다 버전이 안 나오면 파이썬 미설치입니다.
  사내 소프트웨어 포털에서 Python 3 을 설치한 뒤
  (설치 화면에서 "Add python.exe to PATH" 체크) 다시 시도하세요.
  python 입력 시 Microsoft Store 가 열리는 것도 미설치 상태입니다.

자세한 내용은 README.md 를 참고하세요.
