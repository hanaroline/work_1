이 파일은 자료를 담는 <빈 틀> 입니다

  1. 아래 [파일 추가] 로 자료를 넣습니다.
  2. [자료실 파일 만들기] 를 누르면 자료가 담긴 새 HTML 파일이 다운로드 폴더에 생깁니다.
  3. 팀원에게는 그 새 파일을 보내고, 다음에 자료를 고칠 때도 그 새 파일을 여세요.

지금 이 파일(빈 틀)에는 자료가 저장되지 않습니다. 다시 열어도 비어 있습니다.

파일 정보 수정

자료실 파일 만들기

자료와 화면이 하나로 합쳐진 HTML 파일이 만들어집니다. 이 파일을 팀원에게 전달하면, 받은 사람은 더블클릭만으로 목록을 보고 파일을 받을 수 있습니다.

입력하면 파일 내용이 실제로 암호화(AES-256)됩니다. 비워 두면 누구나 열 수 있습니다.

담기는 용량: -

자료실 파일을 만들었습니다

만들어진 파일-
  1. 이 파일은 다운로드 폴더에 저장되었습니다.
  2. 팀원에게는 이 파일을 보내세요. 받는 사람은 더블클릭만 하면 됩니다.
  3. 다음에 자료를 추가·수정할 때도 이 파일을 여세요.
지금 보고 계신 화면(빈 틀 파일)에는 자료가 남지 않습니다. 방금 만들어진 파일을 잘 보관하세요.

사용법

자료를 올리는 사람

  1. [자료 관리] → [파일 추가] 로 파일을 넣습니다. 폴더·설명도 함께 적을 수 있습니다.
  2. [자료실 파일 저장] 을 누르고 열람 비밀번호를 정한 뒤 [파일 만들기] 를 누릅니다.
  3. 저장된 HTML 파일 하나를 팀원에게 전달합니다(사내 메신저·메일 등).
  4. 자료를 바꾸려면 저장된 파일을 다시 열어 [자료 관리] 에서 수정하고 새로 저장합니다.

받는 사람

  1. 받은 HTML 파일을 더블클릭합니다(인터넷 연결 불필요).
  2. 비밀번호를 입력하면 자료 목록이 보입니다.
  3. 파일명을 누르면 다운로드되고, 여러 개는 체크 후 [선택 다운로드 (ZIP)] 를 씁니다.
알아두실 점: 이 파일은 서버가 아니라 파일 한 개입니다. 자료를 갱신하면 새 파일을 다시 전달해야 하고, 받은 사람이 자기 사본을 고쳐도 다른 사람에게는 영향이 없습니다.
