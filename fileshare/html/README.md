# 팀 자료실 (HTML 한 파일 버전)

**설치도 서버도 없이, HTML 파일 하나로 자료를 모아 팀원에게 전달**하는 방식입니다.
파이썬을 설치할 수 없거나 공유 폴더가 없는 환경을 위해 만들었습니다.

- `team-fileroom.html` 을 **더블클릭** → 파일을 넣고 → **[자료실 파일 저장]**
- 만들어진 HTML 파일 **하나**를 팀원에게 전달 (사내 메신저·메일 등)
- 받은 사람은 **더블클릭 → 비밀번호 입력 → 목록에서 다운로드**

인터넷 연결, 설치, 관리자 권한 모두 필요 없습니다.

---

## 1. 자료를 올리는 사람

1. `team-fileroom.html` 더블클릭 (빈 자료실이 편집 모드로 열립니다)
2. **[파일 추가]** → 파일을 끌어다 놓거나 선택. 폴더·설명을 함께 적을 수 있습니다
3. **[자료실 파일 저장]** → 자료실 이름과 **열람 비밀번호**를 정하고 **[파일 만들기]**
4. 다운로드된 `<자료실이름>_20260813.html` 을 팀원에게 전달

자료를 바꾸려면 **저장된 그 파일을 다시 열어** [자료 관리] 에서 추가·수정·삭제한 뒤 다시 저장하면 됩니다.
원본(`team-fileroom.html`)은 새 자료실을 만들 때만 쓰면 됩니다.

## 2. 받는 사람

1. 받은 HTML 파일 더블클릭
2. 비밀번호 입력
3. 파일명을 누르면 다운로드. 여러 개는 체크 후 **[선택 다운로드 (ZIP)]**

검색·폴더 필터·정렬, 한/영 전환을 쓸 수 있습니다.

---

## 3. 비밀번호와 보안

비밀번호를 지정하면 **파일 내용이 실제로 암호화**됩니다. 브라우저 표준 암호화(Web Crypto)를 씁니다.

| 항목 | 방식 |
|---|---|
| 키 유도 | PBKDF2-HMAC-SHA256, 20만 회, 16바이트 무작위 salt |
| 암호화 | AES-256-GCM (파일마다 별도 IV, 목록 정보도 함께 암호화) |
| 저장 형태 | 암호문만 base64 로 HTML 안에 들어감 |

- 비밀번호 없이는 HTML 소스를 열어도 **파일명조차 보이지 않습니다.**
- 비밀번호를 잊으면 **복구할 수 없습니다.** 원본 파일은 따로 보관하세요.
- 비밀번호를 비워 두고 저장하면 누구나 열 수 있는 파일이 됩니다.

## 4. 이 방식의 한계 (서버 버전과의 차이)

서버가 아니라 **파일 한 개**입니다. 다음은 구조상 불가능하니 감안하고 쓰셔야 합니다.

- 자료를 갱신하면 **새 파일을 다시 전달**해야 합니다 (받은 사람의 사본은 자동으로 바뀌지 않습니다)
- 팀원이 받은 사본을 고쳐도 **다른 사람에게는 영향이 없습니다**
- 누가 열어봤는지 **접속 기록이 남지 않습니다**
- 전달된 뒤에는 회수할 수 없습니다 (비밀번호를 바꿔도 이미 전달된 파일은 옛 비밀번호로 계속 열립니다)

위 기능이 필요하면 상위 폴더의 **서버 버전**(`fileshare/`)을 쓰세요. 파이썬 3 설치가 필요합니다.

## 5. 용량 기준

| 담는 자료 | 만들어지는 HTML | 저장 시간 | 여는 시간 |
|---|---|---|---|
| 5 MB | 약 7 MB | 1초 미만 | 1초 미만 |
| 20 MB | 약 27 MB | 약 2초 | 약 1초 |

자료가 HTML 안에 base64 로 들어가므로 **결과 파일은 원본의 약 1.35배**가 됩니다.
사내 메일·메신저의 첨부 한도를 고려해 **총 50MB 이하**를 권장합니다.

## 6. 동작 환경

- Microsoft Edge, Chrome, Firefox 최신 버전 (사내 표준 브라우저 대부분 해당)
- Internet Explorer 는 지원하지 않습니다
- 인터넷 연결 불필요 (외부 주소를 전혀 호출하지 않습니다)

## 7. 개발자용 점검

```bash
node fileshare/html/selftest-browser.mjs   # Playwright 필요 (인터넷망 개발 환경 전용)
```

파일 추가 → 암호화 저장 → 잠금 해제 → 개별/ZIP 다운로드 내용 일치 → 재편집 후 재저장 →
비밀번호 없는 저장까지 20개 항목을 실제 브라우저(`file://`)에서 확인합니다.
