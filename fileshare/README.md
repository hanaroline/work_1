# 팀 자료실 — 사내망 파일 공유 사이트

내가 만든 파일을 올려두면 팀원들이 브라우저로 열람·다운로드하는 **사내망 전용 파일 공유 사이트**입니다.

- **오프라인 동작** — 외부 인터넷, CDN, 폰트 서버에 전혀 접속하지 않습니다. 폐쇄망에서 그대로 돌아갑니다.
- **설치 불필요** — 파이썬 표준 라이브러리만 사용합니다. `pip install` 없이 `python server.py` 한 줄로 실행됩니다.
- **비밀번호 2단계** — 팀원용 *조회 비밀번호*, 본인용 *관리자 비밀번호*. 둘 다 화면에서 바로 변경할 수 있습니다.
- **기록이 남습니다** — 누가 언제 무엇을 올리고 받았는지 접속 기록에 쌓입니다.

---

## 1. 빠른 시작

### Windows

1. 파이썬이 없다면 [python.org](https://www.python.org/downloads/windows/) 에서 3.8 이상을 설치합니다.
   (설치 화면에서 **Add python.exe to PATH** 체크)
2. `fileshare` 폴더의 **`run.bat`** 을 더블클릭합니다.

### macOS / Linux

```bash
cd fileshare
./run.sh          # 또는: python3 server.py
```

### 첫 실행 화면

처음 실행하면 콘솔에 접속 주소와 **초기 비밀번호 2개**가 출력됩니다. 이 값은 **한 번만** 표시되므로 바로 적어 두세요.

```
================================================================
  팀 자료실 — 사내망 파일 공유 서버
================================================================
  데이터 폴더 : C:\...\fileshare\data
  접속 주소   : http://localhost:8080
                http://10.20.30.40:8080   ← 팀원에게 이 주소를 알려주세요
----------------------------------------------------------------
  최초 실행입니다. 아래 비밀번호로 로그인한 뒤 바로 변경하세요.
    관리자 비밀번호 : xz9m-bf73-rxmu   (업로드 · 삭제 · 설정)
    조회용 비밀번호 : yxy2-4zns-9d38   (팀원 열람 · 다운로드)
================================================================
```

브라우저에서 `http://localhost:8080` 으로 접속해 **관리자 비밀번호**로 로그인한 뒤,
`설정 → 비밀번호` 에서 두 비밀번호를 원하는 값으로 바꾸면 준비 끝입니다.

### 팀원에게 보낼 안내 예시

> 팀 자료실 열었습니다.
> 주소: http://10.20.30.40:8080
> 비밀번호: (사내 메신저로 별도 전달)
> 파일 이름을 누르면 바로 받아지고, 여러 개는 체크 후 [선택 다운로드 (ZIP)] 를 쓰면 됩니다.

## 2. 사내 업무망으로 옮기기 (반입)

인터넷망에서 아래 명령으로 반입용 패키지를 만듭니다.

```bash
python3 make_package.py
```

`dist/` 에 세 가지가 생성됩니다. 사내 파일전송 시스템 정책에 맞는 것을 골라 보내면 됩니다.

| 파일 | 설명 |
|---|---|
| `team-fileshare-<날짜>.zip` | 전체 폴더 압축본. **기본 권장** |
| `team-fileshare-standalone.py` | web 자산까지 한 파일에 담은 **단일 파일 서버**. 압축 반입이 막힐 때 |
| `team-fileshare-standalone.py.txt` | 위 파일의 `.txt` 사본. `.py` 반입이 막힐 때 (받은 뒤 확장자를 `.py` 로 변경) |

업무망에 도착한 뒤:

```bash
# 1) zip 을 받은 경우
#    압축을 풀고 team-fileshare 폴더에서
python server.py            # 또는 run.bat 더블클릭

# 2) 단일 파일을 받은 경우 (폴더 구조 없이 이 파일 하나면 됩니다)
python team-fileshare-standalone.py
```

두 방식 모두 기능은 동일하며, 데이터는 실행한 파일과 같은 위치의 `data/` 폴더에 쌓입니다.

전송이 끝나면 파일이 온전한지 `dist/CHECKSUMS.txt` 의 SHA-256 값으로 확인할 수 있습니다.

```powershell
certutil -hashfile team-fileshare-standalone.py SHA256   # Windows
shasum -a 256 team-fileshare-standalone.py               # Mac/Linux
```

> 반입 심사에서 내용 확인을 요구하면, 외부 통신 코드가 없다는 점을 그대로 보여줄 수 있습니다.
> 서버(`server.py`)와 화면(`web/`)에는 외부 주소 호출이 전혀 없고 — 화면의 모든 요청은 자기 자신(`/api/...`)으로만 갑니다 —
> 파이썬 표준 라이브러리로만 동작합니다. 외부 패키지 설치가 필요 없습니다.
> (`selftest.py` 는 점검용으로 `urllib` 을 쓰지만 `127.0.0.1` 자기 서버만 호출하며, 운영에는 쓰이지 않습니다.)

## 3. 옵션

```bash
python server.py --port 9000          # 포트 변경 (기본 8080)
python server.py --host 127.0.0.1     # 이 PC 에서만 접속 허용 (기본 0.0.0.0 = 사내망 공개)
python server.py --data D:\자료실      # 데이터 저장 위치 변경 (기본 fileshare/data)
python server.py --set-password admin   # 관리자 비밀번호를 콘솔에서 재설정
python server.py --set-password viewer  # 조회용 비밀번호를 콘솔에서 재설정
```

> 비밀번호를 잊었을 때는 서버를 끄고 `--set-password admin` 으로 다시 정하면 됩니다.

## 4. 사용법

### 관리자 (본인)

| 하고 싶은 것 | 방법 |
|---|---|
| 파일 올리기 | `파일 업로드` → 파일을 끌어다 놓거나 선택 → 폴더·설명 입력 → `업로드 시작` (여러 개 동시 가능) |
| 파일 정리 | 목록의 `수정` 으로 파일명·폴더·설명 변경 |
| 파일 지우기 | 목록의 `삭제`, 또는 체크 후 `선택 삭제` |
| 비밀번호 변경 | `설정 → 비밀번호` (조회용/관리자 각각) |
| 사이트 이름 변경 | `설정 → 일반` |
| 누가 받아갔는지 확인 | `설정 → 접속 기록` |

### 팀원 (조회용 비밀번호)

- 파일명 클릭 또는 `받기` 로 다운로드
- 여러 개 체크 후 `선택 다운로드 (ZIP)` 로 한 번에 받기
- 검색창·폴더 필터·정렬로 원하는 자료 찾기
- 기본적으로 **업로드·삭제는 불가**합니다. 팀원도 올릴 수 있게 하려면 `설정 → 일반 → 조회용 사용자도 업로드 허용` 을 켜세요.

### 설정 항목

| 항목 | 설명 | 기본값 |
|---|---|---|
| 사이트 이름 | 로그인 화면·상단에 표시되는 이름 | 팀 자료실 |
| 로그인 유지 시간 | 이 시간이 지나면 다시 로그인 | 12시간 |
| 최대 업로드 크기 | 파일 1개 기준 상한 | 1024 MB |
| 조회용 사용자도 업로드 허용 | 팀원의 업로드 허용 여부 | 꺼짐 |
| 로그인 시 이름 입력 필수 | 접속 기록에 이름을 남기도록 강제 | 꺼짐 |

## 5. 데이터와 백업

```
fileshare/
  server.py           # 서버 (이 파일 하나가 전부)
  web/                # 화면 (HTML/CSS/JS, 전부 로컬 파일)
  selftest.py         # 기능 점검 스크립트
  data/               # ← 실제 데이터 (백업 대상)
    config.json       #   설정 + 비밀번호 해시(PBKDF2-SHA256, 원문 저장 안 함)
    index.json        #   파일 목록 메타데이터
    blobs/            #   업로드된 파일 실체
    audit.log         #   접속·업로드·다운로드 기록
```

- **백업은 `data` 폴더만 통째로 복사**하면 됩니다. 다른 PC 에 `fileshare` 를 복사하고 `data` 를 덮어쓰면 그대로 복원됩니다.
- `blobs` 안의 파일은 임의의 ID 이름으로 저장됩니다(원래 파일명은 `index.json` 에 기록). 경로 조작 공격을 원천적으로 막기 위한 구조입니다.
- 정기 백업이 필요하면 사내 백업 대상 경로를 `--data` 로 지정해서 실행하세요.

## 6. 상시 운영

### Windows — 부팅 시 자동 실행

작업 스케줄러 → 작업 만들기

- 트리거: **시스템 시작 시**
- 동작: 프로그램 시작 → `pythonw.exe`, 인수 `server.py --port 8080`, 시작 위치 `C:\...\fileshare`
- "사용자가 로그온했는지 여부에 관계없이 실행" 체크

### Linux — systemd

```ini
# /etc/systemd/system/fileshare.service
[Unit]
Description=Team File Share
After=network.target

[Service]
WorkingDirectory=/opt/fileshare
ExecStart=/usr/bin/python3 /opt/fileshare/server.py --port 8080
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now fileshare
```

### 방화벽

팀원이 접속하려면 해당 포트의 인바운드를 열어야 합니다.

```powershell
# Windows (관리자 PowerShell)
New-NetFirewallRule -DisplayName "TeamFileShare 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
```

## 7. 보안 관련 안내

이미 적용되어 있는 것:

- 비밀번호는 **PBKDF2-HMAC-SHA256(24만 회)** 해시로만 저장하며 원문을 남기지 않습니다.
- 세션 쿠키는 `HttpOnly` + `SameSite=Strict`, 변경 요청에는 별도 헤더를 요구해 **CSRF** 를 차단합니다.
- 같은 IP 에서 비밀번호를 8회 틀리면 **5분간 잠금**.
- 비밀번호를 바꾸면 해당 등급의 **기존 세션이 모두 만료**됩니다.
- 업로드 파일은 항상 `attachment` 로만 내려주고 `nosniff` 를 적용해, HTML 파일을 올려도 사이트 안에서 실행되지 않습니다.
- 응답에 CSP·X-Frame-Options 등 보안 헤더를 적용했습니다.

운영 시 고려할 점:

- 통신은 **평문 HTTP** 입니다. 사내망 전용으로만 쓰고, 인터넷에 노출하지 마세요.
  HTTPS 가 필요하면 사내 리버스 프록시(IIS/Nginx) 뒤에 두고 TLS 를 종단하세요.
- 비밀번호는 팀 공용입니다. 누가 받아갔는지 더 정확히 남기려면
  `설정 → 일반 → 로그인 시 이름 입력 필수` 를 켜세요.
- 사내 보안 정책상 자료 반출 통제가 필요한 문서라면, 올리기 전에 담당 부서 기준을 먼저 확인하세요.

## 8. 점검 · 문제 해결

```bash
python3 selftest.py     # 로그인·업로드·다운로드·ZIP·권한·비밀번호 변경 등 45개 항목 자동 점검
```

| 증상 | 확인할 것 |
|---|---|
| `python` 을 찾을 수 없음 | 파이썬 설치 여부, PATH 등록. Windows 는 `py -3 server.py` 로도 실행 가능 |
| 다른 PC 에서 접속이 안 됨 | 방화벽 인바운드 규칙, `--host 0.0.0.0` 여부, 콘솔에 표시된 IP 사용 여부 |
| 포트가 이미 사용 중 | `--port 8081` 등 다른 포트로 실행 |
| 비밀번호를 잊음 | 서버 종료 후 `python server.py --set-password admin` |
| 업로드가 막힘 | `설정 → 일반 → 최대 업로드 크기` 확인, 디스크 여유 공간 확인 |
| 파일을 되살리고 싶음 | 삭제는 즉시 반영되며 휴지통이 없습니다. `data` 폴더 백업본에서 복원하세요 |
