[E] 실행 방법 (사용자 안내용)
--------------------------------------------------------------------------------
- 더블클릭 한 번(오프라인, 간편): mirae-sales-toolkit.html  → 4개 도구 모두, 링크 오류 없음.
  (단, 대시보드는 file:// 라서 샘플 데이터로 표시됨)
- 실시간 데이터·링크까지(권장): 실행-Windows.bat (맥: 실행-Mac.command) 더블클릭
  → 로컬 서버가 뜨고 http://localhost:8080/tools.html 가 자동으로 열림.
  (내 PC 안에서만 동작, 외부 공개 아님. Python 우선, 없으면 Node 사용)
- 수동: 폴더에서  python3 -m http.server 8080  실행 후 http://localhost:8080/tools.html

[G] 알려진 제약 / 함정
--------------------------------------------------------------------------------
- file:// 로 열면 ① 실시간 fetch 차단(대시보드 샘플만) ② 상대경로 링크 깨짐(ERR_FILE_NOT_FOUND).
  origin 이 null 이기 때문. → http://localhost 로 열면 둘 다 해결.
- 렌더 블로킹 폰트 <link> 가 사내망에서 멈추면 이후 스크립트가 안 돈다 → [C]의 논블로킹 로딩 필수.
- 올인원 파일은 iframe srcdoc 를 클릭 시 지연 주입(data-srcdoc)해서 초기 로드를 가볍게 한다.
- 공개 Pages 노출 금지(사내 규정). 실시간/공유가 필요하면 사내 웹서버·사내 API·데이터 브랜치.
